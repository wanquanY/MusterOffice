# Community Code of Conduct

MusterOffice welcomes contributors of all backgrounds and experience levels.
Treat people with respect and evaluate proposals by their technical merits.

- Give constructive, specific feedback. Discuss the code and evidence without personal attacks.
- Respect differing experiences and viewpoints. Help newcomers understand project decisions.
- Do not harass, threaten, discriminate, use sexualized language or publish another person's private information.
- Do not spam, impersonate others or use project spaces to promote unrelated services.
- Respect maintainers' moderation decisions and keep discussions relevant to the project.

These expectations apply to issues, pull requests, discussions and other official
project spaces. Maintainers may edit or remove inappropriate contributions, lock
conversations, or restrict participation. Responses should reflect the severity
and repetition of the behavior and protect affected people.

Use GitHub's **Report content** controls on abusive public content. Avoid repeating
private or harmful material in public reports. Account-level abuse can also be
reported through [GitHub Support](https://support.github.com/contact/report-abuse).
Security vulnerabilities use the separate [security policy](SECURITY.md).

## 中文

尊重不同背景和经验的贡献者，围绕代码、事实和方案提供具体反馈。
禁止骚扰、歧视、人身攻击、威胁、泄露他人隐私、冒充身份和垃圾信息。
维护者可按行为严重程度删除内容、锁定讨论或限制参与。
公开内容违规可使用 GitHub 的举报入口，避免在公开报告中再次传播隐私或有害内容。
