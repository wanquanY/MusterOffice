# DrawingML preset definition data

The unchanged `presetShapeDefinitions.xml` comes from the ECMA-376 Part 1 fifth-edition December 2016 archive. `source.json` pins the official URL, outer and inner archives, member name and SHA-256. No application implementation was imported.

`catalog.xml`, `catalog-index.bin` and `catalog.json` are implementation derivatives generated by `tools/contracts/generate-preset-catalog.py`. They are not an amended edition of the standard. The manifest records each arity correction, duplicate record, the constructed upward-arrow definition and catalog-local ratio names. Runtime ordinals address this generated, profile-pinned catalog.
