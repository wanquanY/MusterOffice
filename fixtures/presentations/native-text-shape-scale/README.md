# 自有文字与形状扩展输入

`compose.json` 是项目生成的基础验收材料，不含第三方模板、用户私有文稿或外部图片。
测量固定选取 `slides[1]`，重复为 10/40 页；保留全三页输入以便核对其来源。
它覆盖原生文字和矩形，不是完整混合内容性能语料。

`settings.json` 仅固定字体清单、资源摘要和绘制设置，不包含字体字节、个人机器路径
或权限。调用者必须显式提供符合摘要的合法字体资源包。当前 worker 摘要也固定，
不能用另一个构建冒充原测量；更新构建后须另记样本。

复现步骤、环境、结果及边界见[完整导出测量](../../../docs/implementation/native-export-scaling.md)。
