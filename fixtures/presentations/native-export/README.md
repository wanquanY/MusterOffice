# Native PPTX export input

Owned synthetic author document and PNG checker resource, generated by
`tools/verification/pptx-fixture.py`. No third-party template, private document or
font bytes are included. `Arial` is an explicit reference-only test font choice;
font embedding and visual equivalence are not asserted.

The document contains two pages and 15 objects across pages, a master and a layout.
It exercises text/Unicode, colors, geometry, group transforms, image resources and
connector relationships. This is a development fixture, not a product quality template.
