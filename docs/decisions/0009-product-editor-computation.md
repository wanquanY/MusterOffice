# ADR 0009 产品交互编辑的内核计算合同

- 状态：Accepted，实施中
- 日期：2026-10-02
- 依据：用户明确要求按 Musterwork 原生 PPT 编辑与独立放映方案，Musterwork 从 main 建立独立 worktree，MusterOffice 在主工作区 main 直接开发，持续实现并在开发环境验收。

## 决定

延续 ADR 0007：MusterOffice 提供编辑、布局、命中、文本选择、可逆事务及播放导航计算，
Musterwork 拥有编辑界面、交互历史分组、权限、持久化、窗口和正式版本提交。
人工编辑与 Agent 编辑共用内核模型及校验，不能在产品中复制布局/格式解析或用旧快照覆盖当前文稿。
本专项覆盖日常文字、对象、图片和页面编辑及放映；ADR 0008 的高级功能分档验收安排保持有效。

仅 Musterwork 在本专项使用从 main 创建的隔离 worktree。用户随后明确 MusterOffice 没有并行工作，
应直接在主工作区 main 开发；初建的 Office worktree 已将提交与必要证据移回后删除，避免重复占用构建存储。
已有提交与改动受保护；授权不包括远程软件发布或生产部署。

## 历史计算

宿主按授权记录持有原操作及其基准 checkpoint，向内核供应已解析的历史材料。
内核重算原事务，按受影响声明验证当前值，再仅反向应用该事务改变的声明。
独立声明保持原样；同一声明有后续变更、来源绑定变化或反向应用导致引用不合法时，原子拒绝。
撤销和重做均生成新 revision、ChangeSet 和独立请求摘要，提交仍由宿主 CAS 决定。

公开计算请求不是授权凭据。产品的跨权限接口应接收历史引用，由服务端解析原 checkpoint/操作；
不能把客户端传来的历史快照作为具有权限和谱系的证据。历史中的原始资源随 checkpoint 保留。
当前冲突粒度为文稿属性与实体声明，未声称能合并同一对象上的独立字段更改或提供实时多人协作。

## TS 与 WASM

`packages/editor-client` 是薄类型接口，消费由 Rust Schema 生成的合同。
固定 WASM 包的 `createPlaybackRuntime` 增加 `editor`，复用已初始化的内核。
字素/UTF-16 映射消费固定 Unicode 数据；页面坐标消费既有渲染布局计算。
现有 placements 还不是完整命中或文本光标接口，这些能力必须继续在内核补齐。

## 验收

原生与 WASM 的编辑/历史候选及失败诊断必须一致，保留摘要、资源和错误的原子性。
内核组件、浏览器交互、产品持久化、独立窗口、性能、Office/WPS 分别留证。
当前实现和仍缺能力见[专项进度](../implementation/native-presentation-editor.md)，本 ADR 不代表产品通过。
