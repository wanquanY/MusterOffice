# 决策与评审状态

更新日期：2026-09-24。

## 已确认

- 产品名称：**MusterOffice**。
- 建立独立本地项目，主分支 `main`，不创建额外 worktree。
- 面向 Agent，强调高性能、轻量化、多端跨平台。
- 演示文稿为当前设计方向，产品可扩展文档、电子表格及其他办公场景。
- 计划开源，不采购 Apryse；核心质量和可编辑性要求保留。
- 先明确设计，当前初始化不自动批准语言选型或内核实现。

接受记录见 [ADR 0001](0001-project-identity.md)。
