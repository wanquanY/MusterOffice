# ADR 0006：完整一期开发与持续目标

- 状态：**Accepted：开发范围与持续目标**。
- 日期：2026-09-24。
- 用户指示：“创建一个目标……以目标方案全部落地实现为目标，持续推进，直到能够开始替换musterwork的ppt”。

用户已授权按照 v0.4 整体方案进入完整一期实现，包括 P00 合同、E0 技术验证、基础工程、完整演示能力、Agent 接入、Musterwork 适配与替换验收准备。允许安装必要实现依赖和开展本地选型实验；无需重复询问是否可以开始开发。

以实际实现、原生可编辑文件、跨端/目标应用证据、资源预算和产品链路为完成依据。104项能力计划不因启动开发自动标为实现或验收；文档/合同检查不能代替真实演示文稿验证。

继续使用当前主工作区与main分支。不自动创建子代理、其他任务或worktree，不将本授权理解为公开仓库、发布软件包、部署生产、切换Musterwork线上路由或选择公开许可证的授权。

Rust主体、TS薄接入和精选C/C++的既有方向不变。具体组件通过依赖锁、许可核查与实验记录逐项采用；必要的结构修正应回写设计，不能以降低内容质量、功能或可编辑性达标。

实施入口：[工作包及实验合同](../design/implementation/delivery-plan.md)；推进证据维护于[开发进度](../implementation/progress.md)。
