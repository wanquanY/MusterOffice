# ADR 0010：公开开源与面向使用者的入口

日期：2026-10-04。状态：Accepted。

## 依据与决定

用户明确要求把现有 GitHub 项目调整为开源，README 重点说明如何使用，加入
Musterwork 公网体验和其制作的两套模板，默认英文并可切换中文。随后用户明确
选择 Apache-2.0，并确认体验地址为 `https://app.musterwork.com/`。

- 公开现有 `https://github.com/wanquanY/MusterOffice` 仓库及其现有 Git 历史。
- 原创项目源码和本次贡献的原创模板采用 Apache-2.0；第三方材料保留原许可。
- 根目录 `README.md` 为英文使用入口，`README.zh-CN.md` 为对应中文版。
- 两套模板为「蓝图 · 商务汇报」与「视野 · 内容报告」，各 14 页。
  仓库保存原始可编辑 PPTX、真实渲染预览、摘要和图片来源说明。
- 不迁入 Musterwork 私有应用源码、账号数据、模板目录身份或运行数据。

本决定取代此前“计划开源”“公开许可证待定”和“远程托管/公开时点待定”的状态。
此前 ADR 对当时授权边界的描述保留，不追溯改写。此次授权仅覆盖现有源码仓库公开，
不等于发布软件包、产品部署、完整功能验收或 Office/WPS 互操作验收。

## 实现与验收

新增 LICENSE、NOTICE、第三方声明及 Cargo/npm 项目许可证元数据。README 提供
源码构建、基础 PPTX 导出、文稿检查、结构化计算、MCP 配置和 SDK 入口。
历史阶段进度继续由实现文档和 Git 历史保存，不再占据首页。

验收要求：

1. 两种语言的本地文档/图片链接有效，示例命令在当前源码上实际运行。
2. 模板源和预览的 SHA-256 与原始已验证产物一致，PPTX 结构可读取。
3. 许可证与依赖声明保留准确边界，不将第三方内容重新授权。
4. 推送后回读 GitHub 的公开状态、默认分支、许可证和 README；匿名可访问。

检查过程发现 MCP 独立锁文件遗漏现有内部 `mo-unicode` 依赖边，通过正常 Cargo
离线解析补齐，未改变外部依赖版本或校验和。继续保留文档中的 `--locked`，不绕过锁验证。

2026-10-04 源码检查：CLI 与 MCP 的 `--locked --offline` 构建通过；README 的真实
PPTX 导出、两套模板检查、三页 compose 和 schema 查询通过；按文档配置启动 MCP，
完成初始化、三项工具发现与实际 compose。118 个相对文档链接有效，两套 PPTX 的 XML、
预览/源摘要及嵌入配图摘要核对通过；44 个原创 Rust 包添加许可证元数据。
历史可达对象中 5,012 个文本 blob 的所选常见凭据特征扫描未发现匹配；该检查不构成
完整安全审计。开源不改变此前功能、平台或外部应用验收的范围。
