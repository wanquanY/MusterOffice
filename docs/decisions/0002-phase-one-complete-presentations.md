# ADR 0002：第一期完整演示文稿内核与 Musterwork 替换目标

- 状态：**Accepted（产品目标）；详细技术合同待评审**。
- 日期：2026-09-24。
- 依据：项目发起人要求第一期完成后直接替换 Musterwork 的 PPT 能力，并在本次评审中明确回复：“第一期也要覆盖上述高级内容，按完整演示文稿内核设计”。该问题列明动画/转场、音视频、SmartArt、公式的原生创建、编辑和播放。

## 决定

1. 第一期以完整演示文稿内核为产品目标，包含静态文稿、动画、转场、音视频、SmartArt 和公式；适用对象必须能创建、编辑、渲染/播放并导出原生可编辑 PPTX。
2. 交付文件可以由 WPS、Microsoft PowerPoint 等传统工具打开和继续编辑；质量、功能与编辑体验均为验收对象。
3. 第一阶段的产品完成点是 Musterwork 实际替换完成。现有成功场景是最低回归基线，不是新产品功能上限。
4. V0、V1 等可以作为内部验证节点；只完成静态页面或现有功能迁移，不能宣称第一期完成。
5. 轻量、高性能、小体积要求继续有效。按模块装配可以减少无关加载，但不能借按需加载将上述必需能力排除在第一期完整发行物之外。

## 对现稿的影响

[详细设计 v0.2 历史基线](../archive/presentations-v0.2.md)第 4.3 节排除完整动画播放和音视频编辑的旧范围被本决定取代；第 4.1–4.2 节仅以现有能力定义 M1 的完成标准亦需扩展。静态 Scene、SVG/PNG 预览、原有性能预算和 T01–T30 不能独立覆盖新的第一期范围。

[本次评审](../reviews/2026-09-24-presentations-design-review.md)提出时间/事件模型、媒体宿主、SmartArt/公式语义、互操作与迁移修改建议。建议本身不因本 ADR 被视为已批准技术选型。

## 仍需细化

- 动画/转场效果、SmartArt 布局、公式结构、图表组合及其他演示文稿功能的可追踪清单。
- 目标 PowerPoint/WPS 的确切版本、操作系统、字体和媒体格式；不同目标应用本身存在能力差异时的交付行为。
- 只读检查、可编辑导入、保留回存、播放各自的能力与容量档案。
- 完整发行物、按需模块、字体/素材、输出 PPTX、实时播放和端到端操作的独立预算。

未列明的旧格式、宏、外部嵌入应用等不能仅凭“完整”二字自动宣称支持，也不能未经范围评审永久排除。

## 实施状态

本决定确认目标，不表示能力已经实现或验证。不自动批准开发语言、第三方依赖安装、选型实验、源码迁出、部署或公开发行。本次仍为设计评审与文档工作。
