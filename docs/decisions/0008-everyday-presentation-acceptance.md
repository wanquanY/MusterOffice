# ADR 0008：以常用 PPT 需求作为当前验收范围

- 状态：**Accepted：当前实施和验收优先级**。
- 日期：2026-10-01。
- 依据：用户确认已接入 Musterwork 并正常产出 PPT，要求继续按方案完善，下一次自行测试验收；不过度开发和设计，当前从普通用户角度覆盖常用基础需求，全量功能长期根据反馈逐步完善。

## 决定

沿用现有文档模型、共享计算、原生 PPTX 和 Musterwork 公共接入。当前以日常制作和修改的真实结果推进：页面与基础版式、可编辑中文/富文本、常用段落排版、图片与形状、基础表格、现有文稿/模板的已支持修改、预览和再次导出。常用图表等缺口按真实样本和用户反馈推进，并明确未支持范围。

先修复影响既有成功链路的构建、内容、布局和交付问题；新增能力直接贯通模型、计算和格式，不为本次验收建立新平台或额外架构。真实文件保留内容与可编辑性，不通过截图替代、删除内容、缩字或放宽验证获得成功。

ADR 0002/0006 和 v0.4 的完整能力保留为长期路线。SmartArt、复杂公式、完整媒体/转场/动画目录、3D/Morph/墨迹、全部格式和平台互操作不再是**本次常用功能验收**的前置条件；未完成能力不标为已实现或已验收，也不因此宣称完整一期完成。

## 验证和交接

维护简短的实际能力与限制清单，使用可复跑的日常文稿覆盖创建、指定修改、图片、表格、预览和原生导出；修改现有链路时执行相关回归及适当的 Native/WASM 对照。内核验证、Musterwork 实际调用和用户视觉验收分别记录。保留现有产品固定材料及数据，源码通过不等于已激活到产品。

使用当前主工作区；不创建其他会话、子代理或 worktree，不公开发布或部署。用户后续反馈决定下一批工作的优先级，不以实现完整能力清单为由延迟这次基础功能测试。
