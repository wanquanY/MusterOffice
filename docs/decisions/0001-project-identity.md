# ADR 0001：MusterOffice 项目身份与独立仓库

- 状态：**Accepted**。
- 日期：2026-09-24。
- 依据：项目发起人明确将产品命名为 MusterOffice，并要求在指定代码目录初始化独立项目。

## 决定

1. 产品名称使用 **MusterOffice**。
2. 本地独立 Git 仓库目录使用 `MusterOffice`，默认分支 `main`。
3. 产品定位为面向 Agent 的轻量、高性能、跨平台办公内核，允许后续扩展其他办公领域。
4. 演示文稿保留为当前首个设计与验证方向；整体产品不局限于 PPT。
5. 本仓库成为产品和内核设计的维护位置，Musterwork 保留自身接入设计及迁移导航。

## 本决定未覆盖

开发语言、Rust/WASM 方案、首版完整功能、最低平台版本、许可证、代码迁出、远程仓库托管与公开发布时间继续待定。

建立本地仓库不代表已授权公开私有代码或开始内核实现。本次仅建立项目文档、工程规范和 Git 基础。

## 影响

原 AP-Kernel 讨论代号不再用于正式项目名。演示文稿设计称为 MusterOffice Presentations，未来办公模块在共同原则下使用独立领域模型。
