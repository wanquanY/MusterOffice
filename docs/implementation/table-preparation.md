# 表格来源的共享准备

2026-09-29。本阶段承接[原生表格公共页面与播放](table-page.md)，将同一次页面准备中的表格对象索引、合并网格、样式绑定和声明几何共享给填充、边框与文字。它是计算内核内部的重构，不增加权限、数据库、后台任务或面向人的页面。完整一期和 Musterwork 替换验收仍在进行。

## 生命周期与职责

`mo-presentation-source::source::prepared::SourcePreparation` 借用一份不可变 `SourceIndex`，构造时验证预期来源摘要、表面数量及原生对象身份。对象索引建立一次，实际请求的表格按需准备；网格和样式通过 `Arc` 共享，单元格内容、文字目录及原始声明继续借用来源，不复制成另一套文档模型。

`PreparedSourceTable` 的字段不可由调用者拼装。填充与边框的新准备接口复用原解析器；文字级联和单元格正文绑定直接使用同一真实对象。声明行列坐标仍由编译层的 `DeclaredTableGeometry` 计算，与来源语义层保持分离。页面绘制和文字框编译共享这份几何，源表格的真实对象 ID、单元格地址、声明序号及缺失样式诊断保持。

普通无表格页面不创建该表格准备上下文。当前共享范围是原生表格的这些阶段；普通形状、背景、颜色占位符等入口仍有各自的查询上下文，不能称为所有来源查询都已全局去重。

页面准备结束后，文字阶段使用共享表格，完成纯计算预检后释放引用，再进入图片／字体组件。保留式播放的文字继续使用已有绘制结果；每次采样的绘制预检仍会建立新的表格准备上下文。本阶段没有引入跨帧常驻缓存，也不宣称已消除播放期间的全部重复准备。

## 预算与失败

共享上下文分别限制表面、对象、表格数量及累计网格单元格、步骤、ID 字节。首次准备为一个表格预留网格工作量，重复命中不重复构建；无效网格同样占用已接纳额度并缓存诊断。矩形行宽不合法时，不扫描未预留的单元格载荷。

共享不豁免查询及页面预算。填充／边框查询在构建网格前检查逻辑步骤和数值额度，命中已有网格也继续计费；文字阶段仍累计整页单元格、坐标、文字框、段落和运行项等额度。共享 API 的准备额度和各消费者的逻辑额度分别存在，不将它们合并成隐含的无限缓存。逻辑步骤采用保守预留，不等同于运行时间或分配字节。

取消、额度耗尽、找不到来源对象等准备错误终止该上下文；后续表格与普通填充查询不能继续使用已失败状态。来源或对象身份不匹配会拒绝复用，即使另一份索引具有相同 ID 或摘要。缺失样式和无效网格继续返回已有的结构化诊断，不用默认样式掩盖问题。

## 验证

[阶段证据](../reviews/evidence/2026-09-29-table-preparation-verification.json)记录源码摘要、检查命令及封存文稿重放。新增测试直接核对共享对象／网格／样式引用，以及填充、54 个物理边、6 个合并起始文字框与独立查询的完整结果；另覆盖来源冲突、缺失样式、预算、无效网格缓存及取消后拒绝继续。

455 项相关来源／格式／编译测试和 28 项字体集成测试通过。最后补强失败上下文的普通填充入口后，再执行 17 项表格专项；严格 Clippy、工作区检查、Schema／TS、SDK 依赖边界、Native／WASM 构建和格式检查均通过。

封存的 14 次表格静态请求、18 帧表格播放在 Native／WASM 上完整响应与像素相同，并保持上一阶段结果；旧普通内容的 64 次静态请求和 90 帧播放也保持跨端与历史结果。8 份边框文稿的 29 次查询继续保持公开 Native／WASM 响应及历史摘要。这些检查不替代 Office/WPS 验收。测试字体属于项目自有确定性测试素材，不代表真实商业字体质量。

## 后续与接入

本阶段没有新增外部依赖或线协议。未测得新的墙钟性能、RSS 或安装包体积数据，因此不报加速比例或体积收益。

相邻冲突边框的 Office/WPS 选择规则、完整画笔／描边、自动行高、网格与外框协调、完整变换和外部编辑往返仍需实现／校准。不能以准备层共享替代这些功能验收。

Musterwork 继续只使用 `codex/musteroffice-integration` 独立 worktree。当前不更新产品固定材料或切换默认引擎；经过内核能力与互操作验证后，再原子升级 SDK、Worker、播放材料并验证产品链路。原主工作区留给用户。
