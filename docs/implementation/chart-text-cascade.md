# 图表文字级联与主题字体上下文

图表文字现已复用形状、表格使用的原生段落和字符属性级联，以及主题字体选择算法。
结果绑定真实 chart 部件、正文根和物理序号，没有创建代用形状，也没有把图表文字
放入宿主页面计算。当前阶段仍是声明计算与字体解析，不是完成标签排版或整图绘制。

## 共享计算与图表边界

`ChartTextResolver` 对同一已解析图表建立一次正文索引，接受真实 `c:rich` 或 `c:txPr`
正文及从高到低的原生文字属性根。标签计算器从已解析的单点、系列、chartSpace 声明
构造这条链；自定义富文本使用自身正文，普通标签使用最具体的文字属性正文。

段落属性、默认字符属性、文本 run、换行、字段和段尾插入样式经过同一原生算法。
显式 false 覆盖下层 true；noFill 等互斥声明替换整个属性槽；段尾属性不覆盖已有 run。
来源类型新增 `TextStyleOrigin::Chart`，同时记录部件、正文根和声明序号，查询不能把
其他正文中的同名声明当成当前来源。共享形状/表格模式保留原有默认行为。

图表模式只级联真实声明，缺失属性仍为 None。传统图表默认样式、现代 chartStyle、
字号、字体与颜色还需单独计算，不能套用形状的 18 磅或擅自选 Arial。特别是 ECMA-376
Part 1 §21.2.3.46 规定传统图表样式的主题 minor 字体、chart 字号及标题规则；这些与
普通文本框默认值不同。现代样式的
[CT_StyleEntry](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-odrawxml/502b63f6-d2ff-47f9-a466-73af2d4cc03e)
也包含自己的 fontRef、defRPr 和 bodyPr，不能遗漏后声称已得到最终样式。

`c:txPr` 的 lstStyle 在标准中不受支持，见
[TextProperties](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.charts.textproperties?view=openxml-3.0.1)。
当前计算配置将非空 lstStyle、多个属性段落或属性正文中的文本 run 标为未解析；
不将形状列表层级规则移植到图表。这不是认定所有这类输入都损坏，也不是跨应用裁决。
富文本中的复杂列表同样等待对应规则。未知内容与未知属性保留可定位诊断。

## 字体上下文

`ChartTypefaceContext` 使用同一个原生字体选择器解析直接字体、主题 token、空槽和
supplemental 字体。图表自身的 themeOverride 优先提供字体方案；未声明字体方案时，
使用实际所属页面选中的方案。主题部件读取已从图表颜色计算中抽出，文字与颜色共享
同一个有界读取器、内容类型/关系检查和原始部件摘要验证。

直接字体不要求主题存在。空东亚/复杂文字槽需要明确的主题脚本键，例如 Hans；不取
列表第一项或根据宿主语言猜测。缺少声明、未知 token、重复 supplemental 项、保留的
未知属性均沿用共享诊断。没有读取系统字体、替换家族或伪造 fontRef。

该字体上下文当前是 Rust 编译器接口；后续图表文字编译器须在文字分段后给出脚本键，
再与显式字体资源清单绑定。当前标签查询中的原生字体引用不等于已经获得字体字节、
塑形结果或可绘制文本。

## 标签结果与计算预算

既有 `pptx-chart-labels` 结果增加 `textCascades`，单个标签通过 `textCascade` 索引引用。
相同正文和继承链只计算一次，避免大量同样式标签复制完整文字属性图。删除的标签不
计算正文，没有文字声明的标签保留空引用，等待图表默认样式解析。字体、颜色和布局
声明保留真实位置，未被展开成无来源的宿主 CSS。

正文索引、来源引用和结果词法成本计入预算。步骤、段落、run 和保留字节在图表本次
计算中累计；超过预算或取消不返回部分标签结果。默认采用共享文字级联的 1,024 段落、
4,096 run、1,000,000 步和 4 MiB 逻辑字节预算，可由 Rust 宿主明确调整。它不是 RSS
上限测量。原始来源查询和标签数据绑定仍有各自累计预算。

## 验证范围与后续

验证记录见[本次证据](../reviews/evidence/2026-09-30-chart-text-cascade.json)。自有测试
覆盖直接字体、图表/页面主题选择、中文脚本、空主题覆盖、跨正文绑定冲突、预算和取消；
标签查询补充富文本、原生段尾属性、未声明字号和不支持结构的跨端案例。独立 ZIP/XML
验证器核对声明与来源，并检出人为篡改的字号。它不证明字体选择、塑形或 Office 行为；
这些结论按各自证据区分。共享文字页面另与前一版本逐像素比较，防止重构影响既有结果。
