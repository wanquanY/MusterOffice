# 原生模板的固定压力计划

2026-09-28，Musterwork 独立 worktree 的原生计算档案新增 `office_template_stress_plan`。它从 SDK 已验证的固定模板生成必需案例，结合[实际实例计算](product-template-instances.md)执行参数绑定、渲染和导出。压力策略属于接入产品；MusterOffice 公共 SDK 继续负责参数和文稿计算。本轮没有增加核心业务任务、存储或权限系统。

本阶段完成计划生成和真实文字案例执行。后续[原维护压力任务](product-template-stress-maintenance.md)已接通这些操作和独立提交证明；自动上传和目录发布尚未切换，完整视觉质量与 PPT 替换验收仍未完成。

## 计划语义

操作只接受 `template_ref`、`template_digest`、`settings_digest`、`source_resources`、`resource_cases` 五个显式字段。它与实例计算共用有界模板加载器，验证模板包、原资源实际字节、当前字体和渲染环境。资源材料来自已授权的产品输入，没有任意文件路径或隐式网络加载。

生成文件为 `presentation-native-stress-plan/1`，策略身份为 `presentation.native-template-stress@1`。计划包含模板/环境摘要、一次保存的真实参数基线，以及带顺序 ID 的案例变化。执行时应用基线、单例覆盖和明确的可选参数省略；不为每个案例复制全部未改变的参数。

| 参数类型 | 当前策略要求的案例 |
| --- | --- |
| 全部模板 | 来源参数基线 |
| 文字 | 字符数下限；上限下的宽拉丁、窄拉丁、汉字、RTL 文字、组合字符、词间断行样本 |
| 多个文字参数 | 所有文字同时取下限，以及同时取各类上限样本 |
| 主题颜色 | 黑、白、透明和有彩色值 |
| 对象变换 | 半尺寸、双尺寸、四分之一圈、水平翻转、垂直翻转 |
| 资源 | 每种声明允许的媒体类型都有实际字节不同的替换材料；缺少材料不能生成完整计划 |
| 可选参数 | 明确省略该参数的案例 |

该表是版本化的有限采样策略，不证明任意参数组合或全部语言均合格。资源计划验证身份、类型和真实字节，实际解码在实例渲染中执行；不会接受调用方自报的图片尺寸或“已通过”字段。材料重复供给多个参数时只进行一次实际字节摘要计算。

计划只记录资源的摘要、长度和媒体类型，不记录宿主 `content_id`。来源或资源重新进入另一内容库后，只要真实字节和明确引用映射一致，计划字节和摘要保持不变。案例不会因一次存储迁移而变化。

保留原 8 MiB JSON 上限，最多 8192 个案例，文字生成前检查容量，生成中检查取消。超出容量、参数数值变换溢出、资源材料缺失或额外材料未消费，均使整个计划失败，不截断案例或宣布部分覆盖完成。这些产品计算边界不表示完整维护流程已经能够调度 8192 个案例。

## 实际执行与验证

23 项相关测试通过：18 项模板库测试、2 项计算端口合同测试、2 项真实引擎专项和 1 项原维护定义回归。接入库全部 target、Artifact 库严格 Clippy 通过，执行前后源码清单保持一致。详见[验证记录](../reviews/evidence/2026-09-28-product-template-stress-plan-verification.json)。

真实专项使用一份两页原生模板、一个必填文字参数和固定字体/设置，从生成计划逐项执行全部 8 个案例：来源基线、下限和 6 种上限样本。最大值为 16 个 Unicode scalar。实际结果包括 8 份 PPTX、16 张预览及 96 个逻辑 SDK 资产；每项均校验对应文件字节，不将逻辑资产数当作唯一文件数。

独立 Python ZIP/XML 验证逐项核对原生文字叶节点、实际快照、SDK 实例回执和输出文件。来源基线未改变原部件，其他 7 个实例只改变指定文字，合计 161 个非目标压缩部件保持字节一致。未修改页面预览保持一致；检查按来源页身份定位，没有固定假设目标在第一页。

覆盖字体由已有自有合成字体增加 11 个码点生成，两次生成的 2636 字节结果及配置相同。没有复制第三方字形或使用系统字体；生成器、父字体摘要和用途均保留。三角形合成字形只能验证码点覆盖、参数计算和渲染链路，不证明中文或阿拉伯文字体美观、语言排版和目标应用保真。前阶段原字体缺少 `W` 的拒绝用例继续通过。

交付中的有限结构声明为 `passed`，布局、原生编辑往返、播放和目标应用仍为 `not_proven`。资源、颜色、变换和多参数组合目前只有计划层单元验证，本次实际 worker 执行覆盖上述单文字参数案例，不扩大为全部类型验收。
