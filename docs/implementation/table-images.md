# 原生表格图片填充与播放复用

2026-09-29。原生表格背景与合并起始格的图片填充进入共享页面计算，承接[表格跨帧复用](table-retention.md)。本阶段完成下述范围的源码与跨端验证，尚未升级 Musterwork 固定材料，也不构成完整表格或 Office/WPS 验收。

## 实现

图片布局复用既有裁剪、拉伸、平铺和密度计算。接收区域直接使用真实表格背景或合并格的局部边界及坐标误差，保留原生对象身份和变换；不生成替代形状，不将尺寸截断到整数 EMU。原生查询按表格共享声明几何，页面计算使用已准备的区域。RTL 改变单元格位置，不反转图片像素。

原始关系与声明来源继续保留；不同部件中相同编码内容可共享解码结果。保留式播放记录区域身份，逐帧检查局部布局是否仍适用，再用实际采样变换计算世界坐标。移动、透明度和可见性采样不重新解码图片，也不重复整形文字。

缺失关系、错误引用模式和当前不支持的图片旋转策略在调用组件前拒绝。被合并覆盖的格不被当成独立图片区域。表格边框图片画笔、完整样式目标、完整变换和其余表格能力仍需独立实现。

## 验证与边界

- 464 项相关 Rust 测试、28 项原生文字／绘制测试通过；源码严格 Clippy、全工作区编译、Schema、TypeScript、SDK 边界、原生与 WASM 构建及格式检查通过。
- 六份自有 PPTX 通过完整幻灯片及表格 XSD，各六次；独立从 XML 及四个已知源像素推导的 1,134 个图片像素检查通过。
- 两次静态请求与 24 帧保留式播放的 Native/WASM 完整响应和像素相同，并对应 Rust 实际组件输出。覆盖合并格、RTL、裁剪、拉伸、镜像平铺、背景、内容去重、移动、透明度、隐藏、显示与重播。
- 既有表格语料的 14 次静态请求与 30 帧播放继续跨端一致，响应字节及像素摘要保持历史结果。

失败记录也保留：数值测试最初错误地比较两层舍入后的误差框，现改为直接验证精确有理数角点；测试辅助文件的未使用重导出改为共享常量引用。没有放宽数值误差、关闭 lint 或跳过失败用例。
