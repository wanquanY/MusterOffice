# 产品播放导航与计算组件统一升级

2026-09-28，在 Musterwork 的 `codex/musteroffice-integration` 独立 worktree 中，将已验证的原生序列导航、页面边界及自然结束跳转能力接入产品播放路径。原主工作区留给用户，没有用于本阶段写入、构建或测试。完整替换目标仍进行中。

## 接入行为

产品播放器增加“上一步动画”“下一步动画”按钮，以及画布焦点下的左右方向键。鼠标、回车和空格仍发送普通点击事件；导航与点击保持不同语义，产品不会猜测或重写文稿的动画序列。导航作用于当前页的原生序列，并不自动切换幻灯片。

产品在输入到达时记录播放时刻，依次传给同一个计算 Worker。内核决定节点激活、自然结束跳转、并发和回退；产品没有第二套动画求值器。重新开始页面会创建新的计算状态并清空旧事件，不重读整份材料。按钮、键盘、时钟和 Canvas 仍属于 Musterwork，MusterOffice 没有新增面向人的页面或权限、存储系统。

Worker 拒绝未知输入、倒退的宿主时钟和超出边界的事件数量。实际测试验证了拒绝后已有历史不变，以及同一时刻连续导航和点击保持顺序。取消、换页和关闭继续复用原 Worker 生命周期。

## 实际验证

187 项不同功能测试通过：准备脚本 18 项、产品读取/客户端/真实 Worker 117 项、Vue 查看器 7 项、Rust 接入库 19 项、原生 Agent 26 项。相关 Vue TypeScript 检查和完整桌面前端 Vite 构建通过，构建保留既有大 chunk 提示。新增 Python 复现工具通过静态检查。

五份自有动态文稿通过产品固定 SDK 的独立消费者和实际导出 Worker 生成完整交付，覆盖有限序列、无限并发、无限截断、嵌套依赖和缓存结束条件。新交付经公共交付检查接口导出播放输入，原生 Worker 生成 60 个参考帧。真实产品 Worker 在 Node 的隔离 Worker 运行原入口和公共 WASM SDK，共核对 95 次动态帧：60 次基本采样、5 次错误拒绝后的采样、30 次重新开始后的重播。此前实际产品发布的两版文稿另有 8 帧保持一致，合计 103 次产品 Worker 帧对照。

动态交付的生成没有经过本轮的产品数据库提交；它验证真实计算、交付输入和产品 Worker。旧两版材料来自前阶段真实产品提交。本阶段另运行原生 Agent 导出、导入、数据库重开、丢响应恢复、环境校验及模板复核回归，两类证据分别记录。

首次 26 项原生 Agent 回归有 23 项通过，3 项因测试仍引用旧渲染环境的压力结果而被拒绝。保留失败日志和旧材料，使用当前 Worker 重新执行溢出与可容纳两份输入的定义/压力计算，随后原检查及两个原最终复核用例均通过。没有改变生产校验或测试断言；额外的可容纳输入生成重复执行一项测试，不重复计入 187 项。

最终[可复核证据](../reviews/evidence/2026-09-28-product-navigation-final-verification.json)记录源码、命令、材料和帧摘要。最初的[验证快照](../reviews/evidence/2026-09-28-product-navigation-verification.json)保留；后续仅整理 Python 复现工具格式与显式参数，并用最终工具重新生成动态材料和复验客户端，没有改变计算或产品实现。

本阶段没有新增浏览器、Electron 或 Office/WPS 播放观察。完整出现/消失及其他动画、隐式原生事件、高级转场、音视频、SmartArt、公式、历史迁移、完整产品会话、外部编辑往返、性能/资源/安装包与 E0–E3 继续实施。前后导航已接入不代表完整 PPT 功能或替换验收完成。
