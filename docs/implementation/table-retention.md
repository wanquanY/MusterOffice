# 表格结构与坐标的跨帧复用

2026-09-29。本阶段承接[同次调用共享准备](table-preparation.md)，把原生表格的对象目录、合并拓扑、样式选择和声明坐标保留在不可变来源计划中。继续使用原页面、填充、描边、文字及播放计算；没有另建表格渲染器，也没有增加存储或业务任务服务。

## 所有权与计算

保留页面用 `Arc<SourceIndex>` 持有同一份来源，避免借用自身字段的结构。对象目录保存表面名称及对象位置；网格分成来源绑定和不可变拓扑，拓扑数组共享；样式保留内联／共享目录的真实选择身份或原诊断。坐标层单独共享声明边界及转换误差，文字目录与单元格内容仍来自同一个原生对象。

`RetainedSourcePreparation` 只能从已成功准备的上下文及其准确来源所有者生成；同摘要的新索引不能冒充原对象。编译层捕获坐标时同时检查对象、文字目录和网格的来源绑定。来源字段保持私有且不可变，不使用 `unsafe`、生命周期延长、全局缓存、互斥锁或第二份文稿副本。

每次采样创建轻量借用会话，仅重建小型绑定包装；同一表格不再重建合并拓扑、重新校验整表段落次序或累计声明坐标。可见性、位移、透明度、世界坐标、画笔位置和最终误差认证仍按本帧计算。真实单元格身份、合并、RTL、渐变空间与整体透明度继续进入同一绘制管线。

当前保留范围不含所有页面查询：普通形状、背景、颜色占位符等仍存在独立准备，表格填充、边框颜色及最终路径仍逐帧计算。本阶段不宣称所有绘制准备都已缓存，也不将这些保留数据称为完整 GPU 合成计划。

## 准入、取消和版本

只有初始资源可见性并集已经接纳的表格能进入保留状态。未准备的对象即使存在于原文稿，也不能在采样中追加；动画可显示的原隐藏表格需要在首次准备时完成检查。永久隐藏的无关内容仍遵守原准入行为。

原生对象目录、表格数量、网格规模、ID 字节及坐标仍受已有上限控制。后续页面按已验证的逻辑成本累计预算，无需为了计费再次遍历单元格。缺失样式和无效网格诊断可以随来源一起保留，不改成默认样式或有效结果；无效网格也继续占用已接纳额度。

会话取消或请求越界会使该会话失败，不改变不可变所有者；新会话可以继续计算。捕获过程在返回前再次检查取消，失败不发布半个计划。不同来源、同 ID 的其他对象及替换过的坐标绑定会被拒绝。文稿编辑后必须以新来源重新准备，不能把旧缓存套到新文稿。

## 验证与边界

[阶段证据](../reviews/evidence/2026-09-29-table-retention-verification.json)记录最终检查、源码、语料和输出。新增测试检查原宿主索引引用释放后仍可使用计划、多个会话共用网格数组和坐标、采样没有新增网格编译，以及取消、错误对象、额度、内联／共享／缺失样式和无效网格的行为。RTL 圆形渐变的移动／显隐／透明度采样与重新准备的完整场景、来源绑定及误差元数据对照。

实际播放语料新增圆形渐变表格移动与原隐藏表格的动画显示；它们与已有移动、隐藏、淡入一起使用真实时间树、字体组件及栅格组件，保留播放与逐帧编译比较，并再次跳回历史时间。12 份自有 PPTX 已通过整页／表格 XSD 与来源检查；276 个线性渐变像素通过独立参考。

459 项来源／格式／编译测试、28 项原生字体测试及最终 21 项表格专项通过；严格 Clippy、工作区编译、Schema／TS／SDK 边界检查和 Native／WASM 构建通过。公共接口的 14 次静态表格请求、30 帧表格播放跨端一致，其中既有 14 次／18 帧保持历史完整响应与像素结果；另有 64 次静态、90 帧既有播放和 29 次边框查询保持跨端及历史结果。新增 12 帧分别覆盖圆形渐变移动与原隐藏表格显示，未计入旧结果不变的数量。

字体为项目自有确定性测试素材，不代表商业字体或中文排版验收；没有新测墙钟性能、RSS 或安装包体积，不报加速比例。

冲突边框优先级、完整画笔／描边、自动行高、外框协调、完整变换、Office/WPS 编辑往返、其他高级内容和全部替换门槛继续开放。Musterwork 仅使用既有 `codex/musteroffice-integration` 独立 worktree，本阶段不更新产品固定材料或切换默认引擎，原主工作区留给用户。
