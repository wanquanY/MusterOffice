# 多段与三次曲线路径动画

2026-09-29：新增 `Effect::MotionPath`，连接的直线、三次贝塞尔曲线与关闭路径已接入作者模型、时间计划、原生 PPTX 解析和导出。旧 `MotionLine` 的十进制坐标和精确线性采样保持不变。此项是完整一期的一个实现增量，完整替换验收尚未完成。

## 语义与格式

`MotionPath.from` 给出初始位置；`segments` 包含 `line`、`cubic`、`close`。三次曲线保留两点控制柄和终点，关闭路径回到初始点。坐标是相对原始对象布局中心的幻灯片宽、高比例；路径进度按这一归一化坐标空间内的距离计算，随后才映射到幻灯片尺寸。对象旋转、缩放、可见性和透明度继续属于独立属性通道。

原生解析支持初始 M/m、多个 L/l、C/c、Z/z 和可选 E/e；同一相对曲线命令的三个点均相对于命令开始位置。明确 E 之后的文本按原生规则忽略。仅一段直线继续投影为旧 `MotionLine`。原生导出写出控制点和关闭命令，不把运行时细分折线写回文稿。原始导入 OPC 字节仍由来源模型保存。

命令语法依据 [Microsoft 的原生 animMotion 说明](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oe376/20acd8bd-6ba0-461d-ae9f-f7e0f90e1ff7)。路径中的再次移动、公式、parent 原点、绝对编辑模式和路径角度仍返回未支持诊断；没有忽略它们或把它们改写成当前子集。

## 计算与精度

编译期用 Q64 整数坐标、整数平方根和 de Casteljau 细分建立累计长度表，不调用平台浮点几何。每个接受片段同时满足两个条件：控制多边形长度上界与弦长下界之差在分配预算内；两个控制点到有限弦段的距离不超过 `2^-20`。距离检查包含弦段端点，因而共线折返、零长度弦、回环不会误判为一条直线。

每条路径把总弧长差预算 `2^-20` 分给命令，再随细分二等分。所有接受片段的预算之和不变。浮点参考只用于独立验证，未参与生产计算。

播放按累计长度二分定位，再用有界有理数插值；不逐帧细分、不依赖帧率，也不按曲线参数 t 匀速。初始和最终位置直接使用原始十进制坐标。缓动、重复、倒放、取消与属性竞争复用既有时间语义。

新帧使用 `musteroffice.paced-motion-frame-q64/0.1-draft`，将计算结果的精确分数表示与曲线近似误差分开。归一化位置误差预算为 `2^-17`：累计弧长差和片段到弦距离占主要部分，Q64 坐标转换、32 层细分舍入和整数平方根的累计误差由硬资源上限约束，留在剩余预算内。换算到像素可乘以视口最大边长，例如最大边长 8192 时上界为 1/16 像素。该界描述内核路径计算，不代表外部应用的播放误差、整页排版误差或已测 FPS。

每行为最多 4096 个源命令；整份时间计划默认最多 65536 个命令、262144 个细分片段、1000000 步路径计算。片段硬上限 1048576，细分深度硬上限 32。预算跨对象共享，取消在命令及细分循环中检查。不能在预算内达到精度时返回诊断，不降低精度继续输出。源 XML 路径另受 1 MiB 字节上限限制。

## 验证与互操作边界

Rust 测试覆盖共线非匀速参数曲线、不等长折线、归一化轴向转折、关闭路径、零长度段、十进制端点、回环、尖点、折返、重复倒放缓动、共享预算及取消。曲线使用独立均匀参数积分与弧长反查参考，并将参考采样分辨率加倍检查收敛；未复用内核细分表。PPTX 测试覆盖公共作者序列、原生路径预设、控制点导出回读和独立相对命令样本。

自有 WPS 校准采用同一画面中的直线、非匀速参数共线曲线、不等长折线和轴向折线。早期画面六行的水平中心均为 519.5 像素，支持归一化距离匀速的实现选择；该截图没有精确时间同步，不能证明任意曲线与 WPS 逐帧一致。最终画面也暴露出 WPS 未按该样本的父容器 3 秒截止停止路径，故没有把预期中点作为通过结果。该实验先改写自有 XML 再观察，仅用于语义校准，不是直接作者导出的完整验收。

560 项相关 Rust 测试及严格 Clippy 通过，本轮新增 9 项。两份完整 PPTX 的作者和来源链路共 64 帧与独立参考核对，样本最大归一化位置误差为 `4.812659e-7`，参考加倍分辨率后的差异小于 `1e-9`。32 个无动画静态几何对照仅在写入整数 EMU 时舍入，最大通道差为 1、每帧通道差总和最大 116；这项为有容差画面对照，不称为全部逐字节相等。10 个 PresentationML 部件通过独立 XSD。64 帧分别通过真实打包 WASM 的同步和分步执行；既有直线／混合内容 28 帧回归通过。

另通过公共 `setPresentationSequence` 创建并直接导出六种路径，未手改 XML；该文件的 6 帧原生及两种 WASM 执行均对齐。WPS 12.1.22553 实际播放了该文件，曲线运动和关闭路径回到起点可见。与初始布局截图相比，终点位移最大观测差约 2.504 像素（3024 像素宽画面）；该值只记录观测，不声明像素验收通过。此前直接导出的底层 v0.1 时间图虽然可被内核播放，WPS 中没有播放；它缺少演示序列角色，仍是通用时间图导出的互操作缺口，不能将作者序列通过外推到这一入口。结束后恢复原 WPS 文稿，没有保存修改或新增目录权限。

命令、源码和材料身份见[本轮验证证据](../reviews/evidence/2026-09-29-motion-paths-verification.json)。产品对接只使用[独立 Musterwork worktree](product-worktree.md)。一般路径移动、完整高级动画、外部编辑往返、真实产品运行与全部替换门禁继续开放。
