# 产品查看器接入公共播放 SDK

2026-09-28。状态：候选播放入口已实现并在实际浏览器运行，完整替换仍在实施。所有产品修改使用[独立 worktree](product-worktree.md)；Musterwork 原主工作区留给用户。本阶段没有修改内核计算源代码或产品固定 Rust SDK/native worker。

## 实际链路

产品的原 `MusterworkPptPreview` 可从静态预览进入播放。播放由产品自己的 Worker、时钟、画布和读取权限驱动，计算调用[公共交付播放接口](delivery-playback.md)及公共 WASM SDK。没有把产品页面、权限、任务或存储迁入 MusterOffice。

1. 静态预览继续只读取清单及当前页面图像。进入播放时，沿原不可变内容引用和读取作用域，核对并读取交付 bundle 与资源；便携入口一次打包，上限 128 MiB。
2. 内核检查交付，返回精确 PPTX、字体、实际页序和页面请求。产品不解析私有上下文，也不推测字体或页面路径。
3. Worker 只保留播放需要的 PPTX 和字体字节，释放完整传入材料；选页重新准备对应页面，逐帧不重新读取交付、不重新上传字体。
4. 保留采样使用公开分步接口。产品每批工作后可让出执行；像素在 Worker 内转换成 Canvas 所需的直通 alpha 表示，以转移所有权方式返回。主页面显示像素，一次只等待一个计算请求。
5. 暂停、继续、重新开始本页、通用点击、翻页和退出由产品控制。换页以代次淘汰旧帧；退出、版本替换、作用域取消或组件卸载关闭对应 Worker。浏览器没有 Worker 退出确认，因此这里只声明调用终止并隔离迟到结果。

当前点击是页面通用输入，不能代表对象命中、超链接、完整主序列导航或媒体控制均已完成。页面尺寸在本次打开时固定；自适应重建、完整高级内容与大文稿资源验收继续实施。

## 固定材料和构建

产品新增独立的 `components/musteroffice/playback-lock.json` 和准备命令，固定公共包清单：

`721fc6cd584cce15a1b0ce266adf861712fbac1fc137adc7040f80e049cb45e1`

准备脚本复用原固定组件的路径、清单、长度和 SHA-256 校验。它不下载、不执行来源、不覆盖损坏缓存。Desktop、Web 和 Artifact Share 共用 Vite 插件；只有显式 `MUSTERWORK_MUSTEROFFICE_PLAYBACK=1` 的构建才提供播放来源并带入 SDK 资产。原 stable 工具和引擎未切换。

插件保留已验证字节，按原相对路径输出运行库、WASM 和 notices；不带示例或声明文件。实际最小页面和完整桌面前端构建均输出 42 个完全同摘要的 SDK 文件，共 17,898,282 字节。这是未压缩的候选浏览器材料，**不是** Electron 安装包、替换后体积差值或完整内核的发行尺寸。公共包仍为 `releaseCleared: false`。

实际桌面页面的 CSP 禁止主页面编译 WASM。初版集成在相同 CSP 下确实失败；现在主页面只读取和验证组件字节，转移到 Worker 后再编译、初始化。没有放宽桌面页面 CSP 或启用通用 `eval`。部署时还应分别检查 Worker 响应自己的策略；本地浏览器验证不替代正式服务器及 Electron 协议验收。

实际 Worker 测试执行产品同一份 Worker 入口，Node 只提供浏览器消息端口桥接；编译、交付检查和采样均使用真实公共 SDK。代码字节、交付及返回像素使用所有权转移。对照帧沿用上一阶段原生生成的文件，并再次核对原证据摘要；500 ms 的通用点击不构成动画效果验收。

浏览器装载[实际 Agent Loop](product-native-model-flow.md)提交的两版不可变材料，沿实际产品 Vue 组件和内容读取函数运行。测试只替换 loopback 内容传输，未建立新的真实登录会话。首次预览为 2 次内容读取，进入播放后为 15 次；连续采样、点击和翻页仍为 15 次。换版本时旧 Worker 已调用终止，重新播放再关闭后累计创建 2 个、终止 2 个；最终浏览器错误日志为空。

自有样本采用原创合成字体，截图中的三角形字形是输入内容；它不是业务模板、字体质量或视觉设计验收。浏览器帧计数和命令完成时间不作为 FPS、延迟或内存性能报告。

连续点击回归先复现旧队列的时间序列 `0, 10, 30, 50, 40`，再修正为在输入到达时取时间，得到 `0, 10, 20, 30, 40`。没有通过允许时间倒退来放宽内核约束。失败日志、CSP 失败及最终成功证据分别保留。

所有记录命令执行前后来源一致；汇总脚本再次核对 1,778 个来源文件、两个构建的 SDK 资产、8 个原生参考帧及留存浏览器状态。复核入口为 `tools/verification/product-playback-evidence.py`，使用显式产品目录及新的输出文件，避免覆盖历史证据。
