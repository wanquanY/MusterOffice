# 椭圆渐变的有界首次交点计算

2026-09-25。本阶段延续 [WPS 焦点校准](radial-gradient-calibration.md)，实现独立 C++ 标量计算核，并用实际 Native、WASM、ASan/UBSan 构建验证。**尚未接入 Skia 绘制阶段、Rust 场合同或来源页面**。不能据此声称径向页面、Office/WPS 互操作或 Musterwork 替换完成。

## 语义与职责

`components/skia/mo_elliptic_field.{h,cpp}` 只接收归一化几何，不访问 Skia、字体、图片、文件或宿主，也不分配堆内存。外圆中心为零、半径为一；内椭圆中心为 `c`、轴半径为 `s >= 0`。参数 `t` 从零到一时，中心是 `(1-t)c`，轴半径是 `(1-t)s+t`。

返回像素 `q` 首次属于闭椭圆的参数。已在内椭圆中返回零；整个区间都未进入则返回截断值一。这个标量模型来自上一阶段的有限应用观察，仍是开发语义，不构成任意 DrawingML 文稿的兼容性承诺。

计算域是二进制 float32 输入：`|q.x|, |q.y| <= 1`，中心分量绝对值和轴半径不超过 32768。源码到这些参数的转换误差、页面放置、色标、像素覆盖和颜色插值不属于本接口。

## 为什么不能直接二分

椭圆不一定逐层包含。已验证的反例在 float32 输入下有三个不同的实交点：

```text
q = (-0.9187984697040693, -0.32614082270717)
c = (-0.9715088489324577, -2.0813371009894306)
s = (0.02605792474208458, 1.8864963402571122)
```

独立精确 Sturm 参考证明 `[0,1]` 内有三个根；当前实现返回第一个根附近的 `0.0304546058`，区间包含该根，且之前没有根。不能把“外圆包含像素”或少量样本中的单调变化当作普遍证明。

## 计算方法与误差边界

边界方程为：

```text
Ax(t) = qx - (1-t)cx      Bx(t) = (1-t)sx + t
Ay(t) = qy - (1-t)cy      By(t) = (1-t)sy + t
P(t) = Ax² By² + Ay² Bx² - Bx² By²
```

`t>0` 时两个轴半径都为正，故该四次多项式与椭圆边界等价。点/线焦点在 `t=0` 单独作几何分类，必要时消去分母引入的 `t²` 因子；等轴内圆消去共同的正半径平方因子，降低到二次式。

多项式使用带向外舍入区间的 Bernstein 系数。乘积保留六倍系数，避免除六引入额外表示误差。左侧优先的 de Casteljau 分割先排除更早的区间，之后才接纳根。只有能证明单一符号变化时，才运行最多 16 步的受限 Newton 候选计算；候选还必须通过两端区间符号检查。二次式的重根仅在判别式被证明精确为零时直接计算，不以阈值将近根合并。

成功的边界结果包含 `lower/upper`，同时包住第一个根和返回的 float32 值，宽度不超过 `2^-23`。这是**相对于输入 float32 的标量界**，不是源文稿几何误差、Office 差异或最终像素颜色界。代码中的论证与独立参考验证不等于机械形式化证明。

算术依赖 IEEE binary64、最近舍入、渐进下溢及关闭浮点收缩/fast-math。编译时检查表示格式并拒绝 fast-math。误差自由加法与 Dekker 分解恢复舍入方向；插值的 `1-t` 也单独包围，不能把任意 Newton 参数的减法视为精确。

每次最多访问 512 个区间节点，最多分割 24 层，固定栈最多 25 个节点，无递归。宿主可进一步降低节点预算。不能分辨的边界返回 `Precision`，预算耗尽返回 `Limit`，非法输入返回 `Invalid`；不会把未验证候选当颜色坐标。将来接入绘制时必须传播这些状态并禁止发布部分图像，不能忽略状态只读取数值。

算法依据：[Sharma 博士论文中 Bernstein 形式的 Descartes 根隔离](https://cs.nyu.edu/exact/doc/sharmaThesis.pdf)、[Rump 的浮点验证方法综述](https://www.tuhh.de/ti3/rump/intlab/ActaNumerica2010.pdf)。实现为本仓库新写的有界数值代码，没有迁入这些资料的实现或引入新的第三方依赖。

## 实际验证

入口：`tools/verification/elliptic-scalar-checks.py`。测试桥只批量调用实际 C++ 核，不复制求解逻辑。Python 参考独立构造精确有理数幂基多项式，通过 Sturm 序列判断根数及首根所在区间，不从本实现读取预期系数或使用截图探针的采样搜索。

- 1,238 个调用：1,230 个成功，1 个保守精度诊断，5 个非法输入，2 个预算诊断。
- 成功用例全部通过精确分类/根区间检查；838 个使用通过验证的候选路径，最多实际访问 45 个节点。
- 覆盖偏心、非等轴、外部焦点、点/线/区域、外扩、亚正常数、极大参数、多个交点、精确重根和重根两侧的 float32 邻值。
- Native、WASM、ASan/UBSan 的状态、分类、数值区间、工作计数逐字节一致。
- 4,005 组独立算术输入验证加法、乘法、插值，共 12,015 项精确有理数包含关系，三端结果相同。
- 有效但过于接近内边界的用例明确返回精度诊断；不能将成功率解释成完整渐变已支持。

本阶段没有改 Rust、Schema、既有源页面或组件 ABI；上一阶段的 611 项 Rust 测试和 82 份合同是历史结果，不写成此次重新运行。旧源文件和既有组件产物通过摘要核对，新求解核尚未链接进现行产品模块。
