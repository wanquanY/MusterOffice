# 原生表格能力同步到 Musterwork

2026-09-29。承接[表格跨帧复用](table-retention.md)，在[既有独立 worktree](product-worktree.md)同步 Rust SDK、原生导出 Worker 和 WASM 播放包。此阶段把已实现的表格能力接入原有产品调用链路；完整一期及 PPT 替换验收仍在进行中。

## 接入与验证

产品仍通过公开 SDK 和原有适配器消费内核，不增加表格专用宿主接口、渲染器或前端表格模型。源码包按固定 manifest 准备，Cargo 使用对应目录；导出 Worker 和播放包分别固定摘要。产品只修改材料锁定、Cargo 路径及锁文件，并增加新版本的 SDK 源码。默认工具发行与引擎没有切换。

首次独立消费编译拒绝旧锁文件：表格模型现在引用已经存在的 `thiserror`。离线重新解析后，两个锁文件都只增加了该内部依赖边；外部包的名称、版本、来源和校验值逐项保持。随后恢复 `--locked --offline` 编译，没有通过移除检查接受未固定的依赖。

五份自有原生文稿分别覆盖表格移动、圆形渐变移动、透明度、隐藏及原隐藏表格显示。公开导入生成来源快照，独立 SDK 消费端通过实际导出 Worker 创建交付，产品播放 Worker 再消费该交付。五份导出的 PPTX 与输入逐字节相同，保留原生表格、合并格、文本、渐变和时间树；这证明当前链路的来源保留，不代替 Office/WPS 编辑往返。

每份交付先由原生计算得到五个时刻，共 25 个参考帧。实际产品 Worker 完成 55 次表格采样，包括错误输入拒绝后的继续采样、重新选页与重播，全部像素对应参考。固定的两份旧路径文稿另完成 34 次历史帧对照，原产品版本 1／2 的两页文稿完成 8 次帧对照。后者继续通过真实产品读取函数验证材料并转交 Worker；账户与材料来自既有自有测试配置，不代表新的真实用户会话验收。

164 项功能测试通过：独立 SDK 作者序列 1 项、产品 Rust 适配器 19 项、客户端 117 项、查看器 7 项、材料准备 18 项及旧路径回归 2 项。Vue 类型检查及启用候选播放包的桌面前端构建通过。来源、命令、失败修复、材料与最终结果见[阶段证据](../reviews/evidence/2026-09-29-product-native-tables-verification.json)。

## 继续验收

完整表格边框冲突、更多画笔／描边、自动行高、完整变换及外部应用编辑往返仍未完成。动画转场、音视频、SmartArt、公式等一期完整内容、真实 Agent／Electron 会话、跨平台、历史迁移与 P00／E0／E1–E3 仍需分别完成。合成字体仅用于确定性测试，没有使用系统隐式字体，也不构成中文或商业字体质量结论。

接入产品拥有交互、权限、文件与存储；MusterOffice 继续只提供文稿计算和薄接入。本次全部产品写入、构建及验证均在 `codex/musteroffice-integration` 独立工作区，原主工作区由用户使用。
