# 原生淡入淡出与产品接入

2026-09-28：淡入、淡出的透明度计算、原生多行为预设、可编辑 PPTX 读写及作者／来源页面绘制已贯通。独立 Musterwork worktree 同步升级公共 SDK、导出 Worker 和播放包，并通过实际产品 Worker 验证。完整一期目标保持进行中；此阶段不代表所有动画、Office/WPS 互操作或产品替换验收完成。

后续进展：[背景快照范围](snapshot-scopes.md)补齐了输出画布与透明组的显式捕获语义，并升级产品材料。本文保留 Fade 阶段的验证及材料记录。

## 同一时间图中的行为与预设

`Effect::Fade { target, transition }` 提供 `in`、`out` 两种方向。时间图沿用已有精确时钟，涵盖重复、速度、加减速、自动反向、填充、导航和重新采样；`FrameState.opacity` 使用有界精确分数。多个行为作用于同一对象时，透明度拥有独立属性通道，按既有激活时刻和文档顺序选择，不覆盖旋转、缩放或可见性。

单个 Fade 行为只负责透明度。Agent 使用 `setPresentationSequence` 创建有放映语义的预设，编译器生成同一原生效果组中的两条行为：

- 淡入：开始时设为可见，同时执行 0 → 1 的透明度变化。作为对象的首个入场效果时，播放初态隐藏该对象。
- 淡出：执行 1 → 0 的透明度变化；在有限活动区间的最后 1 ms 设置隐藏。短于 1 ms 的行为使用自身完整区间；无限重复没有终点，不臆造隐藏时刻。

后一个批次仍依据包含重复与速度的完整活动时长安排。辅助行为参与节点预算、身份去重和取消；不在宿主存储第二套动画状态，也不要求 Agent 逐帧调用。裸 `setTimeline` 不会自动添加上述入场初态或辅助行为。实际操作说明同步于 [Agent Skill 参考](../../integrations/skills/musteroffice-presentations/references/advanced-content.md)；这不表示已发布新的产品内置 Skill 版本。

## 原生格式和对象整体绘制

Reader／Writer 使用 `p:animEffect filter="fade" transition="in|out"`；预设身份为 `presetID=10` 与 `presetClass=entr|exit`，包含对应可见性辅助行为。Reader 检查预设的行为顺序、数量和目标一致性，未知过滤器及自定义 progress 等载荷明确报未支持。

自有 WPS 文件的 Fade 行为省略 start、fill 和属性名列表；当前读取将这一已验证的有限 Fade 形式规范化为零开始和 Remove。该处理不推断其他行为的缺省属性。[Open XML AnimateEffect 文档](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.presentation.animateeffect?view=openxml-3.0.1)描述了过滤器及归一化进度；当前实现没有据此宣称支持任意过滤器或进度曲线。

页面编译将对象及祖先组合的透明度降低为连续绘制区间，再使用[隔离透明合成](opacity-groups.md)。一个对象的填充、描边、文字轮廓和图片先完成内部绘制，再整体合成；重叠区不会因逐画笔乘透明度而改变。嵌套组合保留各层作用顺序。精确分数仅在光栅边界舍入到 0–65535。

透明度变化不改变几何放置；来源播放仍复用已准备的图片、文字和本地几何。隐藏对象保留资源身份，恢复时无需重新取得或解码资源。计算核心没有增加 UI、权限、网络或持久存储。

## 本阶段验证

[验证记录](../reviews/evidence/2026-09-28-fade-native-verification.json)固定了源码、生成合同、材料及测试输出摘要：

- 503 项相关 Rust 测试通过，包括新增的 9 项精确 Fade、复合预设、原生读写、嵌套绘制、资源复用和非法输入测试。严格 Clippy、格式、Schema／TS 生成与类型检查通过。
- 15 个作者帧和 42 个来源帧通过原生执行，并分别通过公共 WASM 包的同步、分步 Worker 路径逐像素及元数据核对。包含自有 WPS 文件、图片、文字、组合、前后导航与逆序采样；彩色矩形内部像素另有独立透明合成期望值。27 个 PresentationML 部件通过 XSD 校验。
- WPS 实际打开内核导出的两组效果后，仍提供可编辑的淡入／淡出预设。将入场时长从 0.5 s 改为 1 s 并保存，内核回读后的 11 个精确时刻符合修改结果，出场时长保持 0.5 s。这是自有样本的编辑往返证据，不是 PowerPoint 或任意动画文件的验收。
- 独立产品 SDK 消费者生成真实交付，12 个原生参考帧进入产品测试；实际产品播放 Worker 完成 19 帧导航、后退、重播对照。公共接入准备、SDK 消费者、适配器、客户端及查看器合计 158 项测试通过；Vue 类型检查和完整桌面前端构建通过。

最终原生产物重建后更新了导出 Worker 摘要，并重新生成原生及产品参考；播放包重建字节保持。早期测试脚本的编译错误、二进制版本偏移的误读、输入生成与读取竞态、ZIP 时间戳导致的样本身份变化均保留记录。ZIP 生成现已固定时间与部件顺序；没有删除校验或改变生产语义来获得通过。

## 继续实施的缺口

非恒定的幻灯片背景填充使用背景快照。当前快照要求在同一最内层透明组内取得和使用，尚不能正确表达从外层背景取得快照、在对象内部使用的语义。带此类填充的动画对象不在本次已验证范围内；需要补齐明确的捕获范围和边界时机，不能静态化或改画笔绕过。

任意原生过滤器、自定义进度、多种高级动画与转场、音视频、SmartArt、公式，以及任意节点依赖的外部编辑往返仍属于完整一期任务。WPS 此次可编辑性证据不替代精确中间画面、PowerPoint、多平台与完整 Agent／Electron 流程验收。历史迁移、性能、内存、正式安装体积及 E0–E3 门禁继续开放。
