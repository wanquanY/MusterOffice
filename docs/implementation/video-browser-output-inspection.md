# 浏览器导出候选的共享检查

状态：计算层已实现；产品持久任务和发布接线仍在进行，不能以此宣布成片交付完成。

`mo-video-export::inspect_browser_candidate` 使用现有 `mo-media-isobmff` 有界索引，比较不可变 ExportPlan 配置与真实 MP4 的电影时钟、视频/音频轨道、逐包时钟、尾帧、单段单位速率 edit、编码 priming 和剩余 padding。只接受已验证的 `H264WebCodecsAacMp4` 有序 AVC 档案，不扩大为原生重排 AVC。返回准确的视频抽样位置，调用方仍须实际解码、核对 codec/尺寸/颜色/音频布局及已关闭文件的完整摘要。

`ProjectExport.inspectCandidate(length, readAt)` 是上述计算的 WASM 入口。只接受有界只读字节能力；不持有路径、任务、账户或文件发布权限。产品将新组件作为不可变清单安装，不修改已安装组件。此方法不依赖编码会话已经完成，允许刷新后重新编译同一工程与参数、验证已封存候选。

边界：这是发布前的有界结构与时钟门禁，并非所有帧/音频的质量证明。独立完整解码与质量测试另外执行；没有将抽样解码包装为全片验证。

本批证据：

- `mo-video-export` 12 项测试通过，包括分数帧率、短尾、显式 AAC priming、19 组时钟/包/轨道损坏、配置范围、档案和取消拒绝。
- 相关导出与 WASM 包 strict Clippy 通过（新增诊断示例另随最终提交复核）。
- `inspect_candidate` 诊断宿主读取 Musterwork 实际生成的两秒 B/VFR 源素材正放/倒放成片，返回 60 帧、96000 音频样本及 `0, 1, 59/30` 秒抽样位置。
- 产品独立 FFmpeg 门禁完整解码立体声、单声道、无音轨三种真实成片，电影/轨道/逐帧时钟正确。两种音频最佳对齐偏移为 0，误差不高于同码率参考 AAC。该证据不宣称像素等价或产品 UI 已验收。

诊断入口：`cargo run -p mo-video-export --example inspect_candidate -- CONFIG_JSON MP4`。参数是 `EncodeConfig`，命令不发布文件。

后续产品宿主必须以固定版本、原始导出意图和组件摘要为依据，独立关闭后回读/hash，保存验证结果，以单个持久事务提交正式文件和任务完成状态。取消、旧执行 epoch、失效身份及验证失败不得得到完成回执。既有 `v0.1.0` 稳定回滚基线不变。
