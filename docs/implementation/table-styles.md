# 原生表格样式来源与声明选择

2026-09-29，接续[网格与文字范围](table-geometry.md)，增加原生表格样式目录、内联样式及按单元格选择声明的共享计算。此阶段不代表表格文字排版或页面渲染完成，Musterwork 产品材料继续保留上一验证版本。

## 来源与所有权

[样式模型](../../crates/mo-presentation-source/src/source/table/styles.rs)保留 `tableStyles` 部件的地址、摘要、默认插入 ID、物理元素序号、MCE 分支记录和未解释内容。Presentation 关系必须唯一、指向内部完整部件且内容类型正确。目录键归一化 GUID 大小写，声明自身保留原拼写；这是容忍原文件大小写的读取行为，不表示小写 GUID 满足严格 XSD。

内联 `a:tableStyle` 与目录 `a:tblStyle` 使用[同一流式读取器](../../crates/mo-presentation-source/src/source/table/styles/read.rs)。13 个条件区域、背景、文字字体和颜色、填充及 8 类边框复用既有 DrawingML 类型；背景效果复用效果读取器，节点留在所属样式目录，不混入页面的物理序号空间。字体集合保留三个脚本字体和有序补充字体；字体引用允许没有颜色。未声明、显式 `def/on/off`、空声明和 `fontRef none` 均分别保留。

样式数、元素和属性字节在整个文稿内累计，与内联表格、共享样式部件共用预算；填充、线条、效果另受各自原有预算约束。底层 XML/MCE 遍历检查取消。未知内容绑定到样式、背景或所属区域，避免一个未启用区域的扩展阻断另一格的文字声明选择。单元格 3D 此时仍保留为未求值声明，不能算作已渲染能力。

原生文字编辑继续修改真实 XML 叶子；其他部件和样式字节保留。作者模型尚未产生的内联样式在原生作者写出路径上被明确拒绝，不能静默丢弃；来源保留路径不受此限制。

## 选择规则与复用边界

[借用式选择器](../../crates/mo-presentation-source/src/source/table/styles/select.rs)每表绑定一次显式样式 ID 或内联声明，不把 `tblStyleLst@def` 当作已有表格缺失引用的替代。缺失定义、矛盾内联/引用、无效身份均有错误；尚未实现的内置样式不能自动替换为无样式。

每格使用已验证网格中的物理地址，最多检查 13 层，常量大小存储，不复制样式或反复扫描整表。条件声明依照微软 [MS-OI29500 §2.1.1265](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/90de4085-5fbf-47a7-bc37-d59509481d0a) 的 DrawingML 顺序选择。字体、颜色、粗体和斜体逐项保留实际区域及原生序号；`def` 延续父层，显式关闭可以覆盖父层。对象本身的文字格式、主题字体和颜色解析仍由下一阶段消费这些结果。

条件区域成员规则当前属于待应用验证的计算配置：启用的首末行列不参与同方向条带，条带从正文首行/列开始交替；列地址按原生声明顺序解释，RTL 位置由几何层负责。合并边界、RTL、单行/单列表格的最终视觉，以及区域交叉时条带与直接格式的全部组合，仍需实际 Office/WPS 对照。Rust 测试是当前计算规则的证据，不能替代该互操作验收。

## 验证与后续

[读取测试](../../crates/mo-pptx/tests/table_styles.rs)覆盖目录/内联两条真实 PPTX 路径、13 类区域、8 类边框、字体/颜色/效果、MCE、非法结构、身份关系、累计预算、取消和文字编辑保真。[选择测试](../../crates/mo-pptx/tests/table_style_selection.rs)覆盖逐项来源、显式默认/关闭、区域重叠、单格退化、缺失定义、网格绑定、未启用扩展隔离和取消。

Native/WASM 来源读写、生成 Schema/TS、独立 XML/XSD 读回及相关回归的实际结果记录在[阶段证据](../reviews/evidence/2026-09-29-table-styles-verification.json)。声明选择目前是 Rust 库计算；跨端来源测试不应被描述为它的公共渲染验收。

416 项相关 Rust 测试通过，新增读取/选择测试 13 项；间接持有可选样式目录的内存布局调整后，受影响的 24 项测试及严格 Clippy 再次通过。工作区编译、Schema/TS 同步、原生和 release WASM 构建通过。4 份带样式文稿完成 20 次跨端来源对照，独立检查 36 格、806 个声明位置、26 次 XSD 与 20 次 JSON Schema；原有 11 份表格的 55 次来源对照、14 次作者请求和独立读回亦通过，导出与编辑后文件摘要保持不变。

下一步保留原始对象与单元格文字作用域，把所选字体/颜色及直接 run 格式接入现有文字编译器，落实内边距、裁剪、行高和边框，再贯通共享页面、Native/WASM 像素及 Office/WPS 验证。随后在[既有独立接入 worktree](product-worktree.md)统一升级 SDK、导出 Worker 和播放材料，继续完整一期及替换验收。内核不新增页面、权限、持久存储或产品任务职责。

后续实现：[单元格文字计算](table-text.md)已沿真实单元格范围接入声明级联、字体和颜色及共享段落引擎。该阶段仍未完成表格页面绘制和外部应用验收，具体边界以其证据为准。
