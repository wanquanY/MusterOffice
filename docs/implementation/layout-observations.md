# Agent 可定位的文本布局观察

状态：已实现并通过局部测试；不代表完整视觉验收或 Office/WPS 互操作通过。

真实 Agent 验收暴露了证据与修正之间的缺口：内核的预览证据已记录第三页文字超高，但接入工具只返回质量声明和文件引用，模型没有拿到可直接定位的诊断。详见[实际模型验收](live-agent-acceptance.md)。

`delivery::inspect` 在核对真实文件、预览、渲染计划和测量覆盖后，为 `ReceiptInspection` 增加可选的 `layoutDiagnostics`。Native SDK、CLI 和 WASM 使用同一实现；产品只投影报告，不再次实现排版、对象编号或尺寸计算。旧报告可以不含该字段；历史预览没有测量时明确计入 `unmeasuredPages`，不解释为没有问题。

## 诊断语义

- 每个受影响文本框带页 ID、从 1 开始的页序号、证据资源 ID、原生部件/对象地址和可定位时的模型 `objectId`。表格保留物理单元格地址。
- `capacityExcessEmu` 是包括行距和段落间距的内容高度超额，可能没有字形越界。
- `inkExcessEmu` 分别记录字形轮廓越过文本内部区域的左、右、上、下距离。悬挂标点和正常字形外伸也可能产生该数据；它不是裁切或对象重叠的裁决。
- 同时提供内部宽高、内容高度、行数、横向溢出行数和紧急断行行数。长度为向上取整的十进制 EMU 字符串，12700 EMU 为 1 pt；正数不会被舍入为零。精确 Q32 原始值仍留在对应预览证据中。
- 摘要遍历全部已测文本框，仅返回按页和绘制顺序排列的最多 32 个受影响项且条目 JSON 总长不超过 24 KiB；`affectedFrames`、`omittedFindings` 保留完整计数。截断不等于后续页面正常，修改后应重新导出检查。

原生对象地址来自此次实际构建的 `PresentationPlan`。新文稿复用计划的原生编号和部件声明；导入文稿复用已验证的 `sourceBindings`。不根据形状名称猜测对象，不在接入产品重写编号算法。

没有诊断项也不证明布局质量。该报告不自动修改字体、缩小文字、裁切内容或改变质量声明；最终视觉、文件编辑和目标应用验收仍独立进行。

## 局部验证

28 项 delivery 测试覆盖原生/导入对象定位、行距与字形溢出区分、历史未测页面、条数和字节双重截断、取消、亚 EMU 数值保留及数值越界拒绝。严格 Clippy 和生成类型检查通过。

对同一真实 Agent 的两版三页 PPTX，读取全部 13 个交付资源并核对摘要后，Native/WASM 完整响应一致，均识别到 3 个已测页面、12 个文本框和 6 个需检查项。第三页第一张流程卡的字形底部越界为 583002 EMU；封面标题仅行高超额而字形未越界。原来的四项 `not_proven` 声明保持不变。私有输入、字体、凭据和个人路径不进入公开证据。

产品接入与模型自主修正需要另行验证，不以本报告回放代替。

## 实际页面文本重叠候选（2026-09-30）

Skill 12 的真实模型试验将第三页正文上移，虽然单框溢出归零，却与标题重叠。
因此增加 `textCapacity.pageInk` 与 `layoutDiagnostics.textOverlaps`：前者来自实际
非透明字形轮廓，后者只比较这些测量，不使用形状容器外框猜测文字占位。

绘制时汇总字形局部包围范围，通过同一原生放置变换映射到页坐标，包含旋转、翻转、
组合与数值误差界。播放复用已缓存字形，但每帧按当前采样位置重新放置测量；不会沿用
移动前的坐标。表格以物理单元格区分。无填充、全透明或无轮廓文字保留测量记录，但无
可见字形范围；历史报告缺少 `pageInk` 时计入未测页面。测量覆盖必须与实际文本框匹配。

两个范围仅在有正面积相交时进入候选，边缘相接不算相交。报告携带两个真实对象 ID、
来源地址、单元格、裁剪标记、误差上界及相交宽高。范围包含字间空白，且在裁剪和图层
遮挡之前采集；旋转后的轴对齐包围框、刻意重叠也可能产生候选。因此它不是像素碰撞
裁决，也不自动修正文稿或升级质量声明。

一次检查最多比较 1,048,576 对，最多返回 16 对且条目 JSON 总长不超过 12 KiB。
`checkedPairs` / `uncheckedPairs` 明确工作覆盖，`intersectingPairs` / `omittedFindings`
保留已检查部分的命中与截断数量；未检查部分不能宣称没有相交。原单框诊断仍独立受
32 项 / 24 KiB 限制，两组条目合计最多 48 项 / 36 KiB，另加有界摘要与 JSON 分隔符。
全部路径支持取消。产品继续只投影 SDK 结果。

### 验证证据

124 项编译/交付、23 项真实字形/页面、97 项 API/操作/SDK/文件桥测试通过，严格局部
Clippy、生成 Schema 与 TS 检查通过。旋转/翻转/组合测试以实际着色像素验证测量范围；
透明、裁剪、表格、隐藏/播放移动、历史未测、异常覆盖、条数/字节/比较上限均有回归。

对真实模型生成的三页文稿，完整导出检出第三页三组标题—正文候选，前两页没有候选。
通过 SDK 原子编辑移动三个正文并扩大三个卡片，文字、字号与其余内容完全不变；重新
导出后 58 对均检查、重叠候选为零。查看真实第三页预览确认标题与正文已分离。修复前后
两个交付包的完整验收响应、六页实际 PPTX 重新渲染的测量与全部 RGBA 字节 Native/WASM
一致，共比较 22,118,400 字节像素。通用复测入口为
`tools/verification/computed-delivery-parity.mjs`，输入由调用方指定，私有字体不入仓库。

这次修复由工程验证脚本调用公开 SDK 完成，尚不证明模型能自主修复。新的 SDK、Worker
和播放包已准备，产品激活及真实模型复测另行记录。证据摘要见
[验证清单](../reviews/evidence/2026-09-30-text-ink-overlap-verification.json)。
