# 容器结束与因果生命周期

状态：容器结束条件已进入共享时间模型、原生读写与编辑依赖，本阶段构建及公共入口验证已完成。完整容器变速、重复激活、重启与完整演示内核继续推进。

## 调度职责

此前的时间 DAG 同时承担引用依赖和祖先截止：子项开始依赖最近固定祖先的结束。加入“父项结束由子项开始触发”后，这种前置依赖会错误地形成循环。本阶段移除该耦合，编译阶段检查结构所有权与显式事件依赖，运行阶段通过有界事件队列处理实际开始、结束与作用域关闭。

平面图和分层树使用同一调度器。队列按精确时间、输入事件序号、结束／开始类别及稳定插入序处理；同一因果时点已经排定的结束优先于待启动项。因某个子项真正开始才触发的零延迟父项结束，可以保留该子项的瞬时区间，然后关闭其余未启动子项。没有为了复用旧算法给父子引用增加禁止规则，也不展开成一组绝对时间叶子。

队列耗尽后得到当前完整事件前缀所能确定的区间，包含已声明的未来时间；它不读取未来输入点击，不等待真实墙钟，不按帧或重复次数步进。采样随后使用同一组区间、行为时钟和可见作用域，保持 seek 可重算。未来的真实点击仍可能改变此前尚未确定的结束和后继预测。

每个条件、事件入队、通知和树遍历都有取消检查。新增 `TimelineLimits.max_schedule_steps`，默认 1,000,000，限制本次调度工作；原有节点、条件、输入事件、精确算术位数与树深度预算保留。工作耗尽返回诊断，不发布部分状态或画面。

## 关闭作用域

容器结束先关闭整个子树，再传播实际结束事件。已经活动的后代取得实际截止；尚未开始的后代被取消，不生成伪造的 begin/end。后代的结束可以触发作用域外的行为，已经关闭的作用域不能由此重新启动内部兄弟。

自然结束与祖先截断仍分别保存。自动容器的 endsync=all 等待所有子项自然完成；未触发的子项使该自然结束保持未知。显式结束或祖先终止可以提前关闭它。在同一事件导致父子同时结束时，先结算结束引用，再归纳自动容器的自然完成，避免把正常结束错误归类为祖先截断并改变 fill。

有限行为的反向起点继续取自身活动区间，祖先截止不擅自缩短定义；无限倒放可由有限祖先结束提供范围。自然结束后 remove、freeze、hold 与祖先提前结束时的保留规则继续由共同采样层处理，不在 UI 中补偿。

## 数据、文件与编辑

`TimingContainer.endConditions` 与行为叶子共用 `TimeCondition`：at、after、click。空数组省略，已有文稿 wire 和摘要不因默认字段而变化。条件数预算包含容器开始和结束；对象目标、时间节点引用和负偏移进入同一检查。

原生 `p:par`／`p:seq` 的 `p:cTn/p:endCondLst` 现在与叶子共用解析和写入。列表位于开始列表之后、endSync 和子项列表之前；保存条件顺序、精确 unsigned 毫秒、页面／对象触发目标和原生时间节点 ID。空列表、未知事件、重复／乱序内容及不可精确表示的时间仍明确拒绝。

原子编辑依赖包含容器结束目标及其时间引用。删除被用作停止按钮的对象时，拒绝策略保留原文稿；级联策略删除该容器、所有结构后代和传递事件依赖，不能把子项提升到另一个时钟作用域。合法空计时容器仍按既有规则保留。
