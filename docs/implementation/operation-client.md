# TS 操作与资源客户端

本阶段把既有 Rust 操作合同连接到可注入宿主的 TS 客户端，源码见 [operation-client](../../packages/operation-client/README.md)，实际验证见[阶段证据](../reviews/evidence/2026-09-26-operation-client-verification.json)。它是 SDK 的控制与资源层，尚不是完整 SDK、生产传输适配器、浏览器执行宿主或 Musterwork 集成包。

## 实现与责任

`OfficeClient` 提供统一分发、类型化结果、提交、任务查询、显式取消与有限等待。输入输出复用 Rust 生成的 `HostRequest/HostResponse`；注入的 `OperationPort` 必须先按生成合同验证传输数据，再返回类型化响应。客户端检查任务关联和终态回执，不以 TS 类型断言替代 wire 校验。

等待超时或 `AbortSignal` 只结束本地等待，保留业务 requestId/jobId；不会自行取消业务、重试修改或生成新幂等键。迟到的响应和拒绝均有观察者。显式 `cancelJob` 才进入宿主业务取消路径。等待遵循宿主轮询提示和有限时间预算，不新增持久队列。

`ResourceClient` 使用注入的不可变字节源，按宿主已提交偏移顺序上传一个有界分块。确认回执丢失后，调用者使用原 requestId 和原内容重试，从宿主确认的位置继续；封存校验由宿主执行。uint64 偏移在本地保持 bigint，协议中使用规范十进制字符串。默认客户端块预算 256 KiB、单资产预算 1 GiB，均不取代宿主配额。

下载可绑定固定交付清单中的摘要、长度和类型，核对后才创建私有输出。写入有背压；封存后从最终存储重新读取字节并计算 SHA256，释放验证读取器，最后返回私有引用。空资产也校验。私有写入、封存和读取实际结束后才执行清理，避免本地取消造成迟到 I/O 与删除竞争；原始失败和清理失败同时保留。宿主需保证注入回调有界或可协作终止，SDK 不能强行中断任意回调。

客户端不导入 Node、文件或网络 API，不创建身份、数据库、执行进程或提交权。Musterwork 的 Embedded 接入仍必须映射现有 Invocation、权限、Content Store、任务和原子 Artifact 提交；不能给产品增加第二套独立 SQLite owner。验证目录中的原生驱动仅为 Standalone 集成测试工具，未作为生产传输交付。

## 实际验证

17 项专项测试通过，覆盖迟到失败、局部等待取消、有限超时、任务串号、缺失成功回执、丢失上传确认、精确大整数偏移、最终存储损坏、空资产以及私有输出各阶段取消与清理。大整数用例使用模拟字节源，不是超大文件吞吐或内存测试。生成类型与全部 TS 项目的严格类型检查通过。

macOS arm64 / Node v23.5.0 下，客户端对冻结的真实原生宿主执行 37 次控制调用及 22 次二进制调用：创建两页文稿、修改标题、读取历史版本、幂等重试、上传图片和字体、实际预览/PPTX 导出、读取全部 12 个交付资产，再重启宿主核对同一回执。跨 scope 下载在创建私有输出前失败。

额外 786,469 字节资源真实落库后人为丢弃第一次 append 回执；重新开始上传后实际 append 偏移依次为 0、262144、524288、786432，没有重复追加已提交块。随后完整下载并校验。数据库独立检查确认三项成功任务、两个文稿版本、一个文稿头及已封存上传；没有因本地等待或重试而产生额外业务取消。

独立 Python 验证器对实际请求/响应与交付清单执行生成 Schema 校验，对最终 12 份文件核对长度/摘要。实际 PPTX 中十个相关 XML 部件通过锁定的官方 XSD，包含 15 个原生对象和八段文字；另一 PPTX 读取器识别两页。两张 640×360 PNG 通过像素探针，完整像素摘要与此前 MCP 的同内容页面一致。交付质量声明仍仅将结构标为通过，布局、原生编辑、播放和目标应用四项保持 `not_proven`。

## 体积与未完成项

TypeScript 7.0.2 当前编译输出的七个 SDK JS 模块共 16,371 字节，七份自身声明共 8,108 字节；未压缩、未打包，没有新增运行时 npm 依赖。生成合同声明另行输出；上述数字不是完整 SDK、浏览器资源、内核发行物或 Musterwork 安装包体积，也不是吞吐/RSS/FPS 测试。

本阶段没有修改 Rust、组件、生成合同或依赖锁文件，复用已验证原生宿主与绘制 worker；没有重新声称全仓 Rust 或全部 Native/WASM 验收。生产传输与实时 Viewer/Player、浏览器 owner、Skill/Plugin、完整高级内容、Office/WPS 互操作、Musterwork 真实接入与 E0–E3 替换门禁继续开放。
