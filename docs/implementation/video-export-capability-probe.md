# 浏览器导出能力实测输入

2026-10-09。`ProjectExport.probeFixture()` 提供 `musteroffice.video.export-probe-fixture/1`：128×96、30 fps、0.2 秒的红/蓝两个色块，共 6 帧；48 kHz 立体声静音共 9600 个采样。只包含内核生成的文档、规范摘要和导出选项，不引用外部资源、不含宿主身份或文件路径。

该 API 只构造计算输入，不表示浏览器已有编码能力。宿主必须通过正式 GPU 合成、I420 转换、H.264 编码、共享 AAC/MP4 组件产生候选，实际写入本地存储，独立重新打开容器并解码画面/声音，随后回收临时文件与 Worker，才能声明基线导出可用。能力实测结果属于当前宿主环境；不能保存为用户工程、任务成功或付费模型结果。

小样本不证明其他分辨率、帧率、媒体类型、长时性能或所有浏览器平台。每个实际导出仍检查真实工程、输入、资源预算和编码配置。宿主同时负责登录/工作区变更、有限检测期限、临时资源回收；失败不能关闭独立可用的工程读取和编辑能力。

验证：`tools/verification/video-export-sdk-check.mjs` 使用真实公共 WASM，检查样本无外部资源、固定维度和精确调度；既有 4 组 Native/WASM 向量、239 步比较继续通过。`mo-video-export-wasm` 的编译与严格 Clippy 通过。这里不把样本构造测试当作实际浏览器编码证据；产品的真实浏览器检测另行验收。
