# 时间属性接入共享页面绘制

状态：原生旋转时间图的第一条实际绘制链路。采用既有 Rust 放置、路径编译、误差认证与 C++ Native/WASM 绘制组件，作者文档保持不可变。本阶段仍不能替代完整播放内核或 Musterwork。

## 一条计算路径

`PlaybackPagePlan` 持有一份已验证的页面请求、原始页面放置、不可变时间计划和播放版本绑定。每次采样先从显式演示时间与事件历史求出属性，再把旋转覆盖传入同一个 DrawingML 放置引擎。未被活动/冻结行为覆盖的对象使用作者值；移除型行为结束后恢复原始旋转，不将最后一帧写回文档。

静态页面与播放页面使用同一个场景 builder、形状几何、设备降低、精度预算和 raster backend。对象放置继续遵循已有的组合中心、非均匀缩放扇区和父级翻转规则，不将其换成通用仿射旋转相乘。没有第二套演示用渲染器，临时覆盖独立于作者文稿。

播放计划可由 Rust 调用方复用文档验证、摘要、时间图和无覆盖时的原始放置；目前有覆盖的采样仍重新计算放置、路径和场景降低。JSON 开发接口逐请求创建计划。完整保留式合成、仅更新受影响图层、WASM/宿主长期会话、媒体资源租约和显示调度仍待接入，不能用本阶段离线帧计算宣称实时性能已达标。

## 分数角度与误差

时间插值可产生非整数原生角度。共享引擎增加有界精确角度表示，整数角度保留快速路径；分数角度按精确有理数完成一圈归一化、象限/扇区判定和父级反射合成。合成先约去分母公因子，避免同一时间基准被重复放大。

分数角度最终转成向外舍入的 Q96 区间，并进入现有三角函数区间算法；输出 Q32 仿射矩阵及其误差界继续进入页面和设备预算。这里的量化有明确外包误差，不将播放属性取整到原生 1/60000 度网格。整数直角保持零误差路径，越过精确算术预算返回 `LIMIT_EXCEEDED`，不静默近似。

内部角度中间数预算为 8192 位，字符串在解析前也有限制。时间图仍使用上一阶段的独立预算。预算声明不等于产品支持容量；完整大文稿、深组合和实时负载仍需验收。

## 接口与原子结果

新增 `compile-playback-page` / WASM `compile_playback_page` 和 `render-playback-page` / WASM `render_playback_page`。请求由已有快照/时间求值输入、viewport 和显式画笔默认值组成，Schema/TS 继续从 Rust 生成。

公共入口验证快照语义摘要和播放 revision，在同一调用中求值和绘制，调用方不能直接注入未绑定的属性覆盖。编译响应附带时间状态、精确属性、放置、原始文档摘要与页面计划；绘制响应附带同一时间状态及实际场景/像素摘要。session/generation、事件游标和时间属于结果身份，宿主负责时钟、事件排序、版本权限及最终提交。

时间/版本错误与页面/组件错误保留各自类型。缺少事件历史、未实现绘制、数值或精度预算失败均不返回部分像素。组件调用后取消遵循既有 raster 生命周期：丢弃像素并使该组件实例失效；宿主后续重建组件。计算计划本身保持不可变。

Native CLI 通过已有隔离 raster worker 绘制，再核对元数据、字节长度和像素摘要，沿用不覆盖既有文件的原子发布。开发入口没有获得额外文件、网络或隐式字体权限。

## 当前覆盖与后续工作

当前实际播放绘制覆盖作者模型已实现的实体填充/描边路径和组合；动画属性为上一阶段的旋转行为。原生导入页面的图片、文字、渐变等更完整静态能力仍需接入动态属性；未实现的作者内容会明确拒绝，不能因为静态来源管线支持而宣称动态播放已支持。

后续继续连接来源时间树与资源页面、保留式放置/路径/字形与图层缓存、可复用宿主/WASM 会话，再扩展容器、多条件、文字与高级对象目标、其他效果、转场和媒体。Office/WPS 动画编辑和播放尚无本阶段新增观察，文件格式校验与自有帧结果不能替代目标应用验收。

## 本阶段验证与成本

665 项 Rust 测试、90 份同源 Schema/TypeScript 检查、严格 Clippy 和 rustfmt 通过。38 个公共输入分别编译/绘制，形成 76 次 Native/WASM 成对调用，其中 34 个成功采样帧逐字节一致；失败不产生像素。独立 Fraction 与 100 位精度参考检查 104 个对象的 1,040 个矩阵/锚点标量，均在报告的误差界内。4 个直角样本的 307,200 个像素与独立整数像素置换完全一致。回退 seek 和失败后恢复结果不变。

355 次旧静态绘制和 246 次旧时间接口调用与上一阶段冻结结果一致。实际 CLI 的不覆盖发布、失败不生成目标文件已验证。诊断拼图来自这些真实像素，不属于原生可编辑性或外部应用视觉验收。

当前 Rust WASM 为 7,170,320 字节，较上阶段增加 75,301 字节；C++ WASM 保持 2,370,691 字节。这是原始模块，不能推算完整安装包、字体或媒体依赖闭包。

局部性能条件：Apple M4 Max、arm64、Darwin 25.2.0、Node 23.5.0；320×240 自有形状页面；模块已加载；5 次预热后 25 次采样；本任务无同时构建/测试，其他系统负载未控制。公共 WASM 调用包含解析、快照验证、计划创建、时间/放置/路径/设备计算、绘制回调、元数据和像素传递。两种整数状态另用移除时间图且写入等价静态旋转的文稿作对照，并验证像素相同。
