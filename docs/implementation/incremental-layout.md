# 页面依赖与增量编译

2026-09-27 评审整改。此处说明当前静态作者页面的库能力，不表示完整交付、来源页面或时间采样已经复用这些缓存。

[`PageDependencies`](../../crates/mo-presentation-model/src/dependencies.rs) 保留声明的继承关系，收集页面、版式、母版、主题、组内对象、连接目标、字体和资源身份。标题、名称、无障碍说明、页面顺序和时间线不参与静态布局键；这些修改仍改变文档版本，并通过各自的变更字段报告。未知来源包的身份保守地影响全部页面，不根据未解析内容推断安全复用。

事务回执新增可选的 `invalidatedSlides`，报告需要重新计算的存续页及新页；删除页继续由 `deletedSlides` 报告。`invalidateAllLayout` 只在页面尺寸改变时为 true。历史回执缺少新字段时仍可读取；旧回执的全量失效标记不改写。

[`PagePlanCache`](../../crates/mo-presentation-compile/src/incremental.rs) 由调用宿主持有，按页面数与生成命令数限制保留量，按最近使用顺序逐出。键同时绑定上述依赖、绘图配置、viewport 和编译 profile。命中也执行语义校验和取消检查；不能凭调用方提供的 ChangeSet 绕过验证。复用的计划更新当前文档摘要，避免元数据修改后输出旧版本的来源标识。

该缓存复用静态布局和 scene 计划，不承诺省去完整文档验证、事务草稿复制、光栅执行或数据库工作；预算是逻辑页面/命令数，不是 RSS 测量。零预算关闭保留，失败计算不发布候选计划。

验证覆盖全量与增量计划的逐字段一致性、独立页面修改、主题/母版/版式/字体资源依赖、元数据变化、取消、非法文档与缓存逐出。没有据此宣称发行性能达标。
