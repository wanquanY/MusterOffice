# 原生表格读取与来源文字编辑

2026-09-29，在[原生表格基础](native-tables.md)上实现 DrawingML 表格来源投影、单元格文字绑定和保留式编辑。表格读取与导出可独立验证；共享表格渲染、样式级联及产品替换仍在实施。

## 声明与文字所有权

来源 `SourceObject.table` 保存 `a:tbl` 的物理网格、行、每个单元格、合并属性、表格与单元格属性。属性缺省和显式值保持区别；行高、列宽和四个独立内边距使用原生坐标类型，保留十进制单位精度。文本仍只有一个事实源：`SourceObject.paragraphs`。每格通过起始段落、段落数及文字根 ordinal 引用它，文字根另有表内行列地址。覆盖单元格仍有自己的文字；原生缺失文字体和存在的空段落分别表达。

表格、普通形状共用文字内容读取器。来源普通 run 的段落地址按物理单元格顺序展开，已有 `SourceTextTarget` 和 Unicode `SpliceText` 无需第二套寻址协议。样式、填充、六向边框及效果图复用已有解析器；表格元素、属性和单元格预算跨文档表面累计，文字/线条/填充沿用全文件预算与取消检查。

已知属性仍是原生声明，尚未宣称完成有效样式计算。内联表格样式、未知扩展等保留物理 ordinal 和原始 OPC 字节；未识别的 graphicData 不投影成空表格。表格样式 ID 被记录，但其目录、条带/首末行列选择、边框冲突和级联还未求值。

## 同一来源事务及历史兼容

`import_document` 产生 `presentationml-retained-fields-v3-draft`：沿用来源标题与字段语义，并包含表格单元格文字。表格仍为来源对象，局部文字编辑经现有 `Snapshot`、`Transaction`、`SourcePlan`、`PreservedPlan` 写回真实原生叶。完成输出后重新读取并验证预期声明；其他 OPC 部件、关系、合并标记和未知内容不变。

V1/V2 历史投影继续把表格文字保留在原包，不自动改变旧快照字段或约束。来源计划按记录中的 profile 重建基线；禁止把新增单元格文字伪装为旧版本投影。V3 不是宿主数据库迁移，不能将版本字段直接改写当作迁移；需要提升历史快照时，应从真实原包重新建立来源绑定并处理已有编辑。产品固定 SDK 尚未升级到该版本。

动态字段、兼容性分支、结构化文字叶和时间引用沿用原编辑约束。普通局部编辑不重建整张表格，也不改写无法解释的格式。

## 验证

[表格来源测试](../../crates/mo-pptx/tests/source_tables.rs)覆盖物理/覆盖/空单元格、多个段落、断行与动态字段、六向边框、属性缺省、精确单位、未知扩展、来源事务、历史投影、过期请求、聚合预算及取消。作者计划与实际导出再读取的完整声明图另在[作者计划测试](../../crates/mo-pptx/tests/author_plan.rs)对照，保留行列身份与文字根所有权。

[公共 Native/WASM 验证](../../tools/verification/native-table-source-parity.mjs)消费原有表格编辑语料，比较实际来源检查、导入、保留式文字编辑的二进制输出及过期请求拒绝。[独立检查](../../tools/verification/native-table-source-readback.py)使用 XML Schema、JSON Schema 和 python-pptx，核对文字、合并与尺寸，并逐部件/逐 XML 字节证明只有请求中的叶子发生变化。

本轮 428 项相关 Rust 测试（新增 12 项）、严格 Clippy、完整工作区编译、Schema/TS 同步均通过。11 份表格文件完成 55 次 Native/WASM 来源检查、导入、字节编辑及拒绝对照，累计修改 65 个普通文字叶；独立读取覆盖 119 个物理单元格、66 次 XSD 与 55 次 JSON Schema 校验。原作者事务语料的 14 次请求、11 份导出跨端对照及独立结构读取也重新通过。

最终命令、日志和摘要见[阶段证据](../reviews/evidence/2026-09-29-table-source-verification.json)。这些结构验证不能替代 WPS/Office 实际编辑或像素验收。

## 后续与接入边界

下一步沿共享文字与资源页面编译器实现单元格有效样式、排版、填充与边框绘制；随后处理文字驱动行高、整表尺寸调整、表格样式及单元格动画，并验证传统应用往返、Native/WASM 像素和产品调用。当前读取成功不意味着表格预览已可用。

后续已实现[合并网格、声明几何与借用式文字范围](table-geometry.md)，供共享排版使用；这不会把本阶段的历史结构证据提升为表格视觉验收。

Musterwork 后续修改、构建及测试始终在[独立 worktree](product-worktree.md)执行，原主工作区由用户继续开发。本阶段未更新产品固定 SDK/Worker/WASM、未切换默认引擎，也没有运行用户数据库。只有完整表格链路验证后才统一升级产品材料；完整一期及全部替换门禁继续保持。
