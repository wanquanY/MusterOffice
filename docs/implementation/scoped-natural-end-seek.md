# 序列自然结束跳转与局部时钟

2026-09-28。承接[原生序列导航](native-sequence-navigation.md)，共享内核已实现 `nextAc=seek` 的自然结束跳转，并接入既有 PPTX 读写、原生 SDK 和 WASM 播放。此阶段没有修改 Musterwork 的固定 SDK、导出 Worker 或播放包，也没有完成整体替换验收。

## 计算语义

自然结束位置与实际结束时刻分开处理：有限行为按其速度、重复次数、重复时长和结束条件计算；无限循环以第一轮结束位置参与自然位置计算，已经超过该位置时不会倒退。容器递归计算已知子节点的结束位置，执行范围内的延迟开始和事件依赖。未知的未来用户输入不会被合成；已解析的实际结束边界仍可以提前终止容器。

例如，1 秒开始、持续 10 秒的动画在宿主时间 3 秒收到下一项命令，内核可将该分支的内部时钟推进 8 秒；宿主时间仍是 3 秒，下一项也从 3 秒开始。若该分支有无限循环，`concurrent=true` 会保留实际活动状态，后续采样继续从跳转后的内部时间运行；`concurrent=false` 则在跳转后终止该分支。跳到自然位置本身不会伪造无限节点的结束事件。

规则依据为 ECMA-376 Part 1 §19.5.65 `seq` 的 `nextAc` 与 `concurrent`。本阶段验证了实现的数值和因果关系，尚未通过新的 WPS/PowerPoint 实际播放校准证明所有组合与应用行为一致。

## 实现边界

- 局部时钟记录属于一次具体激活及其父激活。跳转记录沿该父链继承，后退、父节点重启和重新激活分别创建正确的新记录，其他分支的时钟保持独立。
- 宿主时间、输入序号与跳转内部的精确因果位置共同排序。相同宿主时刻的多次输入，以及被跳过区间内的先后事件，不会折叠成一次激活。
- 开始原点和结束界限保留接收节点的局部坐标。后续跳转不能改变已结束行为的反向播放原点或冻结姿态；缓存的事件条件也按接收分支的时钟计算延迟。
- 调度器按顺序执行跳过区间里的内部定时器。跨分支事件在实际宿主时刻发出，外部分支的延迟保持宿主时钟；零延迟反馈可以继续触发内部子节点。
- 没有跳转的时间图使用原时钟坐标的快速路径。所有新工作仍检查取消，循环反馈达到调度预算后明确失败。保留采样器只在整次计算成功后更新状态。

主要实现位于 `mo-timeline` 的 `tree/sample/clocks.rs`、`intervals.rs` 和 `schedule/seek.rs`；行为速度、重复与缓动继续复用原 `BehaviorClock`。没有增加第二套动画算法、运行时依赖、系统时钟、线程、UI、权限或存储。

公共事件、时间图和帧合同保持现有形式。原生 Reader/Writer 现在接受并保留已有枚举中的 `seek`。未知属性、缺失事件目标、未实现的行为和非法时序仍明确诊断；本阶段没有把这些情况改成默认动画。

## 已完成的验证

证据见[阶段记录](../reviews/evidence/2026-09-28-scoped-seek-final-verification.json)，由 `tools/verification/scoped-seek-evidence.py` 对当前源码、实际日志、输入、帧及包文件重新核对后生成。

- 相关 7 个 Rust 包共 **533 项通过、0 项失败、8 项忽略**；忽略项没有算作通过。严格 Clippy 通过。
- 导航测试包含同刻结束条件的因果序号择优、有限结束、无限首轮、超过首轮不倒退、嵌套分支、反向速度、部分重复、自动容器结束、缓存事件、同刻多次输入、跨分支反馈、后退重播、取消原子性与循环工作预算。
- 五份自有完整 PPTX 覆盖有限跳转、无限并发、无限独占、嵌套结束依赖和缓存结束条件。**65 组作者/来源对照、130 个实际渲染帧**，包含重复及倒退采样；关键缩放值另按独立方程断言。
- 上述帧通过实际原生 Worker、从独立复制 SDK 构建的 Rust consumer，以及真实打包 Node WASM Worker；WASM 使用有界分步采样。
- 另回放 **259 个旧冻结帧**和上一阶段 **60 个导航/页面边界帧**，既有结果保持。
- 五份 PPTX 在 Native/WASM 导出字节一致，**30 个 PML/DML 部件**通过固定 ECMA XSD。七份时序查询跨端一致；此前真实 WPS 六矩形来源仍可读，另一份缺失 `onEnd` 目标的来源仍明确拒绝。

初次通过后，代码复查发现同刻结束条件仅按局部时间择优、丢失较早输入序号的问题。新增回归先复现了错误，再修正为局部坐标与完整因果顺序共同择优。最终证据对应修正后重新构建的 SDK、原生 Worker 和 WASM；初次记录及失败日志保留，不替代最终验证。

这些一致性检查共享同一内核，不能替代独立应用的视觉与编辑验收。本阶段未新增浏览器、完整 Electron 或 WPS/Office 播放记录。
