# 精确图表数值与扇区分配

2026-09-30。`mo-charts` 开始承接设计中独立的图表计算领域。本批实现饼图、环形图所需
的角度分配基础：**不是完整图表绘制、作者模型、工作簿写出或模板准入**。Musterwork
仍固定早晨已验证的 SDK/Worker；本批没有更新产品组件、配置或重启开发进程。

## 数据和计算

`DecimalNumber` 接收有限十进制字符串，支持小数及指数写法，保留全部原始字节，包括
显式正号、负零、尾零和 XML 空白。内部将非零系数与十进制指数分开，以整数计算；
不会先转成 `f64`。空值、空字符串、错误值和非有限值不能被当成数字零传入。它们属于
后续图表数据模型和缺失值策略，格式适配器不得为调用本模块而静默补零或删点。

单个数值最多 1024 字节，非零规范化十进制指数范围为 -4096..4096；显式指数也受同一
范围约束，即使系数为零。默认每次最多
4096 个点、4 MiB 原始数值、100 万共同尺度整数位数和 400 万累计边界数值位数。
累计边界预算额外覆盖“一个很大的数与许多很小的数”所造成的重复宽整数计算，
不能仅按每个输入自身位数计量。全部预算和身份检查先于展开整数分配；失败不返回前缀。
每个有界阶段和点均检查取消。复用已固定的 `num-bigint 0.4.8`，没有新增外部组件。

`SectorRequest` 明确给定点顺序、稳定索引、起始角、方向和负值策略。负值策略是拒绝或
使用绝对值，**本阶段不宣称任一选择就是所有 Office 图表的默认行为**；输入数据不被修改。
输出角以十二点方向为零、Q32 圈数表达，顺时针增加。端点不归约到 [0,1)，因此跨越一整圈
仍保持连续，逆时针端点可为负数。半径、环孔、标签、图例、样式和三维计算不在此结果中。

每个端点由精确累计权重除以精确总权重，最后一次舍入到 Q32；不能把每片角度先舍入再
累加。相邻片共享同一边界，非零总量严格闭合一圈。输出给出保守的一个 Q32 单位端点
误差界，扫角需合并两个端点误差；这不是世界坐标、像素或曲线路径的误差证明。
零值仍占据原索引；正值小到两个端点重合时设置 `positiveBelowResolution`，没有丢弃
该数据。空序列和全零输入返回 `zeroTotal`，不会虚构等分圆环。

## 接口和验证

公开底层入口为 Rust `layout_chart_sectors`、WASM `layout_chart_sectors` 与：

```sh
mo-cli layout-chart-sectors fixtures/charts/sectors/thirds.json
```

请求/响应 Schema 与 TypeScript 由 Rust 生成。JSON 入口限制请求字节、拒绝重复字段、
额外字段和浮点 JSON 数值；错误区分输入、预算和取消，并保留失败点的稳定索引。
该接口是纯计算，不建立 Agent 工具权限、文件路径、数据库、任务平台或页面。

九项图表领域测试和两项公开 API 测试通过，包含 729 组独立小整数端点约束、精确闭合、
大/小指数、负值策略、负零、未达到输出精度的正值、全部预算和各阶段取消。严格 scoped
Clippy、生成类型及 TS 编译通过。

实际 Native/WASM 对比了 84 个完整响应：76 个成功计算、8 个明确错误；其中包含 64 个
固定种子的随机输入、极端指数/精度/资源反例及两份真实环形图的数值通道。独立有理数
程序复算成功案例的全部 1103 个端点及相关状态，全部匹配。84 个响应也通过生成的
Schema；非法非有限值、错误标记请求按预期不符合数值 Schema。详见
[机器可读证据](../reviews/evidence/2026-09-30-chart-sector-computation.json)。

跨端复现程序 [chart-sectors-parity.mjs](../../tools/verification/chart-sectors-parity.mjs) 对比
完整响应，输入清单元素为 `{ "name": "thirds", "request": "/caller/thirds.json",
"expectedStatus": "computed" }`。输出报告必须是新文件；由调用方决定保存位置。
[独立有理数检查](../../tools/verification/chart-sectors-oracle.py)使用 Python `Fraction`
复算每个端点、方向、闭合、索引、零值与精度诊断，不调用 Rust 内部算法。

```sh
node tools/verification/chart-sectors-parity.mjs \
  "$MO_CLI" "$MO_WASM_NODE_MODULE" "$MO_CASES_JSON" "$MO_NEW_PARITY_REPORT"
python3 tools/verification/chart-sectors-oracle.py "$MO_CASES_JSON" "$MO_NEW_PARITY_REPORT"
```

## 下一层集成要求

来源适配须继续保留系列、分类、原始缓存与工作簿数据权威，不能把本批数字计算当成缓存
已经重算。完整环形图要继续求环半径、变换、样式、标签与图例，接入共享几何/文字/绘制，
并维护原生图表及嵌入工作簿可编辑性。两份旧柱状图的结构问题需要独立、可追溯处理。
本批不关闭现有模板、Office/WPS、完整高级内容或全产品替换门禁。
