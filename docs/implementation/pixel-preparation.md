# 有界像素准备

状态：2026-09-27，已实现并通过本阶段验证。承接[可恢复绘图状态](stepped-raster.md)和[TS/WASM 分步播放](wasm-stepped-playback.md)，不代表完整 PPT 或 Musterwork 替换验收。

## 实现

原有绘图 task 仍保持单一所有者，新增私有像素传输游标，分步完成三类工作：

- 直通道图片只预乘一次，每工作单元最多处理 65,536 个像素，完全沿用既有整数舍入。已预乘的不可变图片继续借用输入，不增加图片副本。
- 背景以完整行初始化，每工作单元不超过 65,536 个像素。使用原有 Skia 色彩转换和清除操作；全部行完成后绑定完整目标 surface。
- 合成前缀逐段复制，每工作单元不超过 262,144 字节。复制期间不继续后续绘制，完成后才交给拥有独立像素的快照画笔。

共同状态位于 [`MoPixelTransfer`](../../components/skia/mo_pixel_work.h)，调度仍由 [`MoSkiaRasterTask`](../../components/skia/mo_skia.cpp) 持有。未完成的预乘资源和快照不进入图片/画笔表；取消时由 task 释放。未完成的目标帧不能 `take`。同步入口也排空同一个状态机，不保留第二份渲染实现。

此处只将均匀背景清除按行拆开。实际路径的扫描转换、抗锯齿、描边、裁剪和合成顺序均未改动；没有重新裁剪路径，也没有恢复先前被否决的几何分块实验。

ABI 4、执行扩展 1、V4–V12 输入、状态码及 TS 方法签名保持不变。工作单元始终是可变的内部进度单位，调用方不能依赖固定步骤数量。组件不新增时钟、调度器、权限、持久存储或页面。

## 验证

[阶段证据](../reviews/evidence/2026-09-27-pixel-preparation-verification.json)绑定源码、输入、实际产物、日志和保留的失败调用。

- 原有 554 组组件输入与新增 71 组边界输入，共 625 组；原生与 WASM 各以 1/7/4096 工作单元核对完整状态和像素，各 1,875 次分步比较通过。WASM 另外通过 625 次同步比较。新增输入包含分块前后边界、透明 RGB、全部通道/alpha 组合、多图片及两次前缀快照；其中 13 组图片有独立整数预乘参考。
- 原生 ASan/UBSan 共 2,500 次比较，实际提前取消 1,750 次；另有 20 次较晚取消，覆盖图片预乘和快照复制中段，均重新渲染成功。`detect_leaks=0`，不宣称 LeakSanitizer 通过或物理 RSS 回收。
- 独立像素传输探针在原生及 sanitizer 各验证 20 次完成/复用和 20 次提前销毁，覆盖边界、未完成取出拒绝及逐字节舍入。
- WASM 新增 20 次中段取消后完整复用，task 句柄与 TS 输入分配均释放。该计数不代表 Skia 内部分配或浏览器进程 RSS。
- 同源离线 SDK 在 Node 与 Chrome 各核对 71 帧的全部像素和元数据，均与原生历史参考相同。Chrome `153.0.8010.53`、隔离上下文，另有 30 次步骤间取消后继续采样。
- 15 步所选门禁通过，包括严格 Clippy/格式、119 份 Schema、TS 和已有原生绘制/播放/导出/CLI 集成。不是重跑全仓全部 Rust/MCP 测试，保留报告中的忽略项和筛选范围。

一次播放验证调用误多传了参考目录，工具在处理输入前拒绝了无效 mode；保留失败记录，纠正参数后重新执行通过。没有为通过检查修改参考像素或容差。

## 局部耗时与体积

在 Apple M4 Max、36 GiB、macOS 26.2 上，两份原创 64 MiB 像素准备输入分别运行旧/新原生组件各五次，每次新进程、交替顺序、`workUnits=1`。每次最长 `step` 耗时的中位数：

| 输入 | 旧组件 | 新组件 |
| --- | ---: | ---: |
| 4096 × 4096 背景清除 | 4.747 ms | 0.067 ms |
| 4096 × 4096 直通道图片预乘、1 × 1 输出 | 8.304 ms | 0.133 ms |

这些是准备阶段让出粒度的诊断，不是整页性能或 P95。无字体，进程内缓存为空，系统页缓存和整机负载未控制；计时排除 begin 验证、TS 复制、结果取出和 IPC。两版输出摘要一致，原始逐次观察与设备、输入、依赖/编译产物 pins 均保存在阶段证据中。完整画质、吞吐量、取消响应及物理资源回收须另行验收。

Skia WASM 为 **2,373,665 字节**，比上阶段增加 **1,118 字节**。本次离线播放包 60 文件、清单外 **14,397,221 字节**，归档 **4,142,036 字节**；两次打包逐字节相同。核心 Rust WASM、HarfBuzz 和第三方版本/许可证未变，图形适配层重新编译并复用已核对摘要的上游静态库，没有声称重新构建了全部上游。`releaseCleared` 仍为 false；这些数字不等于完整内核或 Musterwork 安装包。

## 仍需完成

单个 Skia 路径绘制/裁剪、几何边生成、渐变计算、输入验证、内存分配及跨端复制仍可能形成同步临界区。像素数量上限也不能为分配器和系统调度提供时间保证。宿主只能在组件返回后协作取消，既有 Worker 强制终止差异仍存在。下一步继续处理这些临界区，保持相同的扫描转换与像素结果。

本阶段没有写入 Musterwork、迁移其历史文稿或替换其 PPT 实现。完整高级内容、Office/WPS 互操作、Musterwork 实际 WebView 和 E0–E3 继续保持未验收状态。
