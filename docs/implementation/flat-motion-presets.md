# 平面路径动画的原生效果身份

2026-09-29。[多段与曲线路径动画](motion-paths.md)之后的兼容性修复。完整一期及 Musterwork 替换验收目标保持进行中。

## 原因与实现

此前底层 v0.1 时间图导出的路径在 WPS 中没有播放。Writer 已有 `tmRoot → mainSeq → parallel → parallel → effect` 的五层组织；实际缺口是 `TransformPreset` 只覆盖缩放和旋转，`animMotion` 的效果层没有原生编辑身份。公共作者序列使用 `CustomMotion`，因而相同路径可以播放。问题归属原生格式映射，不需要宿主替换调用入口。

现在直线及多段／三次曲线路径都映射为 `presetID=0`、`presetClass=path`、`presetSubtype=0`、`nodeType=withEffect`。缩放、旋转和路径共用已有 `native_preset` 映射；Reader 和 Writer 从同一身份定义取得 ID 与类别。新增元数据只描述原生效果，不替代实际路径与时钟。

Reader 严格提升时序中性的既有包装，保留行为 ID、目标、十进制控制点、开始／结束引用、点击、延迟、重复、往返、缓动、反向速度、restart 和 fill。错误的类别／编号不会被剥离。容器有实际时钟、事件引用或导航时仍保留完整时间树；没有为通用可见性赋值或 Fade 擅自增加进出场预设。

没有改变 JSON 合同、WASM/原生计算算法或产品接口，没有新增运行依赖、C/C++、权限、存储和交互能力。

## 原生验证

单变量控制文件只在六个路径效果容器增加上述四个属性，所有其他包部件及行为子树保持原样。WPS 12.1.22553 实际放映六个路径，前后截图的六色位置均发生变化，闭合路径返回原点。正式 Writer 随后直接导出的文件，其全部 13 个解压部件与该控制文件逐字节相同；不把手工修改控制文件冒充生产导出。

校准只使用已授权目录中的自有样本。校准前前台应用是 WPS，结束后关闭控制样本并恢复 `rotation-absolute-fixed.pptx`；没有保存用户文稿或增加系统授权。截图没有时钟同步，因此这里只证明这些自动路径可被识别和播放，不宣称任意点击、依赖、重复的 WPS 时序、原生编辑往返或 PowerPoint 验收。

416 项相关 Rust 测试及严格 Clippy 通过。新增混合缩放／旋转／直线／曲线测试，比较导出包装与独立无包装原生语法的完整投影及 30 组事件／采样状态，覆盖点击、结束依赖、重复、往返、反向速度、缓动、保持与移除，并拒绝错误的路径预设类别／编号。其余容器身份、有限时长和事件引用测试继续通过。

两份完整 PPTX 共 64 个作者／来源帧、32 个独立静态几何对照及 10 个 XSD 部件检查通过。64 帧分别通过打包 WASM 的同步和分步执行，28 个旧直线／混合帧回归通过。共享内核跨端一致不等于 Office 独立视觉验收。
