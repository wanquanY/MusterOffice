# 原生直线路径的缺省行为

2026-09-29：此前在 WPS 中直接绘制的路径原文件已通过内核读取和计算。该文件的字节保持不变；缺省 `cBhvr.additive` 与效果容器的 50% 缓入／50% 缓出同时生效。此阶段解决直线路径的默认值映射，完整一期与 PPT 替换验收仍在推进。

## 语义依据与边界

[Microsoft 的默认值说明](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oe376/6988ac0e-8227-47dd-a67b-1bbb925cd0af)将缺省 additive 记为 `base`；其[值域实现说明](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oe376/d4cb5f92-92a0-4103-9a15-d499efbe9785)又说明 PowerPoint 不支持 `base/mult/none`。这些说明不足以证明所有行为的缺省值都等于替换。实现按行为的值域处理默认值，保留尚未验证的其他属性域。

自有六矩形对照为每个对象设置两条路径：先水平移动 15% 页宽，再从原始布局中心移动 10% 页宽。第二条分别使用省略、`base`、`repl`、`sum`、`mult` 和 `none`。在 WPS 12.1.22553 中：

- 自动连续播放后，六对象均位于原始位置加 10% 页宽。
- 分次触发时，第一段结束确实为原始位置加 15%；触发第二段后变为原始位置加 10%。截图位置与独立几何期望最大相差 0.6 截图像素。
- 后三种声明在此 WPS 对照中也表现相同。这不足以证明它们具有普遍等价语义，因此没有据此开放 `sum/mult/none`。

当前映射只为已有的 `origin=layout`、相对编辑模式、单一 M→L 路径接受省略或显式 `base`。这类路径给出相对原始布局中心的完整偏移，进入现有的绝对运动属性通道；后启动行为替换同一通道的前值，移除后重新显露下层值。通用属性动画、旋转、缩放的缺省叠加规则没有被扩大解释；累积、其他变换空间、曲线和多段路径的限制仍生效。

共同属性检查移到行为映射模块，调度器、属性优先级和绘制器继续使用统一实现。公共合同未增加字段，也未增加运行时状态、依赖或宿主逻辑。来源文稿的原始 XML 继续由 OPC 保真路径保留；重新按作者模型生成时，Writer 使用已有明确的 `repl` 声明。

## 验证

- 523 项相关 Rust 测试及严格 Clippy 通过。新测试用手写原生 XML 检查活跃／保持区间的替换、非零路径起点、移除恢复、倒退采样、保留采样一致性及不支持声明的明确拒绝。
- 两份完整来源文件共 32 帧通过独立分数运算核对；25 个可精确表示为整数 EMU 的位置另外与无动画静态几何逐像素相同。没有对其他分数位置进行舍入以制造静态对照。
- 同样 32 帧分别通过实际 WASM Worker 的同步和分步执行；11 个 PresentationML 根部件通过独立 XSD 校验。

## 继续开放的范围

这是有明确输入域和 WPS 对照的默认值映射，不代表 PowerPoint 实机、任意 WPS 文稿或完整叠加运算通过。数值属性叠加、一般容器时钟、其余高级演示内容、真实 Agent／Electron、多平台、历史迁移和性能／资源／安装包等替换门禁仍开放。

产品工作限定于[独立 worktree](product-worktree.md)。MusterOffice 继续只提供文稿计算与薄接入，默认引擎未切换。

后续进展：同日的[旋转基准与叠加](rotation-composition.md)已进一步实现旋转的布局偏移与 by-only 贡献，并修复绝对作者端点导出；本文的原测试与材料保持历史记录，其余通用合成限制未被扩大解释。
