# 有限同步子树的容器自动往返

2026-09-29：容器 `autoReverse` 已在原生、WASM 和独立 Musterwork worktree 接通。当前支持同时开始、同一有限时刻结束的子树，包含重复叶子、嵌套往返、容器变速／缓动、截断、重启和范围导航。一般错峰／不同长度子树及完整一期替换验收继续实施。

## 生命周期与计算

往返有两个真实的子项激活区间。第一程结束时先处理子项结束和由此引起的取消，再进入第二程；容器自身保持同一次激活。第二程重建后代激活身份，保留第一程历史，不让旧定时事件混入新轮次。两次子项结束通知都可被外部依赖消费。

容器保存单程跨度，在自己的简单时间中折返，然后应用自己的缓动。父子方向级联决定重复边界取值；恰在转折点被祖先截断时保留入射侧终点，不生成第二程。Next seek 处理完整往返及沿途因果事件，Previous 恢复新的播放范围。已有精确分数预算、调度步数、激活记录上限和取消回滚继续约束计算，不在每帧引入全图扫描。

准入仍要求子项同时从局部零开始、跨度相同、无内部结束条件和导航；多子项顺序容器不满足该条件。容器自身缓动与往返可以组合；后代容器存在内部折返点时，祖先缓动需要非线性截止投影，当前明确拒绝，避免用线性时间或舍入时间代替。嵌套往返在已支持的线性有符号速度下可组合。

自动往返延长简单时长、缓动应用于未加倍的单程时间，依据 [SMIL 时间变换](https://www.w3.org/TR/SMIL3/smil-timemanip.html)。原生文件保留容器级 `cTn.autoRev`，没有把语义摊平为叶子属性或修改叶子声明时长。
