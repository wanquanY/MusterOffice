# 椭圆渐变预计算与嵌套求值

状态：开发实现与阶段验证，2026-09-26。延续 Rust 核心、TS 薄适配与精选 C++ 组件方案；本阶段优化已接入实际 PPTX 的 V12 渐变。完整演示文稿能力和 Musterwork 替换门槛仍未完成。

## 实现与证明边界

此前[来源页面](elliptic-source-pages.md)已能绘制圆形/椭圆焦点，但通用首次交点计算在每个像素重复生成固定系数。现在画笔持有不可变 `PreparedGeometry`，缓存两轴半径的 Bernstein 系数和四次半径乘积。半径系数是精确、非负 binary64 数，乘法可以只计算区间的两个单调端点；通用求解器保持原有运算分组、首次闭集进入语义、切触判定和预算。

另为能证明严格嵌套的椭圆族增加专用求值：

- 两个内半径均小于 1，中心为零时，两个轴严格增长。
- 点焦点的中心严格位于单位圆内时，扩张圆族严格嵌套。
- 两个内半径均大于零时，使用支持函数导数的保守下界。设 `m = min(rx(1-rx), ry(1-ry))`、`M = max(rx, ry)`，仅当区间计算证明 `m² > |c|² M²` 时启用。支持函数关于插值参数凸，其初始导数至少为 `m/M`，足以超过中心移动速度。

最后一个条件是充分条件，未覆盖全部嵌套椭圆。不满足条件、区间不确定、非嵌套及外部焦点继续进入同一个通用求解器。不能将椭圆的最小轴增长率直接当作支持函数增长下界。

专用求值先分类初始闭集和外圆，再用最多 16 步浮点 Newton/二分生成候选。候选本身不构成验收：必须通过向外舍入区间计算，在该 binary32 值的相邻舍入中点处证明严格异号。严格嵌套结合异号证明首次根落入正确舍入单元；中点相等或无法证明时使用通用算法。保留最大根区间宽度 `2^-23`、每像素 512 节点、整帧样本/节点预算及无部分输出语义。

未增加逐像素堆分配、第三方依赖、近似纹理或浏览器布局；尚未实现 SIMD 求根。V12 帧和 ABI 不变，Rust 合同和 TS 适配不变。本阶段仍是开发 profile；实现构建摘要已经改变，未来持久渲染缓存必须按设计包含实现身份，不能仅以相同帧版本跨构建复用。

## 测量方法

设备为 Apple M4 Max、14 逻辑 CPU、36 GiB 内存，Darwin 25.2.0 arm64，Node 23.5.0。使用固定版本 Skia/PNG/JPEG/zlib 和同一 Rust、TS、HarfBuzz 产物；C++ 使用正式优化构建，版本和编译参数绑定到[阶段证据](../reviews/evidence/2026-09-26-elliptic-fast-verification.json)中的构建记录。

旧组件和新组件在同一次测量中顺序执行，每组 3 次预热、25 次采样，表中为中位数，原始采样和 p95 保留。组件已加载，不强制 GC；测试输入已在内存中。没有并行运行本任务的编译/验证作业，其他系统负载未控制。这是局部环境观察，不是跨设备统计结论。

### 完整底层绘制调用

Native 计时包括参数验证、画笔/路径/输出分配和绘制；WASM 还包括 TS 传入传出拷贝。每次重新构造绘制状态；无字体、图片或文稿编译。每次输出都与旧组件逐字节比较。

| 中心点焦点 | 1024×1024 | 14.296 → 14.392 | 43.882 → 41.390 |

| 非嵌套多交点场 | 512×256 | 228.136 → 193.863 | 320.935 → 250.401 |

两类嵌套椭圆约加速 5 倍，非嵌套场 Native 约加速 18%。控制组没有统一改善，Native 圆形控制组本次反而增加约 0.28 ms；不能据此声称所有渲染变快，也不能把该波动认定为已有因果解释。非嵌套场仍明显昂贵。

## 验证与体积

独立 Fraction/Sturm 验证 6,486 组输入的首次根和区间：6,438 成功、41 明确精度诊断、5 无效输入、2 预算诊断。Native、WASM、ASan/UBSan 打包结果逐字节一致。1,238 个历史通用标量结果逐字节不变；新输入中，原通用算法成功的情况没有因专用求值变为失败。

Skia WASM 从 2,343,781 增至 2,352,940 字节，增加 9,159 字节，约 0.39%。Rust WASM、TS 适配和依赖锁保持不变。以上是单个裸模块，不包含字体、媒体、宿主、资源或安装包压缩。

355 对 Native/WASM 公共调用的响应、批次和像素与上一阶段相同；其中 183 对为通用/场景调用、172 对为实际来源页面调用。551 组历史底层语料和 83 组实际 V12 批次重放，共 634 组 Native/WASM/ASan/UBSan 检查通过，包含数值/预算失败后的实例恢复。CLI 创建成功、拒绝覆盖已有文件、失败不产生输出文件的行为保持不变。620 项 Rust 测试、严格 Clippy、格式和 82 份 Schema/TS 检查通过。

完整重放、workspace 检查和 CLI 提交结果由阶段证据绑定。旧页面与当前像素相同才继承旧阶段的独立像素参考结论，不将跨端一致性独立声称为 Office/WPS 视觉验收。源参数位移界仍不等于标量或颜色误差界；专用正确舍入是对已编码 binary32 场的保证。
