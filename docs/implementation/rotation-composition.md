# 旋转动画的原始角度与叠加语义

2026-09-29：旋转计算现在区分作者绝对角度、相对原始布局的角度和叠加角度。此次修复解决了对象本来已有旋转时，内核与 WPS 播放结果不一致的问题；新版 SDK、原生 Worker 和播放包已在独立 Musterwork worktree 中更新并验证。完整一期与 PPT 替换验收仍在推进。

## 问题与语义依据

原实现把原生 `animRot.from/to` 当成对象最终绝对角度。对象原始角度为 20° 时，原生 0→30° 在 WPS 的终点为 50°，此前内核却计算为 30°。反过来，作者合同中的绝对 0→30° 若直接写为原生 0→30°，导出文件也会多转 20°。

[Microsoft 的 animRot 实现说明](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/39903f1a-fcb4-4aee-81e2-66f4fc7493fd)列出 from/to、from/by、to-only、by-only 四类输入，并规定显式 to 优先于 by。属性的数值起点为零，不代表最终对象角度必须从零开始；属性合成还需要原始布局与下层动画值。实际映射结合自有非零初始角度对照验证，没有将单个行为的观察推广到所有属性。

在 WPS 12.1.22553 中，六个原始角度均为 20° 的矩形得到以下结果：

| 原生输入 | 第一段结束 | 第二段结束 | 对应计算 |
| --- | --- | --- | --- |
| 先 from=0/to=30°，再 from=0/to=70° | 50° | 90° | 原始角度加当前替换偏移 |
| 先 by=30°，再 by=70°，前段保持 | 50° | 120° | 原始角度加仍生效的各段贡献 |
| by=30° 在 1 秒移除，重叠的 by=70° 在 1.5 秒保持 | — | 90° | 已移除的前段不再贡献角度 |
| 修复后的作者绝对 0→30°，再绝对 0→70° | 30° | 70° | Writer 减去原始局部角度后输出 |

前两组逐行比较省略、base、repl、sum、mult、none 声明；六行在这些 WPS 样本中表现相同。当前只开放省略／base／repl。不能由此宣称一般 sum／mult／none、累积或 PowerPoint 实机行为已经通过。30 个原生输入角度观察的最大误差为 0.044°，12 个修复后导出角度观察为 0.145°；测量使用纯色矩形主轴、按 180° 等价归一，仅验证方向，不代表颜色或动画曲线质量验收。

## 计算合同与实现

`Effect::Rotation` 增加可选 `composition`：

| 值 | 意义 | 原生映射 |
| --- | --- | --- |
| absolute，省略时默认 | 对象的最终局部角度 | Writer 将端点减去原始局部角度，再写 from/to |
| layout | 相对对象原始局部角度的完整动画偏移 | from/to、from/by、to-only 归入此域 |
| add | 在当前有效的下层角度上叠加贡献 | by-only 读为 0→by；作者 from=0 时写为 by-only |

保持原先 absolute JSON 的省略形式和数值含义；Rust 构造器需要显式提供新增字段。采样旋转值改为精确分数与 `basis`，默认 absolute 不输出该字段，layout 则显式携带原始布局基准。非绝对旋转使用 `musteroffice.composed-property-frame/0.1-draft`，不能由消费方忽略基准字段并当作绝对角度。

同对象替换值仍按开始时刻和既有作者顺序决定优先级；只累加最新替换之上的有效叠加贡献。结束移除、保持和倒退查询均由当前时间区间重新计算，不依赖上一帧可变历史。聚合对有效贡献进行线性遍历，沿用精确位数预算与取消检查，没有逐帧排序或无界历史。

共享放置层在原始局部坐标域解析基准，再执行组合、翻转与父级变换。Writer 只读取原始 Document 并流式输出，没有复制时间树或修改作者模型。from/by 的端点超出计算范围、无法表示为原生整数角度的导出端点，以及非零 from 的 add 导出均明确拒绝；没有静默截断或改写。

导入来源仍由 OPC 保留路径导出。解析后的计算语义变化不修改原文件，也不把来源保留等同于完整语义编辑。

## 继续开放的范围

一般原生 additive／accumulate、其他属性叠加、一般容器时钟、其余完整高级内容和任意文稿的 Office／WPS 编辑往返仍需实现与验证。真实 Agent／Electron、多平台、历史迁移、性能／资源／安装包及全部替换门禁继续推进。此轮实际外部播放仅为上述 WPS 自有对照，没有 PowerPoint 实机结论。

产品工作限定于[独立 worktree](product-worktree.md)，原主工作区留给用户，默认引擎未切换。MusterOffice 保持纯文稿计算与薄接入的边界。
