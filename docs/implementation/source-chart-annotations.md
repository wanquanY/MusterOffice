# 来源图表的标签、图例与标题声明

本阶段把图表文本与标注接入已有 `pptx-charts` 查询，保留来源与缺省状态，供后续
图表文字计算使用。它不等于标签已经绘制，也不解除完整 graphicFrame 或模板准入。
Musterwork 当前人工验收候选继续使用固定 SDK；没有更换运行中的内核、重启产品或新增
Agent 工具。完整一期目标仍包括图表布局、原生编辑、工作簿一致性与 Office/WPS 互操作。

## 统一声明模型

`SourceChartPart.annotations` 在有内容时返回两个有界集合：

- `nodes`：组级/单点标签、图例/条目、标题、布局和手动布局，按物理序号排列。
  `parentOrdinal` 连接真实 chart、plot、series、axis 或其他标注；单点/图例条目保留稀疏 idx。
- `textBodies`：真实 `c:txPr` / `c:rich`，包括 chartSpace、坐标轴文字属性以及标注文字。
  每个正文使用共享 `SourceTextCatalog`，带段落、文本、换行与字段的物理来源。

显示开关、标签/图例位置、overlay、手动坐标和布局模式沿用共享图表声明模型；
numFmt 保留 formatCode 与 sourceLinked 的原始拼写。缺少元素、元素没有 val、显式
false/0 各自保留。separator 使用完整字符数据，空分隔符不会变成缺省分隔符。
数值坐标不提前转成浮点，也不把未声明的字体替换成 Arial。

自定义标注文字保留富文本或 strRef 的单一选择。缓存标题保留公式、缺失/空/有效缓存
值及未知内容的来源；不打开外部工作簿，不声明缓存已重算。富文本由形状/表格共用的
DrawingML 语法、文字捕获、填充、线条和效果解析器处理。新增原生 `txPr`、`rich`
根类型，没有伪造 `p:txBody`、图形 ID 或可编辑形状。

目录中的文字是来源数据，不附带 chart 编辑承诺。自动布局、图例项生成、数字格式化、
默认文本及逐属性继承属于后续计算，不能由宿主拼接普通文本框来代替图表语义。

## 解析、未知内容与预算

图表结构只建立一次有界树；选中的真实文字根在同一部件字节上进行一次 MCE 流式解析，
不重新读取文件。文字元素、属性字节、文字字节、填充/线条预算在本次查询的全部正文和
全部图表之间累计。共享图表部件仍只解析一次。另限制最多 16,384 个标注节点、4,096
个正文；调用方可缩小预算。复杂度受既有 XML、元数据、缓存点和部件大小预算共同约束。

重复标签 idx、重复单值/单节点、冲突的 delete/格式选择、混合富文本与引用、不完整正文、
标量内嵌元素均返回错误。原有轴布局测试的空 `txPr` 占位更新为合法正文；它以前只作为
不透明引用，现在进入真实文字语法。查询仍不声称对全部图表内容完成 XSD 或语义验收。

扩展与未知属性/子树保留来源，不能静默变成已经解析的文字。图表布局新增未知属性序号；
圆形几何和样式合成同时检查该信息，阻止未知系列/点/绘图区属性绕过计算准入。
图表来源查询的响应增加可选字段，Rust、JSON Schema 和生成 TS 合同同步更新；严格消费
方需一起更新合同。本批不修改产品固定的 SDK 副本。

## 标准依据与真实模板事实

声明结构依据 ECMA-376 Part 1 §21.2.2 的 dLbl、dLbls、legend、legendEntry、layout、
manualLayout、numFmt、separator、title、tx 与 txPr。源语法解析不提前套用应用默认值。

[微软对 dLbls 的说明](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/953e5879-8008-4d14-a8bc-fbe39d848e0a)
明确了 Office 的组级、系列级与单点覆盖次序，并列出非 ser 父级下的若干子元素限制。
本阶段保留声明位置，尚未实施这一应用 profile 的完整覆盖计算或兼容性裁决。
后续缺省分隔符也必须遵循 §21.2.2.166：通常为逗号；饼图仅显示分类和百分比时为换行。
不能将所有组合统一成逗号加空格。

两个真实模板的圆环图均显示：系列 dLbls 默认声明“分类＋百分比、18 磅”，三个单点
分别覆盖为“仅数值、12 磅”；图例只声明 14 磅，没有字体名称，需继续从主题/图表样式
解析。独立核对保留了这一区别，没有把组级声明当成最终文字，也没有向图例添加字体。
私有模板和文字内容未复制到公共测试目录。

## 验证与后续

证据见[本次摘要](../reviews/evidence/2026-09-30-source-chart-annotations.json)。测试覆盖
组/单点覆盖来源、图例条目、手动位置、中文富文本/换行/字段、缓存标题、MCE、未知
内容、非法选择与跨图表累计预算。共享形状/表格文字和源圆形图表继续执行回归。

跨端检查比较完整原生/WASM 响应；独立 Python 验证器从原始 ZIP/XML 检查父级、物理
序号、开关/坐标原文、字号、字体来源和段落内容，并用错误父级/字号反例验证检测能力。
该验证器明确不接受未经独立投影的 MCE 输入；MCE 的选择与保留由 Rust 用例覆盖。
既有图表几何/绘图结果另与前一版 WASM 对照。没有为本阶段增加渲染或 Office/WPS
通过声明。

后续沿已确认目标继续：实施有来源的标注覆盖规则、数字格式化、图表文字级联和主题
字体解析，接到既有塑形/排版/Draw IR；随后完成标签/图例自动布局、碰撞与引导线、
整图和全页合成，再推进原生编辑与跨应用验收。
