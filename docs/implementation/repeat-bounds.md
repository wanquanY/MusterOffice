# 重复次数、重复时长与不定结束

状态：沿既定 Rust／TS／精选 C++ 路线扩展共享动画时钟。本阶段实现行为叶子的有限/无限重复和重复时长，接入原生 PPTX、作者与来源页面采样。完整容器重复、重启、条件组合、效果、媒体及 Musterwork 替换仍需继续实现。

## 模型和求值

`TimingNode.repeatMilli` 接受原有千分之一次数整数，或显式字符串 `"indefinite"`。Rust 使用 `RepeatCount::Finite(u32)` / `Indefinite`，不以 0、最大整数或负数充当无限哨兵。有限次数仍须大于零；原有整数 JSON、文档摘要和输出保留原表示。

可选 `repeatDuration` 接受 `RationalTime` 或 `"indefinite"`，表示速度缩放前的局部重复时长。未声明时不增加时长上限；显式 indefinite 同样不增加有限上限，但声明身份保留。有限值允许零，拒绝负数。单轮 duration 仍必须为正，不能把“不定重复”与“不定单轮时长”混为一谈。

编译先计算往返后的单轮长度，再取得有限次数产生的总时长与 repeatDuration 的较小值；若两者均无有限上限，活动时长是不定的。速度绝对值将局部时长换算到父时钟。自动往返会加倍单轮，但不会加倍一个独立声明的 repeatDuration。加减速继续作用于折叠后的单轮进度，不改变结束时间。

重复不展开为任务或节点列表。采样通过精确商/余数直接定位轮次，可以跳到大时间点或向后 seek；成本不随经过的重复次数线性增长。现有有理数位数预算、节点/事件预算和取消检查继续生效。

没有结束时刻的行为保持 active；依赖它的 end 的节点仍 waiting。顺序容器等待实际结束，不猜测一个有限结束时刻。有限 repeatDuration 可以释放顺序后继；固定祖先可以截断无限重复。祖先截断同时结束其子树，不能让后继在已经结束的父作用域中补启动。自然结束与祖先提前截断仍分别处理 fill。

零 repeatDuration 是瞬时结束，不播放一整轮。hold 保存起点进度，remove 不输出该行为值；它仍产生可供后继使用的结束时刻。原有正时长要求没有被改成除零可通过。

## 反向重复的起点

有限行为使用已经声明的完整活动时长作为反向起点，父级提前截断不会重新定义这个起点。无限重复没有这样的天然起点；如果父级提供可解析的有限截止时间，则以“截止时间 − 行为实际开始时间”换算出局部反向范围，包括开始偏移、变速与分数尾轮。

如果无限倒放既没有有限 repeatDuration，也没有可解析的祖先截止时间，当前采样返回明确诊断。不会凭空选取一个极大的次数、将无限视为零、循环等待，或返回部分图像。等待开始之前的采样仍然有效，诊断不会使可复用播放会话失效。完整条件/事件驱动的结束范围将随后续时间模型继续补齐。

## 原生文件与默认值边界

PPTX 读写 `p:cTn@repeatCount` 和 `repeatDur` 的 unsigned 毫秒/千分之一次数或 `indefinite` 表示。有限 repeatDuration 不可精确转换成原生 unsigned 毫秒时拒绝导出，不舍入。原始源包和 XML 声明继续保留，旋转仍导出为可编辑原生行为。

原生缺失 repeatCount 当前投影为 XSD 的默认 1000；不会套用 SMIL 的“未声明次数即无次数上限”。repeatDur 与显式/缺省次数的交互使用本阶段明确的最小上限计算合同。Microsoft 属性描述、XSD 默认值和 SMIL 模型不是同一层证据；这部分尚需 PowerPoint/WPS 实际播放核对，不能据此宣布目标应用等价。

共享 unsigned 时间属性读取现在接受 XML 边界空白，仍拒绝负数、越界、小数和未知不定值。次数零继续被时间模型拒绝；重复时长零合法。容器上的重复属性尚未接入，不擅自拉平为多个叶子或改写成近似时间表。

## 验证与后续

本阶段工具使用 `repeat-bounds-` 前缀，输出位于 `.codex-work/repeat-bounds`。独立 Fraction 参考按局部上限、父级截止和速度曲线积分计算作者及原生图片/文字/组合对象样例；实际 Native/WASM 页面与静态变换对照分别核对。旧时间树和行为变速语料使用当前构建重放，历史文件不重写。

结果与当前构建体积由[阶段证据](../reviews/evidence/2026-09-26-repeat-bounds-verification.json)绑定。正确性用例的运行耗时不作为吞吐、FPS、RSS 或最终安装包测量；合成字形也不代替真实字体视觉验收。

本阶段 711 项 Rust 测试、96 份 Schema/TS、严格 Clippy 与格式检查通过。33 组作者文稿有 441 个独立参考采样；含原生导出重读的公共求值为 474 次。968 次 Native/WASM 调用一致，覆盖 46 个作者帧、96 个含图片/文字的来源帧与 126 个静态画面对照。来源保留式帧的解码、塑形、字体上传和 gather 计数仍为零。

3 份作者导出和来源/静态对照共 633 个 PML 部件通过固定 XSD；10 个作者导出的原生时间项由独立 XML 参考核对。无限倒放缺少起点的求值、逐次绘制和保留式绘制均返回错误且不调用绘制组件、不发布像素；同一 owner 随后仍能正确采样开始前的页面。

此前 355 次静态、246 次时间接口、111 次作者会话、70 次来源逐次/对照、135 次来源会话、562 次时间树与 877 次变速语料均已重放；旧请求/响应、已记录帧和像素保持原字节，4 份旧时间树/变速 PPTX 导出也保持不变。原有“repeatDur=1000 不支持”的 Rust 断言已按新增能力改为未知值拒绝，并增加有效重复时长的正向检查。

Rust WASM 原始模块为 7,793,362 字节，较上一阶段增加 15,282 字节；C++ 绘制 WASM 仍为 2,370,691 字节，依赖锁文件未变。这些值不代表完整字体/媒体/运行时依赖或 Musterwork 安装包；已有渐变性能缺口和外部应用验收仍开放。
