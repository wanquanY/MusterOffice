# 原生上传策略与宿主环境描述

2026-09-28，Musterwork 独立 worktree 已将候选上传入口接到实际 SDK 生成的环境描述。上传可以自动固定原生策略 /3，并沿原任务进入整份文稿的 `native_define` 阶段。稳定配置继续使用策略 /2。该进展尚不证明异构执行节点派发、完整模型会话或 PPT 替换验收。

## 环境身份的来源

产品 Cloud Worker 新增 `--describe-office-environment`。它只需要已定义的 Office 宿主配置，校验实际 worker、显式字体和设置，调用公共 SDK 的环境计算，输出闭合的 `musterwork.office-execution-environment/1` 描述。无需数据库、模型或遥测配置；不创建模型任务，也不渲染文稿。初始化仍包括原宿主私有暂存准备和有界恢复。

描述包含编译档案、字体摘要、设置摘要、渲染器档案和 worker 摘要。设置摘要由 SDK 计算，已经绑定设置、字体和渲染器。后端不重新实现这一算法，不扫描系统字体，也不把配置中的名称当作计算身份。

部署方保存原始描述文件及其 SHA-256。候选后端通过进程配置取得文件位置和摘要，最多读取 4096 字节，并检查普通文件、实际字节摘要、闭合字段、类型和版本。它是已安装环境的描述，**不证明执行节点在线，也不预留计算名额**。实际执行继续核对固定环境；worker 或设置不匹配时明确拒绝。

这条边界属于 Musterwork 的部署组合。MusterOffice 未增加权限、任务、存储或配置服务。其他产品直接使用 SDK/MCP 的方式不因此增加要求。

## 上传与恢复

`native-office-preview` 的上传策略从上述描述取得编译档案、字体和设置摘要，模型路由仍由原产品解析器提供。描述缺失、损坏或超限时，新上传在保存来源文件及写入任务之前失败，不改走旧引擎。

原幂等查询仍先于策略解析。已接受请求重复提交时，返回原任务及固定策略，即使部署描述文件之后不可用也不重新选环境。原协调器使用任务已有策略读取来源、准备整份文稿阶段和提交维护请求。没有新增上传队列、业务任务平台或绕过原检查点。

## 已执行的验证

[验证证据](../reviews/evidence/2026-09-28-product-native-upload-verification.json)记录实际命令、源码及材料摘要。125 项不同测试通过：后端专项及协调器回归 47 项、旧上传/目录/升级和发布配置回归 56 项、云宿主 3 项、共享适配器 19 项。另有 7 个子测试通过，未重复计入 125。相关 Rust 库和可执行入口通过严格 Clippy，四个 Python 文件通过 Ruff。

- 实际 Cloud Worker 二进制在无数据库和模型配置下导出描述。重复导出的 423 字节完全一致；改变预览宽度会改变设置摘要；错误 worker 摘要和未知命令被拒绝。原始输出成为明确的自有测试夹具。
- 这份实际输出与上一阶段真实两页文稿的 SDK 环境一致。本轮还再次完成固定 worker 的实际导入、渲染和导出，没有据此提升视觉、播放或 Office/WPS 声明。
- 原上传接口、实际 SQL 及原协调器验证策略固定、任务复用和进入 `native_define`。这里的模型路由及 Runtime 接受端口是测试替身，只返回接受，不伪造文稿完成或视觉通过。
- 七类闭合字段错误，以及字节替换、超限、重复 JSON 字段、链接、目录、相对路径和缺失摘要被拒绝。固定文件失败不会保存来源或创建新任务。
- 原有环境不一致拒绝、取消期间计算名额持有、来源材料和压力计划回归通过。原后端弃用告警保留，没有为获得通过而屏蔽。

SDK 和 worker 未升级。当前仍使用 macOS ARM64 Debug worker；此处没有新增性能、发行体积或 Linux 部署结论。

## 下一项接入工作

原生任务的实际计算已经按固定环境拒绝不匹配，但原云调度器尚未根据完整 Office 环境选择执行节点。需要将任务的已签名环境要求接入原派发与恢复，使配置不同或版本不同的节点不能领取它不能执行的任务，并验证混合节点、重启和升级期间的行为。描述文件不能替代这项调度约束，也不能据此开启生产替换。

随后仍需真实父子维护任务、最终目录与 Agent 消费的完整会话，以及历史迁移、高级内容、Office/WPS、Native/WASM、性能和全量发行验收。完整目标保持进行中。

后续进展：原调度器的环境约束、恢复与历史投影已进入[环境派发阶段](product-native-dispatch.md)。上文保留本阶段完成时的验证边界，不追溯扩大旧证据。
