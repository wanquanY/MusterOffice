# 原生出现／消失与产品组件升级

2026-09-28，原生 Appear／Disappear 的初始状态、触发与撤销进入同一时间图，并在 Musterwork 独立 worktree 中同步升级 Rust SDK、实际导出 Worker 和 WASM 播放包。该阶段完成了有限原生预设的计算与产品播放链路，完整一期目标仍进行中，默认 PPT 引擎尚未切换。

## 计算与文件语义

此前通用 `setVisibility` 仅表达激活期间的固定属性赋值。原生“出现”还要求对象在首次触发前隐藏；主放映序列的“上一步”需要撤销最近激活的点击组并等待下一次触发。把这些行为交给产品补偿，会使导入、导出、直接采样与保留播放产生不同结果。

时间容器现在可显式携带 `presentation`：`mainSequence`，或具有 `preset` 与 `trigger` 的 `effect`。当前映射为 Appear、Disappear、Spin、GrowShrink；保留 clickEffect、withEffect、afterEffect 的原生身份，不用身份改写显式时钟。预设容器必须匹配已支持的单个行为，未知预设、类型或不匹配的负载仍返回诊断。多个行为组成的其他原生预设尚未因此获得支持。

编译阶段按时间树顺序建立初始属性层。对象的第一个预设为 Appear 时初始隐藏；第一个预设为退出或强调时保留文稿的基态。实际激活／冻结的属性赋值覆盖初始层，撤销与回放恢复同一初始层。没有插入伪造时间节点，也没有修改文稿的永久显示属性。这一多效果排序规则有单元验证，当前 WPS 实机证据仅覆盖单对象单预设。

显式 `mainSequence` 的向后导航会撤销最近激活的点击组，包括尚未结束的组；通用序列保留原先的导航定义。原生导出保留预设类别、编号、触发身份和时间树。删除目标对象时，会清除已空的预设身份，但保留仍可能被引用的计时容器、时长与 ID。

WPS 产生的顶层、无限期、无结束条件的 mainSeq 可省略 fill；该限定情形下结束填充不可观察，读取时归一为 Remove。有限或嵌套的其他缺失 fill 不借此推定默认语义。

## 独立应用与渲染验证

自有六矩形样本在 WPS Office **12.1.22553** 的真实放映中观察到：Appear 初始隐藏、下一步显示、上一步恢复隐藏；Disappear 初始显示、下一步隐藏、上一步恢复显示。内核重新导出的 Appear 文件也重复观察到上述状态。按已有授权短暂前台校准后退出放映并恢复原应用，没有编辑用户文稿。

去掉预设标识的对照文件在 WPS 中未形成可播放动画，不能将通用 Set 的计算支持等同于 WPS 可识别的原生预设。实机证据验证离散播放状态，不代表精确时刻、色彩校准、WPS 编辑回存、Microsoft Office 或所有动画均验收。

本阶段验证包括：

- 554 项相关 Rust 回归通过，普通测试运行中 9 项仍按原定义忽略；另补充并通过 1 项“仍在运行的点击组被撤销”测试。相关严格 Clippy、生成 Schema／TS 检查通过。
- WPS 来源、内核文档和重新导出的 PPTX，共 78 个原生采样帧与独立静态显隐页面逐字节一致；同样 78 帧分别通过打包 SDK 的同步及分步 WASM Worker。
- 503 个既有跨端采样完成回归。其中 6 帧因首次保留原生预设／主序列身份而改变时间图与帧摘要；逐字段审计确认其余状态与全部像素仍等于原基线。原失败与旧证据保留，没有删除摘要检查。
- 两份原生导出文件的 10 个 PresentationML 部件通过独立 XSD 校验。

复现工具为 [appearance-fixtures.py](../../tools/verification/appearance-fixtures.py)、[公共 SDK 重放](../../tools/verification/wasm-playback-reference.mjs)及[证据核对工具](../../tools/verification/appearance-evidence.py)。[阶段证据](../reviews/evidence/2026-09-28-appearance-native-verification.json)分别记录计算、实机观察和产品检查。

## Musterwork 接入结果

全部产品修改、构建与测试限定在 `musterwork-musteroffice` worktree、`codex/musteroffice-integration` 分支。原主工作区留给用户。计算边界不变：产品拥有按钮、键盘、时钟、文件与业务状态；SDK 负责文稿语义、播放计算和诊断。

启用播放的桌面前端输出 42 个 SDK 文件，未压缩合计 **18,162,756 字节**，比上一产品阶段增加 215,768 字节。本次升级同时包含上一阶段固定显隐能力。该值只统计 Vite 输出中的播放 SDK；导出 Worker 仍是开发构建，不能据此得出安装包、峰值内存或延迟结论。
