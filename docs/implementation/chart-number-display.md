# 图表数字格式与可排版片段

图表标签的数据绑定现已连接到精确数字显示计算，既有 `pptx-chart-labels` 入口可通过
`numberSymbols` 显式请求该计算。原始十进制值、百分比分子/分母、格式代码及其来源
继续保留；新增结果是可交给文字排版的片段，不是图表已绘制或模板已准入的声明。

## 计算与来源

`mo-charts::number_format::Formatter` 解析一到四段格式，按原始数值的正、负、零选择
数字段。文本段是单独语义，不把数字强行变成文本单元格。使用已有精确十进制和大整数
依赖，显式小数格式按绝对值四舍五入，中点远离零；不经过 JSON/JavaScript 二进制浮点。
百分比直接使用完整数据缓存归一化所得的分数，不从绘图角度逆推。

当前实现包括 0/#/? 占位、整数溢出位、千分位、逗号缩放、百分比、科学和工程计数法、
科学计数进位、负数/零段、空段、八种命名颜色、引号/转义文字及测量型占位。科学计数法
中的文字保持原来的相对位置。重复 `*` 按标准仅保留最后一项；较早项不变成可见文字。

数字格式参考 ECMA-376 Part 1 §18.8.30–31，以及 Microsoft 的
[NumberingFormats 说明](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.numberingformats?view=openxml-3.0.1)。
图表 `c:numFmt` 引用同一格式语言，但实际图表的默认格式、目标应用行为及正文布局必须
分别核对，不能以电子表格的局部导出结果代替整图验收。

## 排版边界

输出 `NumberDisplay` 包含所选段、可选颜色和 `rounded` 数值变化标志，片段分为：

- `text`：确切的可见字符，后续使用普通文字分段、字体绑定和塑形。
- `reserve`：保留指定字形的测量宽度，包含问号占位和下划线占位；不替换成普通空格。
- `fill`：等待可用宽度确定后重复指定字形；计算层不以猜测次数生成长字符串。

缺省 `General` 与可用宽度有关。当前只返回十一字符固定窗口内可精确表示的有限数值；
需要精度选择、科学计数选择或循环小数的情况返回 `generalNeedsLayout`。完整的测量决策
仍需接入，不能静默截断内容。条件段、日期/时间、分数格式、区域指令和索引调色板也保留
带原始 UTF-8 偏移的诊断，待补齐各自语义；它们仍在一期范围内。

## 既有标签入口

请求中的 `numberSymbols` 明确提供 `decimalSeparator` 和 `groupSeparator`，不读取操作
系统区域设置。未提供时保持原有完整响应。提供后，结果保留相同符号，单个标签新增
`formattedComponents`，与已有 `components` 一一对应。自定义富文本仍走自身正文；
文字组件原样保留，数字和百分比组件使用已有来源选择器给出的代码。

显式未链接格式、单点缓存格式和系列缓存格式的优先级沿用已有绑定规则。缺失代码返回
`missingFormat`；尤其不能把值缓存的格式当作已证明的百分比缺省格式。未解析格式只是
局部显示诊断，不抹掉原始数据；预算或取消失败则终止整个标签计算，不发布部分结果。

格式语法按代码缓存，同一次请求共用格式、数值工作量和输出预算。默认最多 128 个代码、
每个 4 KiB、合计 64 KiB；单次数值展开最多 16,384 位，累计 1,048,576 位，小数占位最多
256 位，结果逻辑成本最多 4 MiB。百分比点查找复用有序归一化结果，避免逐标签扫描系列。
这些是有界计算规则，不是 RSS 或完整文稿性能测量。

## 验证与仍开放的差异

[证据摘要](../reviews/evidence/2026-09-30-chart-number-display.json)分别记录原生测试、真实
Native/WASM 结果、独立 Decimal/Fraction 参考及外部应用观察。独立参考只认证明确列出的
数字格式；没有把测试夹具中的预期值当作独立算法证明。

本地 LibreOffice 对 28 项自有 XLSX 格式导出可见 CSV，再与等价 PPTX 标签计算比较。
目前保留四类差异：零值全可选小数位是否显示小数点、仅有小数点的尾部显示、位于小数点
之前的缩放逗号、重复百分号的缩放次数。完整记录保留双方输出，不能计作 Office/WPS
兼容通过。后续按格式来源和实际图表分别校准，而不是把另一应用的回退行为作为内核规则。

继续接入完整图表样式/缺省值、组合标签文字、主题/字体资源、塑形与布局、颜色及留白片段
绘制，再与标题、图例和绘图区合成。Musterwork 本轮未更新验收候选；完整模板、图表编辑、
高级内容和 Office/WPS 门禁保持开放。
