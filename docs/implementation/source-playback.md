# 原生来源页面的动画绘制

状态：原生旋转时间树已接入既有来源页面、图片解码、文字塑形和渐变绘制管线。当前是单页、明确时间与事件历史的实际采样能力；完整效果、转场、媒体和 Musterwork 替换仍未完成。

## 来源语义与求值

`SourcePlaybackPlan` 从经过检查的不可变 PPTX 包和来源索引建立计划。它读取所选 slide 的原生时间树，复用[已有严格时间映射](timeline-rotation.md)，验证目标对象并编译确定性时间计划。不能识别的节点、属性或条件会给出诊断，不以静态页面代替动画成功。

时间节点仍使用内部 `tn.*` / `sp.*` 求值键；每个对象键同时携带其 slide 部件与 native ID 的绑定。相同整数 ID 在母版、版式或另一页上不会成为同一个动画目标。当前形状、连接线、图片及组合可被旋转，尚未完成的 graphic frame 动态语义明确拒绝。

来源 API 的 `binding.revision` 必须等于实际 PPTX 包 SHA-256；宿主负责将产品修订映射到这份源字节及验证授权。这个内容身份不能代替产品版本来源、权限或任务 fence。原有作者快照 API 的 revision 规则不变。

## 一套放置与资源页面

`SourcePlaybackSample` 只能由其计划求值产生，不接受宿主注入任意属性矩阵。它持有精确有理角度和当前时间状态，并借用产生它的页面计划；准备绘制时再次核对包与来源索引摘要。

角度以“部件＋原生 ID”覆盖共享放置引擎的瞬时旋转，进入与作者播放相同的精确角度、DrawingML 组合扇区/翻转及 Q96 误差计算。组合祖先参与同一次放置；不把旋转烘焙进源 XML 或改变原生声明。来源 `NativePlacement.transform` 继续记录原声明的解析值，动态状态由响应中的 `playback` 给出。

图片世界画笔、裁剪、渐变坐标、文字轮廓和装饰线继续消费这份放置与误差界；局部几何、字形与资源解析规则没有第二套实现。结束移除型行为恢复来源声明值；冻结型行为继续覆盖。渐变和图片的既有未实现方向/空间规则仍明确拒绝，不能因增加动画而绕过静态能力门槛。

静态和动态入口共享来源/显式字体准备、页面预检、组件、误差预算和结果验证。实际帧结果附带包/slide 部件摘要、原生目标绑定、精确时间状态、资源页面统计与像素摘要。源字节与来源索引保持不变。

## 接口和生命周期

新增同源合同 `pptx-playback-page-request` / `pptx-playback-raster-response`，以及 `render_pptx_playback_page_json`、WASM `render_pptx_playback_page`、Native 隔离 worker 的 `--pptx-playback-page` 与 CLI `render-pptx-playback-page`。字体仍通过显式 manifest 和字节提供，图片解码/文字/绘制组件分别由宿主提供。

请求由既有资源页面请求及 `PlaybackSampleRequest` 组成；交互历史沿用完整前缀、generation 和事件序号校验。时间失败和资源页面失败保留各自诊断。错误、取消、精度不足或无效组件均不发布部分像素；CLI 沿用原子、不覆盖的文件提交。

Rust 时间计划与采样对象可复用。当前公共 JSON 入口每次重新打开源包、建立索引、准备字体并解码/塑形；它尚未并入[可复用作者页面会话](playback-sessions.md)，也没有保留来源资源缓存。性能数字必须包含这些成本。下一步继续整合来源计划/资源的所有权和缓存失效，不能用单页样例宣称完整实时播放达标。

本入口采样单页内部的时间行为，不负责页面间转场、媒体设备、显示时钟或完整放映状态机。MCP 仍不承担逐帧传输；这些能力最终由 SDK/宿主层驱动。

## 验证

自有输入覆盖文字与图片同页、组合图片、母版/版式/slide 同号对象、圆形渐变的扇区边界及交互点击；源结构由独立 XML/XSD 工具核对。Fraction 参考直接根据原生时间值计算预期旋转；整数状态用独立修改 XML 变换并移除 timing 的文件作精确像素和组件帧对照。回退采样核对结果不变，失败检查不发布像素及组件调用边界。

678 项 Rust 测试（新增 5 项）、94 份同源 Schema/TS、严格 Clippy 与 rustfmt 通过。44 个公共输入及 26 个独立原生静态对照形成 70 次 Native/WASM 成对调用，其中 37 个动画帧成功。56 个精确角度、60 个来源绑定及 3,120,000 个对照像素通过核对；238 个来源/对照部件通过 XSD。355 次旧静态、246 次旧时间及 111 次作者会话命令保持历史行为，后者包含 34 个原动画帧。

局部性能环境：Apple M4 Max、arm64、Darwin 25.2.0、Node 23.5.0，400×300 自有页面，模块已加载；5 次预热后 20 次测量，交替顺序比较动态请求与独立原生变换静态文件。本任务无同时构建/测试，其他系统负载未控制。包含源包索引、字体准备、解码/塑形、绘制与结果传递，不包含冷启动、请求序列化、RSS、显示调度及完整产品。
