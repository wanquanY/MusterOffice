# 开始条件列表与有界触发求值

2026-09-27。继续处理 [WPS 实际回存](wps-timing-roundtrip.md)暴露的条件列表。实现覆盖显式一次激活的时间图，完整主序列、导航、restart 和重复激活继续实施；不能据此接受任意 WPS 回存文件或启动完整 Musterwork 替换验收。

## 模型与合同

`TimeCondition` 是非递归原子条件：At、After、Click、Never。`StartCondition` 接受一个原子条件或非空 `anyOf.conditions` 列表，结束条件仍使用原子列表。单条件 JSON 维持原表示和字段顺序；Never 序列化为 `{"kind":"never"}`，不接受多余字段。Schema 限定列表至少一个条件，嵌套 anyOf 不合法；实际计算同样校验非空、全部引用和预算。

Rust 草案调用方从原来的类型别名改为 `StartCondition::Single(TimeCondition::At { … })` 或 `TimeCondition::At { … }.into()`；已有 JSON 调用方不需要迁移，穷举 TS 条件类型的调用方需要处理新增分支。不增加私有序列化标记。全部公共合同及 TS 声明从同一 Rust 类型生成。

明确的 Never 表达原生无事件、无目标的 `delay="indefinite"`，不会伪造 0 时刻。带事件或目标的 indefinite 目前保持未映射；不丢弃附带语义。

## 求值和性能边界

开始列表在当前父区间/前序节点允许进入之后，选择可解析条件中的最早时刻。同一时刻按宿主事件序号比较。依赖节点实际开始/结束后，新解析的较早条件可以替换较晚的排队候选；旧队列项按完整时刻校验失效。节点开始后不重复激活，不重用已经消耗的点击。

结构上的父开始、前序结束是必须同时满足的约束，候选开始引用是任选其一的约束。编译使用显式条件子句和索引通知，允许有独立入口的反馈引用，例如 A 在 0 时刻或 B 结束时开始，B 在 A 结束时开始；仅有循环依赖、没有入口的图仍拒绝。Never 不作为可触发的入口。结束条件仍采用原有保守因果验证，不能据此宣称已经支持所有原生循环图。

每个条件只在结构激活和它引用的事件到达时求值，不因一个引用解析而重新扫描整张开始列表。队列候选及工作量受原有条件数、节点数和调度步数限制，循环内部继续检查取消。千项依赖通知的测试使用固定工作预算，证明该场景不会退化为逐次全列表扫描；这不是帧率、耗时或内存实测。

共享保留式 sampler 仍绑定 session/revision/generation 和完整事件前缀。同前缀复用区间；新点击或倒退到较早前缀时重新求值候选。即使 At 已可触发，只要列表存在 Click，调用仍须提供完整事件历史，不能假定未提供的点击没有发生。

SMIL 的开始列表规定最早条件和 restart 共同决定激活；indefinite 不生成开始实例。这是当前一次激活算法的参考，不把完整 SMIL 与 PresentationML/WPS 宣称为等价，原生应用仍需独立校准。[W3C SMIL timing](https://www.w3.org/TR/SMIL2/smil-timing.html)

## 原生文件与编辑

Writer 按列表顺序写多个 `p:cond`，Reader 通过共享条件解析器恢复；行为与有身份的容器共用同一规则。单条件仍恢复为旧原子表示；只有一个元素的 anyOf 经过 PPTX 回读会规范化为原子条件，不声称 JSON 结构保持不变。引用、事件、延迟及目标不得因条件未胜出而省略。

XML 捕获分别计算结构和条件额度，避免仅按节点数量预留导致合法长列表提前被拒绝，也防止条件额度扩大无关 XML 的结构上限。最终时间图仍检查独立条件预算。空列表、未知事件、缺失目标、未映射 indefinite 属性均明确失败。

文档验证检查全部触发目标。删除对象时 RejectDependencies 原子拒绝；Cascade 按完整引用闭包移除相关行为/容器和后继依赖，即使引用位于较晚候选中也不忽略它；不会擅自删除一个候选来改变文稿意思。
