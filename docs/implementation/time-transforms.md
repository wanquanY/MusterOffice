# 行为变速、反向与加减速

状态：既定 Rust／TS／精选 C++ 路线继续实施。有限行为时钟已接入作者文档、原生 PPTX、分层时间树和 Native/WASM 真实页面采样。本阶段扩展的是已有旋转行为；完整效果、转场、媒体、高级对象与 Musterwork 替换验收仍在推进。

## 共享时钟

`TimingNode.timeTransform` 是可选声明，适用于已有 `0.1-draft` 平面图和 `0.2-draft` 时间树的行为叶子。字段为 `speedMilliPercent`、`autoReverse`、`accelerationMilliPercent`、`decelerationMilliPercent`。速度为非零有符号整数，100000 表示正常速度；两个加减速比例为非负整数，合计不超过 100000。缺少整个声明时使用正常速度、不往返、无加减速；显式声明必须提供全部四个字段，避免第二套隐式补值规则。

编译时为每个行为建立同一个 `BehaviorClock`，平面图和时间树都使用它计算活动时长与采样进度。结构求值不再各自维护重复次数和末端边界算法。时钟仍使用受位数预算约束的有理数，不用帧率或浮点时间近似；宿主继续持有实际时钟、输入事件和显示队列。

声明时长为 D、重复次数为 R、速度绝对值为 S 时，父时钟中的活动时长为 `D × (autoReverse ? 2 : 1) × R / S`。开始偏移仍按父时钟计算。顺序容器、结束依赖和自动容器时长都使用变速后的活动结束；fill 不延长活动时间。

负速度从完整有限活动区间的末端反向求值，包括分数重复的尾段。随后拆分重复轮次、折叠自动往返的两条腿，最后应用加减速。祖先提前截断只限制采样区间，不重新定义子项声明的完整反向时钟。正向结束或截断恰落在整轮边界时保留前一轮终点；反向激活使用完整活动区间的末端，反向内部边界和最终零时刻使用对应简单时间的零值。

加减速是线性速度变化的积分，而非任意贝塞尔缓动。加速比例 a、减速比例 b 对应标准化匀速段速度 `2 / (2 − a − b)`；三段进度连续并保持总时长。支持全程加速、全程减速和两段相接；a+b 超出 1 明确拒绝，不丢弃设置。该严格输入规则与一般 SMIL 的无效值处理不相同。

## 原生 PPTX 与编辑

有限 `p:animRot` 行为的 `p:cTn` 读写 `spd`、`autoRev`、`accel`、`decel`。作者导出使用原生属性，动画依然是可编辑旋转行为；没有以逐帧图片替代。未声明 timeTransform 的旧导出字节保持不变。读取任意一个相关属性时，按原生默认值组成完整声明；原始 XML 的词法表示仍保留在来源包中。

百分比复用共享 `NativePercentage` 语法读取。整数千分之一百分比和可精确转换的十进制百分比均可投影，负速度覆盖完整 i32 范围。过细小数、越界值、非法布尔值、零速度或无效比例明确诊断，不能通过舍入让文件看似受支持。原生语法校验、投影精度和时间模型验证各自承担本层职责。

`setTimeline` 仍通过既有原子事务入口提交；生成的 96 份 Schema/TS 合同同源更新，不在 TS 中实现另一套时钟。查询、导出后重新读取、作者会话及持有图片/文字资源的来源会话都执行共享时钟。

当前未实现容器上的速度/反向/往返、容器重复、重启、repeatDur、不定重复、完整原生默认值和条件组合。它们继续属于一期目标，读取时保留明确诊断。时间树被投影和播放不代表任意来源动画的保留式编辑已经完成，也不代表 PowerPoint/WPS 已实际验收。

## 验证与体积

[阶段证据](../reviews/evidence/2026-09-26-time-transform-verification.json)绑定实现、合同、构建和返回结果。工具使用 `time-transform-` 前缀，当前输出在 `.codex-work/time-transform`；之前的封存证据和产物保持不变。

- 全仓 703 项 Rust 测试、96 份 Schema/TS、严格 Clippy 和格式检查通过。8 项新增测试覆盖反向分数重复、往返、比例交界、速度极值、开始/结束依赖、祖先截断、向后跳播及原生词法拒绝。
- 33 组作者文稿包含 471 个独立参考采样。Python Fraction 通过梯形面积积分速度曲线，与生产代码的分段闭式公式分开计算；公共入口和原生导出重读共核对 494 次求值。
- 877 次 Native/WASM 调用一致。51 个作者帧、60 个含图片/文字的原生来源帧比较逐次和保留式采样，95 个静态变换对照核对同一实际画面；来源保留式采样的图片解码、文字塑形、字体上传和 gather 计数均为零。
- 来源样例及静态对照的 390 个 PML 部件通过固定 XSD；2 份作者导出包另有 6 个部件通过 XSD，独立 XML 遍历核对 7 个时间项的层级、时长和时钟属性。
- 旧 355 次静态绘制、246 次时间接口、111 次作者会话、70 次来源逐次/对照、135 次来源会话以及上一阶段 562 次时间树调用完成回归；旧请求、响应和已记录帧/像素不变，旧时间树导出的 PPTX 字节也不变。

真实像素预览只使用返回 RGBA；其中自有合成字形用来检查文字资源随对象运动，不代表真实字体视觉质量验收。当前未增加 PowerPoint/WPS 动画播放观察。

Rust WASM 原始模块为 7,778,080 字节，比上一阶段增加 31,658 字节。C++ 绘制 WASM 保持 2,370,691 字节，依赖锁文件未变。没有新增 FPS、吞吐、RSS、冷启动或安装包测量；这些模块大小不等于完整运行依赖闭包或 Musterwork 最终安装包。已有渐变性能缺口仍开放。
