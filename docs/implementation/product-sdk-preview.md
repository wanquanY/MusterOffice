# Musterwork 纯计算 SDK 与原生预览接入

2026-09-28，接续[独立产品 worktree](product-worktree.md)中的实现。`MW:` 是产品仓库相对路径；产品代码留在产品仓库，MusterOffice 没有引入权限、持久存储、业务任务或人的页面。

## 当前实现

产品固定 SDK 从旧宿主版本升级到清单 `550e264393618a838c8d0cf722184ef939373bd0dfc91d2c4a8c2da87f5dda31`，消费 `musteroffice.computation/1-draft`。完整核对 556 个清单文件；Cargo 依赖闭包移除 `mo-operation-service`，增加公共计算和原生调用所需的三个本地 crate，注册表依赖版本未变化。创建/原子编辑直接使用计算候选的 Snapshot；产品仍拥有 Invocation、资源读取、额度、取消和原子提交。

旧适配器把 NotAuthorized、ResourceBusy 和 StorageFailure 当成内核 FailureCode。现在由产品自己的 `OfficeAdapterFailure` 区分计算错误与产品错误；计算诊断的 code/message/detail 保留，产品权限和持久存储失败不再进入内核枚举。显式输入绑定缺失使用计算协议的 ResourceIncomplete，不能把 SDK 资源别名当成账号权限。

导出固定 worker 的 SHA-256 为 `b93e718a02d8620b56c5627ad0c2066cd84cdb694a6fe2d7818399d752a557d0`。本次使用 macOS ARM64 开发二进制，38,694,800 字节；这是实际测试材料身份，**不是发行包体积或性能结论**。冻结 SDK 和 worker 的独立消费已实测兼容，但不覆盖核心工作区尚未完成的序列导航改动，也没有重建完整发行产物。

## 产品预览与下载

桌面、Web、共享会话现在识别 `presentation-artifact/4`，校验清单原始字节、根摘要、Artifact/版本和完整依赖集合。旧格式继续走各自解析器；重复字段、引用替换和版本不符不会被当成原生清单读取成功。

预览初始化仅读取清单。页面由当前视图按需请求，并再次核对长度与 SHA-256；不把整份文稿转换成 base64，不为清单预览提前下载 PPTX 或加载 ZIP 解析器。当前策略仅保留正在显示页面的一个 Blob URL，切页取消旧请求，晚到结果不能覆盖新页面；关闭或共享读取范围失效会释放 URL。当前页读取失败可显式重试。导航仍可选择全部页面，未访问页面暂不生成缩略图。

Web 下载原生 PPTX 时验证实际下载字节。桌面预览与落盘分离，已有打开/导出动作继续由产品 materialization 端口执行；这一阶段没有完成外部 WPS/Office 修改后的再导入流程。共享会话只使用原 retained read scope，不能退回账号 HTTP 或本地文件；运输缓冲区使用后清零。

查看器明确标记静态页面预览，并展示原始五类质量状态。编辑态图片不证明动画、音视频或转场可播放。来源报告中的 not_proven 保持原值，没有因显示成功改为 passed。播放器与完整原生编辑界面尚未接入。
