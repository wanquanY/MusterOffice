# 行为结束条件与共享事件调度

状态：沿既定 Rust／TS／精选 C++ 路线继续实现。行为叶子的显式结束条件已经连接共享时间求值、原子编辑、原生 PPTX 和作者／来源页面。当前效果仍为旋转；容器结束条件、重复激活、重启、完整效果与 Musterwork 替换验收继续推进。

## 数据与事件依赖

`TimingNode.endConditions` 是可省略的条件数组，空数组序列化时省略。每个条件与 start 使用同一个 `TimeCondition` 类型：`at`、引用某时间项 begin/end 的 `after`、页面或对象 `click`。Rust 保留 `StartCondition` 类型别名，原有 JSON 字段和值不改名。条件按声明顺序保存，求值采用最早的有效结束；声明顺序不构成依次执行。

平面时间图和分层时间树现在共用 begin/end 事件有向图、调度和帧采样，删除原先独立的平面调度实现。旧版本仍保留原来的 wire、摘要域和帧 profile；不为复用计算给旧文稿添加合成容器。引用依赖落在具体 begin/end 事件上，因此 `A.end ← B.begin` 与 `B.begin ← A.begin` 可以共同成立；真正的事件循环继续明确拒绝。

编译限制所有 start 和 end 条件的总数，`TimelineLimits.max_conditions` 默认 65,536；逐条件检查取消、引用与非负时间。既有节点、事件、树深度和精确数值位数预算继续生效。时间/事件预算错误不会变成部分画面。

## 结束时间与点击顺序

`at` 相对当前启用同步基准：并行子项使用父项开始，顺序后继使用前项实际结束。它不是相对行为自己的 start 再加一次偏移。`after` 使用所引用事件的实际时间与 delay。显式 end 的偏移位于父时钟，不乘行为速度。

点击条件选择行为已经激活后可用的第一个匹配点击，并加 delay。激活前的点击和已经用于启动该行为的同一个事件不能再作为停止事件；相同时间戳按事件序号区分。一次点击可供独立行为共同响应，顺序后继则须尊重前项结束的事件序号。结束序号来自实际胜出的原因，较晚且未胜出的点击不能被提前消耗。

行为的自然结束取重复时钟上限与显式结束的较小值；祖先截止仍单独处理。结束条件尚未触发时保留未知，顺序后继继续等待。回放只使用采样时刻以前的事件前缀，向后 seek 不依赖某次前向采样留下的可变状态。

当前一次激活 profile 要求候选结束不早于实际激活。若所有条件都已解析且全部位于激活之前，返回带行为 ID 的诊断；没有实现完整 SMIL 的无效区间丢弃、后续区间寻找或重新激活规则。若仍有未发生的点击或未知事件，可以继续等待它。这项限制不改变完整一期目标。

## 倒放与祖先截断

显式结束会改变行为的活动区间，倒放使用该区间的有限终点作为反向起点。自然重复终点较早时仍取较早值。祖先提前截断只停止子项，不重定义一个已经由行为本身确定的反向范围。

无限倒放可使用已解析的显式结束；如果没有自然终点，既有祖先截止仍可提供有限范围。如果采样时仍无有限终点，则继续返回明确诊断，不猜测未来点击或虚构循环次数。同一播放 owner 在诊断后仍可执行合法的开始前采样。

## 文件与编辑

叶子 `p:cTn/p:endCondLst` 原生读写使用与开始条件共用的 condition 解析／写入层，保留条件顺序、原生时间节点引用、对象／页面目标。当前支持 delay、onBegin、onEnd、onClick；未知事件、空列表、重复列表、错误目标、循环和缺失引用被明确拒绝。不可精确转换为原生 unsigned 毫秒的时间不舍入导出。

容器结束列表尚未进入作者与来源计算模型，继续诊断，不将其展开为近似的叶子时间。原始来源包与 XML 保留机制不变。已支持的旋转和条件导出为原生可编辑声明，不以图片模拟动画。

对象引用集合现在包括结束点击目标；时间依赖闭包包括结束条件引用。删除策略 `rejectDependencies` 原子拒绝，`cascade` 同时删除受影响行为及传递依赖并更新树。没有剩余行为的容器仍保留其合法计时身份，不擅自删除用户的结构声明。
