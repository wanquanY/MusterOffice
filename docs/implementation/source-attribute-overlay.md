# 来源属性的保留式编辑

状态：P03 XML 来源层开发实现，2026-09-26。完整一期及 Musterwork 替换仍在推进。本阶段提供格式适配器可调用的属性事务底座；尚未将物理 XML 序号公开为 Agent 操作，也不等于已完成 PPTX 对象属性编辑服务。

## 编辑责任

`mo-xml::rewrite_attributes` 接收不可变原始 XML 与一批属性变更。每项包含物理元素序号、预期元素展开名、属性展开名、预期旧值和目标值。物理序号包含未选择的 MCE 分支，不能代替文档对象身份。上层格式适配器必须先绑定包摘要、对象/属性身份、继承来源和多表示约束；不能让 Agent 直接猜测序号修改原生文件。

`expected_value = None` 严格断言属性不存在，空字符串严格断言属性存在且为空。目标 `None` 表示删除，目标空字符串表示保留显式空值。旧值使用 XML 规范化后的字符值，不进行 Unicode 归一化。重复目标、名称/旧值不符或任一目标不存在时，整个调用失败，不返回部分候选。

已有属性保留原有前缀、单双引号和等号周围空白，仅替换值区域。删除只移除所选属性的名称至结束引号；其余空白保持原字节。新增属性确定性排序并写到当前开始标签末尾；有命名空间的属性必须显式指定已在该元素作用域中绑定的 QName。默认命名空间不应用于无前缀属性。

此操作不新增或改写 `xmlns` 声明，因为它会改变任意后代名称和 QName 属性的含义。需要修改命名空间时，后续结构编辑器必须处理完整受影响范围，不能作为普通值替换执行。

## 字节与验证

共享 XML 扫描器先验证完整输入。词法定位器只在已验证的开始标签内寻找属性值和引号位置；调用方不能提供字节偏移。文字与属性编辑现在共用同一编码保留模块，将解码后的 UTF-8 范围映射回原始 UTF-8/UTF-16 字节。

UTF-8 BOM、UTF-16 字节序及 BOM、未修改实体拼写、注释、PI、CDATA、子元素、未知扩展和其他属性都保留。属性中的制表符和换行使用字符引用，以免重读时被 XML 属性规范化改变。成功候选必须再次经过完整扫描，并逐项核对实际名称和值；格式合法但值不符合意图同样失败。

输入、修改数、修改文本、转义内容、输出字节及 XML 属性数量均有上限。预检、扫描、词法定位、转义、编码和结果验证支持取消。新增底座不引入第三方依赖，也不取得文件、网络或宿主权限。

## 验证范围

全仓 628 项 Rust 测试、严格 Clippy、rustfmt 以及 82 份 Schema/TS 同源检查通过。新增测试包括六种编码/BOM 组合、命名空间遮蔽、别名前缀、删除与插入相邻、缺失与空值、Unicode/字符引用、错误旧值、重复目标、输出预算和取消检查点。独立验证工具使用 lxml/libxml2 与手工词法预期分别核对语义及保留字节；416 个 Native/WASM 诊断用例的返回字节、错误和取消检查次数一致，其中 386 个成功候选通过独立解析。这些探针不是公开产品 API。

共享编码模块的重构也通过既有 PPTX 来源检查和文字编辑入口回归：当前 Native/WASM 与上一阶段 WASM 的 121 次调用一致，包括 72 次来源检查、42 次成功编辑和 7 次预期拒绝。CLI 新文件提交、拒绝覆盖、失败不留结果及无临时文件残留通过。构建、产物摘要及限制由[阶段证据](../reviews/evidence/2026-09-26-attribute-edit-verification.json)绑定，不能以独立 XML 用例声称 Office/WPS 已验收完整编辑。

当前 Rust 产品 WASM 为 6,436,330 字节，较上阶段增加 66 字节；其公开接口尚未调用新属性编辑器，因此不能将这个增量当作完整属性服务的体积。单独 XML 诊断 WASM 为 341,898 字节，包含探针包装和共享依赖，也不能直接相加推断最终包。C++ 绘制 WASM 仍为 2,352,940 字节，依赖锁未变。本轮没有重测页面性能、内存或 Musterwork 安装包。

## 固定方向渐变的待验证项

原生 `rotWithShape` 表示填充是否随形状旋转，见[微软属性说明](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.gradientfill?view=openxml-3.0.1)。它没有单独给出本项目所需的所有组合缩放、翻转和近退化行为；当前不能仅删除拒绝条件便宣称支持。

已生成 30 份自有原生 PPTX，形成 15 对固定/随形状旋转对照，覆盖线性、矩形、圆形渐变，以及普通旋转、直角、水平/垂直翻转和非均匀组合变换。210 个 XML 部件通过官方 XSD；这些只是待观察输入，没有生成或假定目标应用截图。

本机 cua-driver 守护进程缺少辅助功能与屏幕录制权限，已停止该原生应用操作并向用户说明。固定方向渲染策略保持未验收，原生图形未展平。后续先完成真实应用观察，再将规则接入共享画笔；属性编辑底座会用于受源摘要约束的语义操作，避免重写整份 XML。

## 开发入口

- `attribute-edit-checks.py`：workspace、同源合同、原生宿主、Rust WASM 和独立 XML 探针构建。
- `attribute-edit-reference.py` / `attribute-edit-parity.mjs`：独立 XML 参考及双端执行。
- `attribute-edit-product-parity.mjs`：当前 Native/WASM 与上一阶段 WASM 的实际来源检查、文字编辑和文件发布回归。
- `stationary-gradient-fixtures.py`：只生成合法自有观察语料，不替代实机观察。

产物分别存于 `.codex-work/attribute-edit` 与 `.codex-work/stationary-gradient`。封存后不得原地覆盖，后续工作使用新阶段目录。
