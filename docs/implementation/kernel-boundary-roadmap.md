# 纯计算接入实施目标

2026-09-27：用户明确授权按新边界继续实现并持续推进至可直接接入 Musterwork。本页补充原完整一期目标，依据 [ADR 0007](../decisions/0007-kernel-only-integration-boundary.md)，不降低原能力、质量、可编辑性和跨端要求。

## 完成目标

提供面向 Agent 的完整 PPT 内核。公共 SDK/MCP/CLI 可独立创建、导入、查询、原子编辑、渲染、播放、验证和输出原生可编辑 PPTX；动画/转场、音视频、SmartArt、公式和其余一期能力照常验收。权限、持久任务、文稿/资源存储、业务提交和全部面向人的页面由接入产品承担。

Musterwork 通过公共接口和自己的资源/任务/Artifact 适配直接使用内核，保留历史资料及既有产品流程。完成条件是实际端到端调用、完整质量/互操作证据和同条件性能/体积测量达到替换验收门槛，不以包装完成或单个静态样例视为整个目标完成。

## 实施次序与状态

| 阶段 | 交付与退出条件 | 当前状态 |
| --- | --- | --- |
| K1 计算合同拆分 | 计算库不依赖旧宿主/权限/Job 类型；旧协议在兼容层保留原语义；Native 导出及 SDK 消费新合同；验证原子性、取消、资源完整性与兼容 | 当前已实现计算范围通过；旧宿主/MCP 的正式路径迁移归 K3 |
| K2 易用 SDK | 输入、操作、结果的直接调用及常用内存/流适配；无需账号、JobStore、数据库或业务提交器；真实文件输出 | Native 创建/导入/原子编辑/导出及独立打包消费通过；[原生播放 SDK](native-playback-sdk.md)、[TS/WASM 离线包](wasm-playback-sdk.md)与[浏览器 Worker](browser-playback-sdk.md)接通已有采样，71 个旧帧保持像素。完整能力、高层跨端接口、取消性能与其余浏览器/实际 WebView 继续实施 |
| K3 薄 Agent 入口 | CLI/MCP 共用计算，按输入输出桥接工作；无自有持久库/页面，独立客户端及 Skill/Plugin 验证 | CLI、默认本地 MCP、可选 2026 HTTP 及 [Skill/Plugin 开发包](agent-package.md)已接入共享计算；清单、包搬迁与实际导出通过。客户端激活、附件、旧版 HTTP 与正式发行继续实施 |
| K4 产品适配 | Musterwork 消费公共发行输入，原任务/权限/存储/提交保持产品所有；逐项核对历史产品改动，修复实际接入缺陷 | 待完成 |
| K5 完整替换验收 | 原一期能力、Native/WASM、Office/WPS、I01–I20/MW 门禁、完整包与性能证据分别通过 | 待完成 |

[计算合同与直接 SDK](computation-boundary.md)记录首轮实现及实测证据。K1–K4 可逐步接通已实现能力，不能掩盖 K5 缺口。持续沿用同一计算实现，不为演示维护另一套引擎。旧宿主及持久数据先隔离兼容责任，再确定退役路径，不通过关闭验证或删除历史材料完成拆分。

## 状态说明

本轮开始时目标工具返回原目标 `paused`；随后用户更新目标，明确排除权限、持久存储、业务任务和产品 UI，工具已确认新目标为 `active`。继续按本页与 ADR 0007 执行；实际源码与验证进展记入[实现进度](progress.md)。
