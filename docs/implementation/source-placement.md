# 原生 PPTX 对象坐标

2026-09-25：真实来源对象的组合坐标、位置/尺寸继承及方向选择已接入 Rust 范围读取、CLI 和 WASM。作者页面与来源页面共用同一套 Q96 区间坐标计算，不把来源对象转换成会丢失声明的作者模型。本轮实现与验证绑定[证据](../reviews/evidence/2026-09-25-source-placement-verification.json)。

这是来源页面编译的一层。**完整页面绘制、Office/WPS 一致性和 Musterwork 替换门禁仍未完成。** 本轮 WPS 观察发现了真实差异，见下表，不能以数值测试通过替代目标应用验收。

## 计算与来源

开发配置为 `drawingml-source-sector-scale-q96-v1-draft`。请求绑定包摘要、表面部件和原生对象 ID；结果保持请求顺序和重复项。只求请求对象及其组合祖先，按需索引继承表面；循环、顺序错误、预算耗尽和取消不会返回半份成功结果。默认限制为 256 个查询、100000 个索引对象、1000000 步及 128 层组合/占位符链。

- 组合保留 `off/ext/chOff/chExt` 四组独立值。子原点参与中心映射，奇数 EMU 的半单位中心保持精确，不先取整数或浮点舍入。
- 组缩放采用已有的 DrawingML 角度分区和翻转方向语义，不能用普通仿射父子相乘替代。共享实现见[坐标核心](../../crates/mo-presentation-compile/src/placement_core.rs)；既有作者页面结果保持不变。
- 子尺寸某轴为零或省略时，该轴不缩放；有效子空间尺寸采用该轴目标尺寸，保证旋转中心仍正确。[MS-OE376](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oe376/d0f234dd-61e9-418e-aa02-24cbb85fe299)说明 Office 的非零除法及零/省略行为；本轮 LibreOffice 另有实际文件观察。这不代表 WPS 的退化组合行为相同。
- 本配置保留但不施加页面/版式/母版 `spTree` 的根组合变换，返回 `rootTransformIgnored`；嵌套 `grpSp` 正常参与。根变换是源声明的一部分，原文件不改写。
- 位置和尺寸沿用来源占位符的逐项解析及最终声明位置。方向取最近一个实际存在的 `xfrm`：该节点缺少的 `rot/flipH/flipV` 使用 0/false/false。没有变换节点才继续沿匹配链查找。此规则是当前 draft 的明确选择，**空/部分变换与 WPS 存在差异**，不能描述成已认证的通用 Office 规则。
- `graphicFrame` 保留自己的旋转/翻转声明，但本配置不应用这些方向属性；上层组合方向仍参与。该选择依据 Office 实现说明，尚未完成本轮目标应用图表/表格观察。

每个值携带 `declaration` 或 `default` 及对象来源。输出同时包含原始解析尺寸、有效子空间、局部锚点、世界矩阵和逐系数误差界。使用顺序是 **路径点减锚点，再应用世界矩阵一次**；不要再次叠加祖先矩阵。原生路径编译已把 `a:path@w/h` 缩放到对象尺寸，不能在此重复缩放。

未知变换属性/子树保留物理节点序号，计算返回带责任对象的 `retainedTransform`；受影响子对象沿用祖先诊断。已知声明的重复、顺序、负尺寸及叶节点语法错误直接拒绝来源检查。缺失坐标、继承异常、标准坐标范围和数值表示范围分别诊断，不用零或单位矩阵伪装成功。合法零尺寸组使用配置中明确的默认规则。

## 接口

```sh
mo-cli pptx-placements query.json source.pptx
```

```json
{
  "expectedSourceSha256": "实际源文件的 SHA-256",
  "surface": "/ppt/slides/slide1.xml",
  "objects": [99],
  "profile": "drawingml-source-sector-scale-q96-v1-draft"
}
```

摘要示例是说明性占位符，不是可通过请求。WASM 为 `place_pptx_objects(request, sourceBytes)`；Rust 范围读取入口接受来源/计算预算和取消回调。公开结果为 `evaluated` 或类型化错误，各对象另有 `resolved/unresolved`。Schema 与 TS 从 Rust 类型生成，当前仍是开发接口，尚未代替完整 OperationService/MCP。

## 实际验证

- 371 项 Rust 测试、严格 Clippy、rustfmt、63 份 Schema 和 TS 检查通过。新增 8 项测试覆盖组合子原点、零轴、旋转、继承边界、graphicFrame、根声明、未知语义传播、畸形输入、摘要/预算/取消和非法父图。
- 146 个真实 PPTX，334 批新增 Native/WASM 检查：146 个来源读取、156 个坐标请求、16 个原生路径编译、16 个实际场景绘制。响应字节和实际像素一致。绘制显式使用红色诊断画笔，不代表来源填充/效果已连接。
- 独立 Decimal 140 位计算核对 363 个对象、2178 个矩阵系数和 1815 个控制点，误差均在返回区间内；另独立核对 1637 个原始变换及 3 个未知节点位置。
- 137 份幻灯片 XML 通过官方 Transitional XSD。其余 9 份为明确的未知/越界/畸形探针，不计为结构通过。
- 旧 9067 批在新产物上全部重跑：9066 批记录完全不变，1 个 LibreOffice 往返来源用例仅增加原本未投影的根变换；请求、旧数值、几何、矩阵、文件编辑和像素结果未放宽比较。独立作者页面参考再次核对 8807 个对象、52842 个系数和 44042 个控制点。
- 当前累计 **9401 批主内核跨端检查**。这是低层验证数量，不是用户场景覆盖率或 Office/WPS 验收数。

## 目标应用观察

本地 macOS arm64，WPS 12.1.22553（22553）、LibreOffice 26.2.0.3。使用本项目合成矩形文稿：WPS 后台打开并检查真实编辑画布，LibreOffice 输出 PDF 后读取实际绘制路径。只记录所测矩形的可见性和近似范围；没有编辑/保存/重开或 Microsoft Office 认证。完整窗口截图留在忽略目录，公开证据只有自有幻灯片的像素统计和摘要。

| 探针 | 当前 draft / LibreOffice | WPS 观察 |
| --- | --- | --- |
| 非零页面根变换 | 不移动子对象 | 同样不移动 |
| 非零子尺寸、非零子原点组合 | 矩形正常缩放/平移 | 所测矩形范围一致 |
| 零子尺寸组合及其 90° 变体 | 子对象按单位轴缩放显示 | 两个探针均未见红色子对象 |
| 占位符无本地变换 | 继承母版方向和位置/尺寸 | 所测矩形同样继承 |
| 占位符本地空变换 | 位置/尺寸继承，方向回默认 | 仍显示母版旋转 |
| 占位符仅声明 `rot=0` | 位置/尺寸继承，方向为零 | 未见红色对象 |
| 占位符完整位置/尺寸变换 | 使用本地坐标，方向回默认 | 所测矩形正常显示，方向相同 |

这些差异是未关闭的互操作问题。需要扩大 Office/WPS 实际样本并明确各目标配置；对新建或修改后的导出，还需验证显式、等价的原生声明能否消除缺省差异。不得静默修改导入源文件、扁平化成图片，或把本配置贴成已兼容标签。
