# 分层时间树与局部时钟

状态：继续既定 Rust／TS／精选 C++ 方案，扩展原有单次激活旋转链路。已实现显式并行/顺序容器、作用域计时、原生 PPTX 读写、事务依赖清理和真实页面采样。完整动画、转场、媒体、高级可编辑对象、生产 Agent 分发与 Musterwork 替换验收仍未完成。

## 模型与边界

`mo-timeline` 的 `musteroffice.timeline/0.2-draft` 使用 `tree.roots` 和 `tree.containers` 表达结构，原有 `nodes` 保留行为叶子。容器有稳定 ID、`parallel`/`sequence`、开始条件、`automatic`/`fixed`/`indefinite` 时长、`remove`/`freeze`/`hold` 和有序子项。每个叶子或容器必须恰好归属一个父容器或根列表；结构与开始/结束依赖分别检查，拒绝循环、重复归属、丢失引用和过深嵌套。

旧 `0.1-draft` 不携带 tree，序列化时省略空 tree；原有文稿、计划摘要、时间状态和像素结果保持不变。`0.2-draft` 必须携带 tree，并使用新的计划摘要域及 `musteroffice.rotation-tree-frame/0.2-draft`。新帧附带容器状态和 `suppressed` 状态。JSON Schema／TypeScript 从共享 Rust 类型生成，不增加第二套时钟实现。

容器仍只激活一次。行为保留已有正时长、千分之一重复次数和精确多圈旋转；容器重复、重启、速度、反向、多个开始/结束条件、导航事件、其他效果及子目标尚未完成。该边界是当前实现状态，不能用于缩减一期范围。

## 时间、事件和显示作用域

相对偏移从父容器开始计算；顺序容器中后一个子项从前一个子项的活动结束计算。并行项共享父时钟。自动时长等待全部子项结束；尚未触发的交互项使自动结束未确定。固定祖先的结束时间截断后代，即使中间存在自动或不定时长容器。没有叶子的容器仍可作为独立计时器。

编译生成开始/结束事件依赖 DAG；自动结束依赖子项结束，子项开始依赖父项开始与最近的固定时长约束，避免把父子作用域错误变成循环。执行保持有理数运算，未改为浮点时间表或固定帧率索引。

点击按已验证的完整事件前缀求值。子项只接受作用域启用后、事件序号晚于启用事件的首个匹配点击。顺序容器的结束事件携带必要的点击序号，包括空计时器经自动父项完成的情况；同一时间戳的前一个点击不能被后继再次消费。显式 begin/end 依赖若早于作用域启用，不重放到启用时刻。宿主依然负责输入采集、时钟、显示队列、取消与 generation 隔离；内核不新增常驻系统时钟。

活动区间与显示保持分别处理：

- `remove` 在自然结束后恢复基础内容；`freeze` 在父项持续活动或保持时保存末状态，但顺序容器中的后续兄弟启动会结束该保持；`hold` 随父项继续保持。
- 父项提前结束且保持时，尚在活动的子树在截断位置保持，即使子项自身声明 remove。自然结束早于或恰好等于父项结束的子项仍遵从自身 fill。
- 持有父状态会钳制后代采样时钟；没有在有效作用域中开始的项被抑制，不在结束后补启动。保持状态不延长活动结束或推迟顺序后继。
- 同一对象的替换式旋转仍按最近激活优先；时间相同按显式树遍历顺序决定，不能用叶子存储数组顺序替代树顺序。

默认预算为总计 10,000 个容器/行为、128 层时间树、65,536 条事件、1,024 位精确中间数。Native XML 深度和包大小另受既有 XML/OPC 预算限制。结构与事件 DAG 迭代验证；采样建立按目标有序的点击索引并二分查询，没有每个节点扫描完整事件列表。

## 编辑与原生文件

既有 `setTimeline` 事务接收新树；回执仍报告 `changedTimelines`。模型验证包含容器的对象点击引用。删除对象时，拒绝策略保持整个快照；级联策略同时删除直接依赖、显式事件依赖闭包及被删除容器的结构后代，再清理父项引用，不把子项提升到另一套时钟。保留的顺序项维持相对顺序。空容器的身份、时长和外部依赖仍有意义，因此不因没有绘图叶子而擅自删除。

PPTX 原生写入 `p:par`、`p:seq` 与各自 `p:cTn`，保留树顺序和原生时间 ID；叶子仍为可编辑 `p:animRot`。固定时间精确转为 unsigned 毫秒，不可精确表达时拒绝导出。自动时长写为 `dur="indefinite"` 配合 `endSync(evt=end, delay=0, rtn=all)`；不定时长没有该结束条件。空容器省略 `childTnLst`，不产生 XSD 不允许的空列表。

读取保留 tmRoot 内部的实际层级，并绑定原生时间与对象身份。当前只接受已映射语义：显式 restart=never、受支持 fill/时长/条件，以及默认或关闭导航的顺序容器。未映射的并发导航、next/prev 行为、额外属性和其他行为仍明确诊断。未带容器的 `0.2` 根森林在导出后可按等价 `0.1` 原生并行列表读取；私有作者版本不是 OOXML 字段，不为保留内部版本人为添加容器。

读取投影不代表已经实现任意来源动画的保留式编辑，也不等于 Office/WPS 已观察验收。原始源包不变，来源资源播放会话仍复用局部图片/文字资源并通过同一放置与精度链路绘制。

## 验证和成本

[阶段证据](../reviews/evidence/2026-09-26-timing-tree-verification.json)绑定源码增量、构建产物、请求、响应、帧和历史回归。验证工具为 `timing-tree-` 前缀，当前产物位于 `.codex-work/timing-tree`；此前封存产物不重写。

本阶段通过 695 项 Rust 测试、96 份 Schema／TypeScript 检查、严格 Clippy 与格式检查。25 组创作文档使用独立 Python Fraction 闭式区间公式；公共接口及原生导出后重新读取共核对 278 次时间采样。562 次 Native/WASM 调用一致，包含 39 个作者帧和 48 个原生来源帧的逐次与保留式采样比较；57 个静态变换对照直接核对同一画面。来源保留式采样的解码、塑形、字体上传及 gather 计数保持零。

4 类原生资源样例覆盖顺序 freeze/hold、自动容器被父项截断、同一时刻的有序点击，并使用非整圈终态使保持差别可见。原生样例和静态对照的 144 个 PML 部件通过固定 XSD；2 份作者导出包另有 6 个部件通过 XSD，7 个时间项由独立 XML 遍历核对层级、顺序、时长、条件和 fill。实际像素预览只来自返回的 RGBA；文字为自有合成字形，不构成真实字体视觉质量验收。

旧结果回归包括 355 次静态绘制、246 次时间接口、111 次作者会话、70 次来源逐次/对照调用及 135 次来源会话调用；旧请求、响应和已记录帧/像素字节保持一致。新树作用域验证没有放宽旧结果断言。

Rust WASM 原始模块为 7,746,422 字节，比上一阶段增加 157,495 字节。C++ 绘制 WASM 保持 2,370,691 字节，依赖锁文件未变。本阶段没有新增吞吐、RSS、冷启动或完整依赖闭包/安装包测量，不能把原始模块体积当作 Musterwork 最终包体积。之前渐变页面的性能缺口仍开放。
