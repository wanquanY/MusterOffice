# 原生模板后端阶段编排与文件传递

2026-09-28，Musterwork 独立集成 worktree 将原生模板定义与压力计算接入原后端协调器、阶段日志和 Runtime 传输。MusterOffice 仍只提供计算；任务、租约、取消、内容库及目录事务继续由 Musterwork 拥有。

本阶段没有启用自动上传的原生默认策略。`native_verify` 实际质量计算和原生目录发布尚未完成，当前不能认为模板上传或完整 PPT 替换已验收。

## 阶段与进度

显式冻结的 `presentation-compilation-policy/3` 使用整份来源 PPTX，后端不会把它拆成旧 HTML 页面。原存储读取、摘要及 PPTX 输入校验后，将不变的来源文件交给原维护入口；后续仍走已有签名准入和查询优先的派发方式。

| 阶段 | 本阶段行为 | 进度含义 |
| --- | --- | --- |
| `native_define` | 来源渲染、模板定义及实际输出身份进入原检查点 | 页数来自快照与交付预览共同验证的有序页面 ID |
| `native_stress` | 使用同代已完成定义，传入固定计划所需的来源与资源案例；接收完整计算证明 | 压力计算完成，已验证质量页数仍为零 |
| `native_verify` | 阶段身份和前置依赖已接通，实际质量计算尚未实现，完成回执明确拒绝 | 不产生质量通过或目录版本 |

整份来源的后端 `page_index` 为 `-1`，Runtime 快照不设置页索引。阶段请求封存同一任务、generation、来源、模板、字体和设置；前置检查点必须来自当前 generation。新一代重试保留旧检查点作为历史，但不会把旧 Run 的结果改写成新一代结果。

完成结果继续受原租约、取消和任务身份约束。Runtime 适配器在导出结果文件前验证原生回执的请求、任务、generation、编译档案、字体及设置；日志提交再次核对完整阶段身份和前置结果。模型文字、重复案例或压力计算成功都不能替代质量证据。

## 文件传递

原内容桥接增加 SDK 所需的显式媒体类型，包括快照、文稿上下文、特性清单、字体档案、质量文件及二进制字体。容量、摘要、媒体类型及所有者检查保持有效。

跨内容库时，只有外层阶段数据中的明确引用被转换成产品私有对象，再上传到新的内容库。模板包、快照和回执等 JSON 文件本身保持原字节；不会因为内部出现某个内容 ID 就赋予额外读取权限。下一阶段使用封存的显式资源引用，按真实摘要、长度和媒体类型重新绑定材料。

实际文件测试覆盖定义阶段的 17 个引用及压力阶段的 107 个引用，所有引用获得新内容 ID，全部文件字节保持一致。跨阶段去重后上传 78 份内容、658750 字节。这是该自有样本的传输记录，不是性能或发行体积结论。

## 数据库与验证

迁移 368 扩展原阶段枚举，并在 PostgreSQL 中约束原生阶段只能使用整份来源索引。已有不可变检查点、请求准入、租约及发布事务不另建一套。存在原生检查点时，回滚在修改约束前拒绝执行，保留已有证据；空库回滚和重新应用均已验证。此次只操作隔离测试容器和测试 schema，未迁移生产数据库，测试容器已移除。

本阶段 107 项相关测试通过：95 项后端单元/传输回归、10 项真实 PostgreSQL 测试、2 项真实原生维护专项；维护、快照及接入库的严格 Clippy、新增 Python 文件的 Ruff 与格式检查通过。

验证范围分别记录：

- 后端协调、签名回执和数据库测试使用明确的传输结果夹具，验证身份、事务、重试、取消及阶段顺序，不模拟内核质量。
- 原生专项使用原 Agent Loop、SQLite 工具日志和真实 worker，完成定义及全部 8 个文字压力案例，并拒绝 13 类压力证明变造或缺失。
- 跨内容库测试读取上述真实 worker 产生的文件；独立检查器验证全部 8 份 PPTX、16 张预览、161 个不变压缩部件及各阶段一致的页面身份。

上述测试尚未组成自动上传到目录发布的完整产品端到端验收。字体仍为自有合成字形；布局、原生编辑、播放和 Office/WPS 质量声明保持 `not_proven`。压力阶段文件为 25183 字节，仍受既有 512 KiB 容量约束，不能据此推断大模板容量。

命令、源码摘要、实测文件与保留失败见[验证证据](../reviews/evidence/2026-09-28-product-template-coordinator-verification.json)。此前计算实现见[原维护压力计算](product-template-stress-maintenance.md)。下一步继续实际质量验证、原目录事务、自动上传环境选择和批量恢复；完整高级内容与替换门禁保持开放。
