# 饼图与环形图的有界路径计算

本项承接[精确扇区分配](chart-sector-computation.md)，把明确的数据、中心、内外半径和
坐标容差编译为共享 Draw IR 的闭合三次曲线路径。属于计算内核实现；尚不代表原生
PPTX 图表渲染、编辑、主题、标签、图例或模板准入已经完成。Musterwork 的早晨验收
候选保持原有固定版本，本项未改动或重启产品。

## 语义与精度

- 输入为精确十进制权重；扇区仍从十二点方向开始，调用方明确顺/逆时针和负值策略。
  中心与半径使用 Q32 EMU；内半径为零表示饼图，正数表示环形图。外半径必须为正，
  内半径必须严格小于外半径，不猜测 Office/WPS 的默认布局。
- 共享端点先在 Q32 圈单位中计算。曲线细分仅除以二的幂，所有角度在 Q96 内精确
  表示；先做象限约化，再做区间三角函数计算。没有转成整数角度或调用平台 `libm`。
- 三次 Hermite 插值与现有 DrawingML 弧路径共用同一数学实现。每段每轴的曲线误差
  不超过 `r × |h|⁴ / 384`，`h` 为弧度步长。数值转换的误差另外记录；控制点误差
  通过非负 Bernstein 权重传递到整条三次曲线。
- 十进制分配相对输出角度的误差，用 `outerRadius × 2π × endpointError` 转为
  坐标误差；两端之间的线性角度插值仍受相同最大端点误差约束。最终报告角度、曲线、
  数值三项及其总和，并在总和超出容差时拒绝。细分预算根据剩余容差收紧。
- 零权重点保留索引并输出空路径；正权重若已经小到 Q32 扇区端点重合，返回精度
  错误，不将其当作零值丢弃。预算或取消失败均不返回前缀结果。

完整圆周单独闭合。完整环形图的内外轮廓方向相反，以 nonzero 填充形成圆孔，
两条轮廓之间没有径向连接线，因此描边不会添加虚构的接缝。非整圆扇区则沿外弧、
端点径向边、反向内弧和闭合边形成轮廓。

几何端点相同不等于相邻异色区域的抗锯齿合成已经通过质量验收。最终图表绘制仍需
验证边界覆盖、描边顺序、主题、标签与应用互操作；本项不声明不存在像素级接缝。

## 接口与资源边界

`mo-presentation-compile::chart_geometry::compile` 接受一个完整扇区集合，统一限制
路径、命令、弧段和计算阶段。默认上限分别为 4096、262144、131072 和 4000000；
十进制运算沿用图表领域预算。每次三角函数计算记入 24 个有界阶段，循环中检查取消。

公开底层入口为 `mo_kernel_api::compile_chart_geometry_json`、WASM
`compile_chart_geometry` 和 `mo-cli compile-chart-geometry <request.json>`；JSON
Schema 与 TS 合同从 Rust 生成。坐标和数值保持字符串，不接受浮点替代或未知字段。
入口不包含存储、权限、网络、系统字体或产品页面，也没有提升 Agent MCP 工具能力声明。

此响应中的误差以局部 EMU 计，不包含页面仿射变换、设备坐标量化或像素覆盖。下游必须
继续传递并合并误差预算；本次像素验证工具明确将几何误差按视口缩放后，加上 raster
报告的坐标量化误差。

## 验证方法

领域测试覆盖正反向和跨圈共享端点、圆周闭合、空权重、亚精度正值、全部资源上限、
各取消检查点、极限容差，以及每段三次曲线的采样坐标约束。共享 DrawingML 数学
实现同时执行既有编译器回归。

[`chart-geometry-parity.mjs`](../../tools/verification/chart-geometry-parity.mjs) 比较原生
与实际 WASM 的完整响应，并将自有曲线路径送入原生/WASM Skia，比较全部元数据及
像素。填充和纯描边分别验证圆孔、圆外空白、圆环内部，以及完整环形图没有径向描边。

[`chart-geometry-oracle.py`](../../tools/verification/chart-geometry-oracle.py) 从原始
十进制权重独立求比例，用 90 位 Decimal、Machin 恒等式及独立三角展开计算参考坐标，
核对每段曲线九个采样位置是否位于声明误差内。它不复用内核三角函数，也不把已经
舍入的输出角度当作真值。采样是回归证据，解析误差界来自上述插值与区间推导。

本次结果：编译器 100 项单元测试（包含九项新增几何测试）、两项公开 API 测试、严格
Clippy、生成合同和 TS 编译全部通过。130 个完整 Native/WASM 响应一致，其中 55 个
成功、75 个预期失败（63 个精度、10 个输入、两个资源预算）；全部响应通过 Schema。
大量精度反例来自跨数千十进制指数的数据，不能把其正值静默改成零。

13 帧填充/描边的全部像素和元数据一致，另外对圆孔、圆外及单扇区内部执行了
2,997,704 次像素断言。独立程序核对 239 个扇区、8660 段三次曲线、77,940 个采样点，
均在误差界内；移动控制点和伪造零误差两个反例被拒绝。64 个既有原生 DrawingML 弧
案例在重构前 WASM、重构后 WASM 和原生 CLI 之间完整响应相同。

自有复现输入在 [`fixtures/charts/geometry`](../../fixtures/charts/geometry)，可先运行
`mo-cli compile-chart-geometry fixtures/charts/geometry/full-ring.json` 查看纯计算结果。
版本、哈希、跨端记录与边界见[审查证据](../reviews/evidence/2026-09-30-chart-sector-geometry.json)。
渲染使用明确的诊断颜色和视口，不声称重现真实源图表的主题、标签或样式；上述结果也
不属于性能或安装包体积测量。
