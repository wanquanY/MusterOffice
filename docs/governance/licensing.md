# 许可证与分发状态

MusterOffice 计划开源，但**当前尚未选定或授予公开开源许可证**。仓库初始化没有附加一个未经项目权利人确认的 `LICENSE` 文件。

Apache-2.0 是详细设计中的建议，待决定后添加准确的许可证、版权归属及第三方声明。产品名称确认不等于许可证确认。

## 迁入和发行前需明确

- 新代码的权利人和贡献权利声明。
- 从 Musterwork 或其他项目迁入内容的来源、许可和授权范围。
- 第三方依赖、字体、图片、模板与测试基准各自的分发条件。
- 必需的许可证文本、NOTICE、SBOM 和资源清单。
- 公开仓库、发布账号、包名和发布时间。

本次仅初始化本地 Git 仓库和设计资料；没有迁入商业 SDK、试用二进制、用户私有文稿、Musterwork 产品源码或凭据。
