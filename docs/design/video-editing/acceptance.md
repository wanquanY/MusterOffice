# MusterOffice Video 完整验收规格

2026-10-06 · v1.0 · 完整验收矩阵尚未通过，部分基础证据见[实施记录](../../implementation/video-editing-progress.md)。对应[产品需求](../video-editing.md#22-范围边界)及[技术合同](technical-spec.md)。本文件中的通过条件不代表已经取得的完整验收结果。

## 1. 完成口径

要达到“用户可以在本地开发环境测试验收”，必须提供固定源码/组件版本、可复现启动方式、独立开发数据、实际产品路由、测试账号/权限准备说明及证据索引。禁止用独立演示页面、假保存、模拟导出或录制视频替代产品链路。

每个验收项记录：需求 ID、测试 ID、输入及哈希、运行环境、组件/codec/字体版本、步骤、预期、实际、结果、日志/产物、未覆盖范围。结果仅使用 `pass / fail / not_proven / not_applicable`，最后一种必须说明依据。

不提供真实 provider 凭证时可以完成协议/故障模拟，但真实生成和计费链路应保留 `not_proven`。可通过已有本地素材独立验收完整剪辑链路，不能假装生成成功。

| SEM-10 | schema 迁移和未知扩展 | 保留原件；必需能力不支持时明确拒绝；迁移可重放 |

## 4. 媒体、音画与质量语料

使用自生成且可再分发的标准测试素材，加经授权的真实素材。每个样本记录构造方式和哈希。至少覆盖：

- CFR：24、25、30、50、60、24000/1001、30000/1001、60000/1001；VFR 的不规则帧间隔；长 GOP、B 帧、非零 PTS 起点、合法负 DTS。
- 音频：44.1/48/96 kHz，单声道/双声道/多声道，音频先于/晚于视频、priming/padding、只有音频/只有画面。
- 画面：横竖屏、旋转元数据、非方形像素、透明图像、SDR/广色域/HDR 输入与显式 SDR 转换。
- 字幕：中文、英文、RTL、emoji、混合字体、复杂字形、缺失字体、长句换行、多个片段重复引用同一源语音。
- 格式与异常：基础 MP4/H.264/AAC 与 WebM/VP9/Opus 档案、损坏文件、截断、异常时长、超大图片、循环嵌套、未知效果。

| ID | 验收内容 | 完成标准 |
| --- | --- | --- |
| AV-01 | 精确定位 | 对已知帧标签素材逐点及随机 seek；无上一 generation 帧、无 VFR 平均帧率偏差 |
| AV-02 | 音画同步 | 闪光/脉冲同步源在起点、10 分钟、60 分钟及多次 seek 后测量，符合预算且无累积漂移 |
| AV-03 | 变速/反向/定格 | 源范围、目标时长、端点及音频策略正确；不存在越界读或隐式丢尾音 |
| AV-04 | 音频质量 | 样本数量精确；重采样/时伸延迟补偿；瞬态、语音、音乐盲听与客观响度/峰值检查 |
| AV-05 | 颜色/透明度 | 标准色块、梯度、肤色与 alpha 边缘；检查范围/矩阵/transfer、双重转换、黑边/白边 |
| AV-06 | 文字 | 相同字体/布局结果一致；位置、断行、缺字有确定诊断；人工审阅字幕可读性 |
| AV-07 | 预览与导出 | 同一采样时刻和效果档案对照；几何/文字一致；GPU/硬件误差阈值明确记录 |
| AV-08 | 故障资源 | 缺素材、磁盘满、GPU 丢失、codec 失效、授权撤销，状态明确且资源有界回收 |
| AV-09 | 输出收尾 | 可解码、容器可打开、总时长与流符合档案；非法部分文件不得发布 |
| AV-10 | 分段恢复 | 跨段无多/少帧、爆音、时伸/效果状态跳变；与从头导出做语义对照 |
| AV-11 | 素材分析与重新分析 | 在带标注的镜头/闪光/静音/重叠语音素材上记录准确率、召回与误判；候选区间合法可回查，人工修订不被重跑覆盖 |

像素/音频容差必须以参考档案定义，例如 CPU 参考的逐像素一致、GPU 的有限色差、编码后的质量阈值分别处理。不能使用单一 PSNR 数值代替对字体缺失、字幕截断或时间错位的检查。

## 5. 跨端、资源与性能

| ID | 验证 | 完成标准 |
| --- | --- | --- |
| SYS-01 | Native/WASM 同一操作语料 | 快照/诊断一致；资源路径不进入内容身份 |
| SYS-02 | 断外网导入本地素材、剪辑和导出 | 已安装的完整离线档案可完成；无模型/遥测隐含网络依赖 |
| SYS-03 | WebCodecs 支持探测、资源回收 | 实际编码初始化/样本验证，不只检查 API 存在；异常路径帧句柄释放 |
| SYS-04 | 浏览器多标签、刷新、关闭、存储配额 | 唯一写入者；原子性与 strict durability 分别验证；配额耗尽不丢失已提交版本；浏览器主动清理与断电保证边界按实测公开 |
| SYS-05 | 跨设备交接 | 权威 epoch 或显式分叉，素材缺失可见，不同时修改两个主版本 |
| SYS-06 | CPU/GPU/内存/复制预算 | 记录全部媒体阶段、UI 和框架开销；逐项对照主文预算 |
| SYS-07 | 浏览器首次加载和原生安装 | 压缩下载、解压安装、字体、codec、模型资源分项和总计 |
| SYS-08 | 取消/崩溃/长时间运行 | 取消符合预算；循环打开/关闭/seek/导出无持续增长；被挂起任务可定位 |
| SYS-09 | 模块独立 | 只装 PPT 不下载视频组件；只调用视频不初始化 PPTX/模板 |
| SYS-10 | 发行可复现 | 清单/哈希/SBOM/字体与 codec 源码对应；版本不被重绑定 |
| SYS-11 | 素材回收与任务交错 | 删除片段、清理历史、正在导出和暂存提案并发时，所有有效 pin 的原资源可读；孤儿能延迟回收，缓存不冒充原素材 |

性能至少两档设备：目标日常笔记本和较低性能设备；macOS arm64、Windows x64、Linux x64 原生及四类桌面浏览器分别登记。未完成的平台记 `not_proven`，不能以一个 Chromium 页面证明全平台。

对照测试采用同素材、同质量/像素格式/输出规格、同硬件、同缓存条件，记录至少 5 次冷/热数据和 p50/p95、峰值。厂商营销倍率和其他机器历史基准不进入我们的通过判定。

## 6. Agent、权限、生成与计费

| ID | 验证 | 完成标准 |
| --- | --- | --- |
| AG-01 | 真实技能发布与工具加载 | 输入框选择、Runtime 发现与执行器一一对应，非仅前端标签 |
| AG-02 | 小模型/大工程 | 分页查询、范围预览和结构化错误；工具结果有界，避免全量工程塞入上下文 |
| AG-03 | Explicit/Auto、重试、委派 | 显式模型/参数不得被改写；Auto 只选合格候选；子任务继承用户意图 |
| AG-04 | 本地执行器断线 | 不盲目重发有副作用的操作，不自动转云；重连通过回执判断是否已完成 |
| AG-05 | 跨用户/工作区/工程攻击 | 猜中 digest/ID 也不能读取或修改；过期引用无权限 |
| AG-06 | 隐式网络/恶意工程 | 资源解析不发任意网络请求，不执行脚本；归档和解码预算有效 |
| BILL-01 | provider 创建成功但响应丢失 | 进入不确定/对账，不重复创建付费任务 |
| BILL-02 | 轮询故障、取消、结果下载失败 | 查询可恢复；取消费用按真实规则；下载重试不重新生成 |
| BILL-03 | 价格变更、停用、缺失 usage | 既有任务按固定价格/配置结算；停用仍可对账；缺失用量不记 0 |
| BILL-04 | 免费模型、超限、重复回调 | 账本不重复扣费；明确上限/释放规则；provider 成本与积分分开 |
| BILL-05 | 本地导出 | 不产生虚假的模型费用；同步流量/可选服务费用分开 |

## 7. 互操作与完整链路

INT-01：自有工程包内嵌全部资源后在另一设备打开，工程语义和继续编辑成立。

INT-02：OTIO 基础子集往返，分别检查轨道/源范围/间隙/转场/标记；不支持项进入损失报告。

INT-03：FCPXML 选定版本在真实目标应用导入/导出；只运行 XML schema 检查不算通过。

INT-04：PPT 固定版本与资源渲染为视频源；PPT 本身的既有导出、播放和编辑回归通过。

E2E-01：从空白对话选择技能，导入混合素材，Agent 生成或选择素材、剪辑、预览；人工修正；Agent 读取最新版本继续；本地导出；消息卡片播放/下载；重启后继续编辑。

E2E-02：上述流程中交错模拟模型响应丢失、页面关闭、磁盘满和版本冲突，工程无丢失、无重复付费/修改、后台状态正确。

E2E-03：没有生成服务和外网，仅使用本地素材完成 Agent 工具执行（推理可用确定性工具序列测试）和人工编辑/导出；真实在线推理另测，不能相互替代。
