# 内核与接入产品边界

2026-09-27 · 依据 [ADR 0007](../../decisions/0007-kernel-only-integration-boundary.md)。这是当前职责与接入实施合同。计算合同及 Native 高层 SDK 已开始实际拆分，见[实现记录](../../implementation/computation-boundary.md)；默认本地薄 MCP 已实现，远程/附件档案和完整接入仍未完成，不是正式可安装包说明。

## 1. 交付范围

MusterOffice 为 Agent 提供完整、高性能、高质量的 PPT 计算能力。接入便利来自稳定接口、常用数据适配和清晰所有权，不通过增加账号系统、数据库或产品界面实现。

| 责任 | MusterOffice | 接入产品/部署环境 |
| --- | --- | --- |
| 文稿与文件 | 创建、查询、原子编辑、格式解析/写出、来源保留、质量诊断 | 选择文件、保存版本、业务历史、最终发布 |
| 绘制与播放 | 字体/布局、页面渲染、时间轴、动画/媒体同步语义、帧与播放控制接口 | 窗口/页面、工具栏、播放器 UI、设备与媒体权限交互 |
| 输入输出 | 消费不可变字节或读取句柄，流式返回模型、PPTX、图像和报告；声明完整依赖 | 打开文件、附件/对象存储、网络取数、输出位置与最终保存 |
| 身份与权限 | 不定义账号、租户、角色、ACL 或业务权限决策 | 鉴权、授权、租户隔离、凭据、允许访问的资源范围 |
| 任务与恢复 | 当前计算的进度、取消、错误、可序列化结果和计算状态 | 持久任务、重试策略、幂等记录、租约/fence、断线恢复、结果提交 |
| 生命周期 | 有界计算内存、显式释放、取消后的计算资源收尾 | 文稿/资产保留、正式资源引用、配额账本、持久暂存回收与备份 |
| Agent 包装 | 薄 SDK/CLI/MCP、操作 Schema、Skill 与安装配置 | 模型、推理循环、工具授权、任务编排和聊天/附件展示 |

PPT 的“页面”是文档语义和渲染单元，属于内核；登录、文件列表、上传下载、编辑器和播放器的产品页面不属于内核。无界面播放计算是一期能力，不能借取消 UI 交付而删减动画、媒体、seek 或跨页语义。

## 2. 最小接入合同

普通调用只需完成：初始化计算设施 → 提供输入和必要资源 → 调用文稿操作 → 接收输出/诊断 → 释放计算会话。内存、流和调用方文件句柄提供常用适配；简单用例不要求实现 JobStore、AuthorizationContext 或 ResultCommitter。

公共计算输入包含文档/来源、版本前提、操作与显式资源；执行选项包含质量档案、计算预算、期限、取消信号和进度回调。宿主的账号、tenant、角色、业务 Job、租约和数据库事务不成为内核必填字段。产品适配器可持有这些信息，在调用前检查权限、调用后验证并提交。

原子编辑仍在计算层保证整批操作全部成功或全部失败。持久 head 的 CAS、跨进程幂等和 exactly-once 业务提交由产品保证；内核 requestId 或 revision 不代替这些持久事实。无状态调用或进程内缓存不得宣称可在重启后恢复同一任务。

“不管理存储”不等于一次性物化整个 PPTX。大文件继续采用有界读取、分块输出和背压；需要随机回读时由调用方提供可回读接收器。薄本地 I/O 适配只处理调用方明确指定的文件/句柄，不创建隐藏文稿库、长期输出目录或后台目录扫描器。

文件暂存若不可避免，必须由宿主提供临时空间/句柄和容量限制；内核报告占用并释放本次计算的租借资源。崩溃后的磁盘持久恢复归宿主；不能以“缓存”名义在 MusterOffice 增加隐式持久存储。

## 3. MCP、CLI 与产品界面

本地 MCP/CLI 复用相同计算入口，通过进程输入输出、宿主附件/文件桥接或受控数据通道交换资源。远程 MCP 通过接入产品的部署网关、资源读取/写回通道工作；网关拥有认证和网络访问策略。MCP 适配器不提供自有 OAuth 账号、上传页面、内容服务器或业务数据库。

普通调用可同步执行或保持当前连接接收进度。若启用持久 Job/Tasks，必须映射到接入产品已有的任务服务，再由该服务确认接受；没有该服务时，不声明持久任务能力。连接内计算句柄仅在已声明的会话/进程寿命内有效；重启后由宿主重新提供输入或恢复其任务。

可直接配置的 MCP 使用支持的文件/附件桥接方式，无需改客户端核心代码或数据库。客户端缺少大文件通道时必须如实报告能力限制，不能为补齐 UI 而在 MusterOffice 建造文件管理平台。

渲染/播放 SDK 返回图像、绘制结果、状态、事件和诊断定位信息；接入产品组合自己的查看器、编辑器和播放器。Agent 工具允许设置动画和采样关键帧，连续帧、媒体字节和时钟不经过模型或逐帧 MCP 调用。

## 4. 计算状态与资源所有权

允许的进程内状态包括已解析文稿、字体实例、图片解码结果、布局/绘制计划和播放会话。每项均有显式所有者、预算、失效条件与释放接口。会话失效是可报告结果，不依赖内部数据库偷偷恢复。

计算只读取宿主提供的资源，不根据 PPTX 外链、模型参数中的路径或 URL 获得新访问权。外部资源需求作为诊断或依赖请求返回宿主。ZIP/XML/媒体/字体输入校验、摘要核对、整数与分配上限、隔离执行、取消仍属于内核正确性与可靠性，不因没有权限系统而移除。

输出在宿主确认之前是候选。内核生成候选及实际字节验证结果；宿主负责最终保存、原子引用登记和成功状态。若输出写入失败，不能返回交付成功。调用返回的“计算成功”必须与产品“已保存/已发布”分开。

已提交资产的引用关系和删除策略归产品；MusterOffice 不遍历产品的聊天日志、模型记录、数据库表或历史版本来推断全产品垃圾回收。需要保留的输入/输出依赖应由计算结果显式列出，产品按其原有规则登记与释放。

## 5. 包装、体积与性能

| 发行面 | 必需内容 | 不得强制捆绑 |
| --- | --- | --- |
| Native SDK | PPT 内核、必要底层组件、薄接口及计算执行适配 | MCP/HTTP 服务、自有数据库、账号权限框架、产品 UI |
| TS/WASM | 同源内核、必要 bindings、计算 Worker 与数据适配 | 新的 AgentLoop、UI 框架、业务存储或 Node.js 服务 |
| CLI/本地 MCP | 同源计算能力、对应协议/命令适配及必要 I/O 桥接 | 管理后台、登录/上传页面、持久任务/资源平台 |
| 远程 MCP | 对应协议适配、同源计算能力及宿主连接 | MusterOffice 自有租户、账号、内容库、云服务依赖 |
| Skill/Plugin | 操作说明、安装/版本/配置包装 | 第二套引擎、重复 renderer、另一套排版或格式规则 |

上述是待验证的发行依赖边界，不代表当前二进制已经达到。组件可以为计算隔离而保留 worker；不能为追求单进程而降低崩溃隔离，也不能在包装层额外复制多套同版本引擎而不计成本。

按需装配用于选择接入方式、运行平台及未来办公领域。完整一期 PPT 能力不得分成“SDK 完整、MCP 简化”两套，也不得把 SmartArt、公式、动画或媒体删掉后用体积数字宣称全功能达标。字体/codec 可以按明确资源档案交付，但完整离线验收必须包含承诺的全部闭包。

沿用[验收档案](acceptance-profiles.md)的功能、视觉、编辑、动态和绝对预算。在同一 build、文稿、字体/codec、质量检查、设备与缓存状态下，比较直接计算、高层 SDK、本地 MCP及适用的远程 MCP：冷启动、首次可用、P50/P95 时延、CPU、峰值内存、进程数、复制/传输字节、临时磁盘峰值和完整交付耗时。

调用封装、协议通信和隔离有真实开销，必须分项报告。测试前固定相对开销门槛、统计规则和测量误差；门槛未确定或没有实测时保持未验收，不能承诺零开销或随结果放宽要求。远程网络耗时单列且进入端到端结果，不能把成本移到服务器后称为消失。

体积至少报告压缩下载、解包安装、首次完整可用、离线完整包与峰值临时空间；依赖、字体、codec、JS/WASM、原生 worker 与重复副本全部计入。当前局部 worker 的体积不能外推完整一期发行包。

## 6. 当前实现差距与收敛顺序

2026-09-27 实现推进：计算算法及其合同已移至 `mo-presentation-operations`；`mo-embedded-sdk` 新增进程内文稿与借用输入接口，主 WASM 不再依赖旧服务。历史 `mo-operation-service` 保留宿主合同并调用同一计算实现；`mo-standard-host` 的 SQLite、任务、资源和作用域检查现保留在显式 `legacy-host`/`mo-mcp-legacy`；默认本地 MCP 复用直接 SDK 和调用方文件桥接，见[本地薄 MCP](../../implementation/thin-mcp.md)。当前专项证据和剩余验证见[计算合同与 SDK](../../implementation/computation-boundary.md)。

| 收敛工作 | 退出证据 |
| --- | --- |
| 分离计算与宿主公共合同 | 普通 SDK 调用没有账号/权限/持久 Job 必填项；旧合同按明确版本迁移 |
| 完成薄 SDK/CLI/MCP | 干净环境输入 → 编辑 → 渲染 → 实际 PPTX 输出；不初始化内部数据库或产品页面 |
| 明确资源桥接与所有权 | 背压、取消、错误输出、会话销毁、宿主保存/拒绝、重启失效与宿主恢复都有反例 |
| 收敛旧开发宿主 | 在依赖和兼容核对后移出正式交付路径；历史源码/测试/数据去向明确，不以简单禁用校验替代 |
| Musterwork 消费公共接口 | 薄桥接连接其原权限、任务、存储、Artifact 和界面；没有内核对产品私有数据库的依赖 |
| 完整质量与成本验收 | I01–I20、原一期能力、Office/WPS、Native/WASM、全包体积和性能分别通过 |

Musterwork 现有共享内容存储、Ledger 与快照迁移是产品改动，应分清直接接入必需修复和产品通用治理。已发现、会实际影响该链路的资源错误仍须修复；不把全产品存储重构变成所有 Agent 调用的先决条件。

本边界合同不授权删除现有数据库；后续源码拆分按实现记录单独验证。Musterwork SQLite v188 已按[2026-09-28 接入记录](../../implementation/product-sdk-preview.md)完成独立库级验证；不能把内核拆分或迁移测试视为允许删除历史数据。历史阶段证据保留原范围，不用于为新边界的未完成实现背书。
