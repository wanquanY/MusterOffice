# 执行宿主、资源生命周期与性能预算

v0.4 设计提案 · 2026-09-24。所有数值为**拟议预算或实验目标，尚未测得、尚未批准**。不以本稿宣称 Rust/WASM 已达标。精确计量口径、设备层级及扩展工作负载见[验收档案](../implementation/acceptance-profiles.md)。

## 1. 核心与宿主

| 核心拥有 | 宿主拥有 |
| --- | --- |
| 文档语义、布局、时间求值、格式、诊断 | 身份/权限、文件/网络、资源授权、任务持久化、用户界面 |
| 所需资源声明、计算进度、取消检查点 | 资源取得、执行隔离、实际调度、跨任务准入 |
| 有界临时计算、输出校验 | 暂存与原子提交、取消后回收、崩溃重试、任务 fence |
| 媒体控制语义、合成计划 | codec、音频/显示设备、平台权限、实际时钟 |

Native 和 WASM 共享同一计算与格式实现；Web 运行于 Worker，原生处理不可信外部文件默认放入可终止的受管进程。强取消依赖宿主终止实例，不能仅因语言有内存安全就省略隔离。

Web、Desktop 和无客户端的 Managed 宿主遵循同一协议。Managed 是产品已有任务的计算适配器，不能重新拥有业务 Run，也不意味着静默上传本地文件。

核心可由[统一 Operation Service](../../architecture/agent-integration.md)经 MCP/CLI/SDK 调用。独立使用由标准宿主持有任务，嵌入产品则注入现有宿主；两者不叠加竞争队列。TS 仅承担薄接入，C/C++ 基础组件遵循已确认的[语言与组件策略](../../decisions/0003-language-and-component-strategy.md)。

## 2. 资源与结果接口

概念接口采用显式长度、摘要、范围、配额和所有权，不传任意文件路径：

```text
ResourceProvider
  describe(handle) → length, digest, kind, immutable, capabilities
  readRange(handle, offset, length) → leased bytes
  release(lease)

ResultSink
  begin(metadata, sizeLimit) → staging handle
  append(handle, bytes) → acknowledged offset
  seal(handle) → immutable read handle, length, digest
  abort(handle)

Execution
  step(workBudget) → progress | needsResource | yielded | complete | failed
  cancel(token)
  dispose(session)
```

ResultSink 是顺序输出候选；ZIP Writer 需采用支持顺序写出的封装策略。若实验表明必须随机改写，增加独立可写暂存接口及预算，不暗中在核心做第二份整包拷贝。seal 后可通过 ResourceProvider 回读**相同不可变输出**，无需下载或重新生成另一份结果。

资源句柄属于会话和授权 scope，带 generation。释放/过期后不可使用，缓存键不包含用户可猜路径。长资源可分块校验；完整摘要在提交前确认。原始输入、压缩输出、解码资源和设备表面分别计量。

核心 ABI 传递可验证的二进制视图或结构化小消息。浏览器优先 transferable buffer/句柄，必要拷贝记录到性能账本；禁止为图像、字体、媒体和 PPTX 默认使用 base64 JSON。WASM 线性内存增长使旧视图失效，SDK 必须限制借用期，不暴露无生命周期的指针。

## 3. 任务执行与取消

一次昂贵计算拆为可让出步骤：包扫描、解析、对象解析、塑形、布局、逐页绘制、写包和重读。每一步有工作单元计数及取消点；资源等待必须允许宿主接收取消。WASM 同步大循环不能靠同一个 Worker 的消息队列及时处理中止，因此 step 返回间隔本身要有界。

建议取消响应 P95 ≤ 200 ms，失去响应的实例由宿主在 2 s 内终止并回收；时间从宿主接受取消开始计，暂停/调度延迟另记。解码器、压缩器和第三方依赖若不能中断，使用隔离任务并纳入最长临界区测量。

核心可以返回计算 checkpoint，但宿主只有在 revision、引擎/profile、资源摘要和阶段边界全部相同时才恢复。不能跨升级恢复内部指针或任意序列化堆。可持久化进度以业务输入与确定的完成单元为主，核心缓存可丢弃重建。

取消后：停止新工作 → 回收 CPU/GPU/解码租约 → 关闭会话 → abort 未提交输出 → 记录终态。已 seal 未提交的对象由宿主回收策略清理；失去任务 fence 的执行实例不得提交，即使晚到结果合法。

## 4. 资源账本与调度

| 类别 | 必须统计 | 释放点 |
| --- | --- | --- |
| 输入/包图 | ZIP、XML、索引、未知保留区、重复解析 | 输入关闭/共享引用归零 |
| 字体/文本 | 字体原字节、解压、塑形/字形缓存、嵌入压缩副本 | 字体包或缓存租约到期 |
| 静态图形 | 解码图像、路径、效果中间表面、页图/缩略图 | 页/对象失效或 LRU 驱逐 |
| 动态/媒体 | 合成层、纹理、解码器队列、VideoFrame/音频缓冲 | 消费/丢弃/导航/暂停策略/停止 |
| 输出/验证 | ZIP 写缓存、输出暂存、重读缓冲、逐页检查 | 检查完成/abort/提交转移 |
| 宿主/WASM | 线性内存高水位、JS backing store、Worker/进程/GPU | 实例销毁及宿主确认回收 |

准入器按阶段估计峰值，限制同时解码的页、效果表面、媒体流及并发文稿；任务间公平调度，前台交互与后台导出具有明确优先级。不能每个任务各自满足 512 MiB，却允许任意数量同时运行。

优先逐页编译/验证，使用依赖闭包维持共享主题、字体和对象。可编辑文档需持有语义模型；只读预览可懒加载目标页依赖，不强制构造全量编辑模型。长文稿不能因每页预览缓存永久保留而线性积累解码图像。

释放对象不一定降低 WASM memory 的已分配页。报告区分活跃内存、可重用空间和高水位；会话结束后必要时回收 Worker/进程，验证产品总占用回落。不能只观察语言层对象数量就声称无泄漏。

## 5. 缓存和增量

缓存键由内容摘要、引擎/规则版本、字体/资源、DPI/色彩配置和状态决定。布局缓存与最终页图缓存分开，播放帧包含事件状态与时间。实际文件 hash 变化后不得继续展示旧页图；跨租户缓存的授权和存储加密由宿主治理。

增量编辑先由依赖图失效，再复用不受影响结果；必须与全量重算结果等价。导出可以复用未变部件/压缩资源，但仍校验完整交付包；不能把“只检查改动框”当成最终文件完整性检查。

## 6. 工作负载与测量口径

| ID | 工作负载 | 核心测量 |
| --- | --- | --- |
| W-S10 / W-S40 | 10/40 页，固定中英文字/表格/图表/图片/字体清单 | 全导出、实际字节重读、全部页检查，120 DPI 预览 |
| W-R80 | 80 页第三方源文件，仅 inspect/preview | 首屏、随机跳页、全页检查与峰值；不套用编辑 40 页准入 |
| W-C40 | 40 页复杂母版/图表/SmartArt/公式/效果，固定对象计数 | 解析、布局、导出、往返和复杂度峰值 |
| W-D | 1080p 目标画布，固定动画/转场图与 1 路 1080p30 媒体 | 准备时间、逐帧时间、丢帧、音画误差、交互和显存 |
| W-M | 固定 codec、时长、码率的多媒体与双流组合 | 原资源复用、随机 seek、缓存/解码峰值和输出大小 |
| W-L | 连续 20 次生成/编辑/播放/停止/取消及异常退出 | 活跃资源归零、工作集回落、长期趋势和未提交产物回收 |

这是语料规格，尚无已生成基准集。每份 fixture 需固定对象数量、效果、文本长度、数据规模、资源 bytes、字体 hash 和权限。仅页数相同并不能用于性能比较。

冷场景分别报告下载、解压、编译/初始化、字体准备、首个有用输出及总时长；热场景注明允许的缓存。正式全导出基准清空最终页图，允许的布局/资源缓存明确记录。网络时间和本地计算时间既分项也给端到端总值。

设备至少包含目标最低内存配置与日常设备；记录 CPU、内存、OS、浏览器/运行时、图形/codec、功耗模式和构建。建议每组 ≥ 30 个计时样本，报告 P50/P95/最大值及失败数；历史 20 次测量保留原口径，不能混为新测量。

## 7. 拟议预算与实验目标

| 项目 | 拟议指标 | 限定条件 |
| --- | --- | --- |
| 静态 WASM 模块闭包 | 压缩下载 ≤ 15 MiB | 含必要 JS glue/算法依赖；字体、媒体模块另列，不能代表完整一期安装包 |
| 静态原生安装闭包 | 未压缩 ≤ 30 MiB/架构 | 核心+CLI/宿主及必要依赖；压缩下载另报，系统依赖显式登记；不含未来领域模块 |
| W-S10 / W-S40 全流程 | P95 ≤ 5 s / 8 s | 资源已准备，包含导出/重读/规定检查；在批准设备上判定 |
| 局部编辑反馈 | P95 ≤ 300 ms | 单对象语义编辑至可见受影响页；不含完整 ZIP 提交，复杂对象另测 |
| W-S10 / W-S40 峰值 | ≤ 256 / 512 MiB 增量 | 专用计算宿主+核心完整增量，含桥接及重读；宿主总工作集另报 |
| 主线程 | 文稿计算不产生 ≥ 50 ms long task | 在集成产品中测量；不能只测空页面 Worker |
| 取消 | P95 ≤ 200 ms，强终止 ≤ 2 s | 所有执行阶段、解码和输出清理均覆盖 |
| W-D 交互播放实验 | 1080p60 呈现，帧预算 16.7 ms，音画误差目标 ≤ 50 ms | 先固定语料和设备，测 P95/最大值、丢帧及同步分布；尚未形成正式 SLA |
| W-L 资源释放 | 活跃句柄/帧/临时结果无残留、稳定工作集无持续增长 | 容许已声明有界缓存与内存池，须有统计解释 |

完整动态内核的模块体积、W-C40/W-M 峰值、最低设备播放档案和完整离线包预算必须在 E0 给出结果，再批准数值；不能拿静态 ≤ 15 MiB 数字宣传完整办公套件。任何工作负载不达质量门槛，其性能数字都不能算达标。

总体积需并列：核心模块、绑定/宿主、绘制、媒体/容器、字体、默认模板/素材、传递依赖、缓存、压缩下载、安装磁盘、首次离线可用总量和生成 PPTX。操作系统提供的组件注明平台前提，不能算作全平台零依赖。

## 8. 输入复杂度、安全与观测

按操作设置页数、对象/字符、几何段、表格格数、图表点数、SmartArt 展开节点、数学树深度、时间节点/事件、解码像素、压缩比及资源总量。配置可调且公布已测边界；不把 40 页写死在领域类型内。

观测事件只记录阶段、耗时、资源量、版本和经过策略允许的标识；默认不上传正文、图像、音视频或完整 XML。诊断 bundle 由宿主显式收集授权。错误和性能报告复用同一阶段名和对象 ID，避免为调试复制用户全部内容。

本规格不新增常驻服务要求，不把客户端失去连接解释为核心永久等待。任务继续、迁移执行地点和恢复政策由[Musterwork 接入合同](musterwork-integration.md)负责。

公共 MCP/Plugin 的安装包、标准宿主、通信缓冲和 Viewer 同样进入体积/内存账本；若按需分包，报告首次完整可用成本。传输层取消与持久作业取消分别处理，详细状态和 I01–I16 接入验收见[公共接口规格](../agent-interfaces.md)。
