# MusterOffice 产品愿景与范围

日期：2026-09-24。名称和产品方向已由项目发起人确认；下述模块划分是架构建议，未来模块未获实现授权。

## 产品定位

MusterOffice 是专门为 Agent 设计的轻量、高性能、跨平台办公内核。通过结构化模型、可编程操作、渲染、导出和诊断，让 Agent 能够可靠创建、修改、检查并交付办公成果。

Agent 是主要调用者，开发者是集成者，人是最终成果的阅读者和编辑者。无需依赖面向人的办公界面自动化，也无需绑定某个模型或业务平台。

## 场景扩展

| 领域                   | 可以解决的问题                               | 状态                               |
| ---------------------- | -------------------------------------------- | ---------------------------------- |
| Presentations 演示文稿 | 布局、图表、模板、预览、原生可编辑 PPTX      | 首个设计与验证方向；详细方案待评审 |
| Documents 文档         | 结构化内容、分页、样式、引用和文档交付       | 后续扩展方向；未定义首版范围       |
| Spreadsheets 电子表格  | 单元格、公式依赖、表格计算、图表和工作簿交付 | 后续扩展方向；需独立计算与兼容设计 |
| 其他办公场景           | 在相同 Agent 协议与资源边界上扩展            | 逐项评审，不承诺全部 Office 能力   |

先把首个领域的质量和接口做完整，再抽取被实际复用的基础设施。不为尚未验证的未来需求提前实现庞大的通用模型。

## 所有领域共同遵守的要求

- 结构化操作、稳定身份、事务、版本检查、可取消执行和可定位诊断。
- 数据、文字和对象编辑性保留；实际文件和外部应用兼容分别检查。
- 完整计算可在适当的客户端或本地宿主运行，不依赖厂商在线许可服务。
- 开放接口与可复现语料；核心不依赖模型采购、产品账户或私有平台。
- 按实际依赖、字体、缓存、输入规模和运行载体衡量体积与性能。

“轻量”是按能力装配、明确资源所有权和去除无关依赖；不得以缺失内容、图片化交付或关闭质量检查换取轻量。

## 与 Musterwork 的关系

MusterOffice 是独立项目。Musterwork 是预期的首个接入方，可以通过适配器使用其能力；MusterOffice 不依赖 Musterwork 才能运行。

Musterwork 负责业务任务、用户权限、模型调用、内容存储和结果发布。MusterOffice 负责办公文档的计算、格式语义与验证。已有代码需要经过权属和依赖审查后才能迁出，目前只迁移设计资料。
